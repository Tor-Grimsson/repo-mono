### 2. Remotion FontPreviewShowcase — Attempted & Abandoned
Attempted to create a Remotion composition animating the `FontPreviewItemAlt` component from `@kol/ui` at 1080×1350 (4:5 Instagram portrait).

**Outcome:** Technically functional but impractical for production use.

**Blockers discovered:**
- `@kol/ui` barrel exports pull in `Icon` and `Illustration` atoms which use `import.meta.glob` — a Vite-only API incompatible with Remotion's Webpack bundler
- Had to create lightweight visual-only replicas (`VideoUI.tsx`) of Slider, Dropdown, Divider, and Icon — resulting in a pale imitation of the real components
- Animation was basic linear value changes, not the polished feel needed for social content
- **Conclusion:** Remotion is best for simple compositions (Wordmark intros, motion graphics) that don't need the full `@kol/ui` component library. For component showcases, Playwright screen recording is far superior.

**Webpack fixes applied (still useful):**
- Added `fullySpecified: false` rule to `remotion.config.ts` for `.jsx` extensionless imports
- Added resolve extensions `.ts/.tsx/.js/.jsx/.json`

### 3. Playwright Screen Recording — Working Pipeline
Discovered and validated a Playwright-based approach for recording real component interactions as video.

**Pipeline:**
1. Playwright launches chromium with `deviceScaleFactor: 2` and `recordVideo` at 2x resolution
2. Navigates to the live dev server, scrolls target component to viewport center
3. Performs scripted interactions (smooth slider drags, dropdown clicks, style toggles)
4. ffmpeg converts raw `.webm` → H.264 MP4 at CRF 18, outputs both 2x (2160×2700) and 1x (1080×1350)

**Key advantages over Remotion approach:**
- Real component with real design system, fonts, dark mode
- No dependency resolution issues
- Interactions look authentic (eased cubic mouse movement)
- ~120 lines of self-contained script
