## 1. Remotion App Scaffold — `apps/video`

### Context

Added Remotion (programmatic video from React components) as a new app in the monorepo. Remotion runs its own dev server and build pipeline (Webpack, not Vite) and consumes shared components from `@kol/ui` without modifying them. TypeScript is used for `apps/video` — Remotion is TS-first and the JS-only rule applies only to web/ui/foundry/fontviewer.

### Key Decision — Webpack css-loader Override

Remotion uses Webpack internally with `style-loader` + `css-loader` (plain strings, no options). `@kol/ui/theme.css` contains `@font-face` declarations with `/fonts/...` absolute URLs that Vite resolves from `public/` but Webpack can't.

**Solution:** Override Webpack config in `remotion.config.ts` to set `url: false` on `css-loader`. This tells css-loader to leave `url()` paths as-is (browser resolves them at runtime). A separate `fonts.css` in `apps/video/src/` provides `@font-face` declarations with relative paths (`../public/fonts/...`) that Webpack can bundle.

The override detects css-loader both as a plain string (Remotion's default) and as an object (if future versions change the config format).

### Key Decision — Font Symlink

`apps/video/public/fonts/` is a symlink to `apps/web/public/fonts/`. This avoids duplicating 18 font files while making them available to both Vite (via `/fonts/...` from web's public dir) and Webpack (via relative paths from video's public dir).
