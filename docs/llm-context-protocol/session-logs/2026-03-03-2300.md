### 1. GLIF MCP Configuration

**Problem**: GLIF MCP server wasn't connecting despite having an API token.

**Root causes found:**
- `claude mcp add` command placed the token as a CLI arg (`-e GLIF_API_TOKEN=...`) instead of in the `env` object
- Initial config was written to `~/.claude/settings.json` — wrong file. Claude Code reads MCP servers from `~/.claude.json`
- Required full Claude Code restart for MCP server to initialize

**Fix**: Manually edited `~/.claude.json` with correct structure:
```json
"mcpServers": {
  "glif": {
    "type": "stdio",
    "command": "npx",
    "args": ["-y", "@glifxyz/glif-mcp-server@latest"],
    "env": { "GLIF_API_TOKEN": "..." }
  }
}
```

Cleaned up duplicate inert entry from `~/.claude/settings.json`.

### 2. MCP Server Bug Discovery

The `@glifxyz/glif-mcp-server@latest` has a validation bug:
- `glif_info` and `run_glif` tools fail with `deletionReason` schema errors

- **Broken tools**: `glif_info`, `run_glif`

## Shell Sidebar CSS Fixes

**Agent**: Claude Opus 4.6
**Focus**: Fix child item indentation and drawer scroll-anchor shift

### 8. Child Item Indentation Fix

**Problem**: In the shell sidebar/drawer navigation, child items (Overview, Atoms, etc.) appeared flush with the parent label text. The parent has a chevron (12px) + gap (8px) before its label, but children only had `padding-left: 12px`.

**Fix** in `packages/ui/css/components.css`:
- `.shell-nav-item` padding: `6px 12px` → `6px 12px 6px 32px` (32px = 12px chevron + 8px gap + 12px indent)
- `.shell-nav-item.active` padding-left: `10px` → `30px` (accounts for 2px left border)

### 9. Drawer Scroll-Anchor Shift Fix

**Problem**: In the workshop drawer, expanding a nav section (e.g. Design System) caused the "NAVIGATION" label to shift up ~4-6px. Did not occur in docs.

**Root cause**: Browser scroll anchoring. In workshop, the active section auto-expands on drawer mount, so content is near/at overflow. Expanding another section inserts children above already-visible items. The browser's scroll anchoring algorithm adjusts scroll position to keep lower content stable, which pushes the top content (NAVIGATION label) upward. Docs never hit this because all groups start collapsed — content never overflows enough to trigger anchoring.

**Fix** in `packages/ui/src/layout/ShellDrawer.jsx`:
- Added `style={{ overflowAnchor: 'none' }}` to the scroll container (`flex-1 overflow-y-auto` div)

### 15. Tailwind v4 @source Fix — Sidebar Layout Broken

**Problem**: After deleting `DocsLayout.jsx`, the sidebar stacked vertically above content instead of side-by-side. Grid columns stopped working entirely.

**Root cause**: Tailwind v4 auto-scans source files but skips `node_modules/`. The workspace package `@kol/ui` is symlinked into `node_modules/@kol/ui`, so `packages/ui/src/layout/ShellLayout.jsx` was invisible to Tailwind's scanner. The arbitrary grid-cols classes (`lg:grid-cols-[256px_minmax(0,1fr)]`) were previously being picked up from `DocsLayout.jsx` inside `apps/web/src/` — the only scannable copy. Deleting it removed the only source Tailwind could find for those utility classes.

**Fix**: Added `@source "../../../packages/ui/src";` to `apps/web/src/index.css` after `@import "tailwindcss"`. This tells Tailwind v4 to scan the UI package source files for utility classes.

### 16. Sticky Sidebar Fix

**Problem**: Sidebars lost sticky positioning — they scrolled with content instead of staying pinned.

**Root cause**: An errant `items-start` was added to the grid during debugging. This shrink-wraps grid items to their content height, making the aside only as tall as its sticky inner div — no room to stick. The original grid never had `items-start`.

**Fix**: Removed `items-start` from the grid. With default `items-stretch`, aside columns stretch to match main content height, giving the inner `sticky` div room to stick within the scroll container.

### 17. Sticky Top Offset Alignment

**Problem**: Small pixel gap between sidebar padding-top and sticky offset.

**Root cause**: Sidebar aside had `lg:pt-8` (32px) padding but sticky inner div used `top-6` (24px) — 8px mismatch.

**Fix**: Changed `sticky top-6` → `sticky top-8` on both NavColumn and TocColumn inner divs.
