### `SearchInput.jsx` — New Props

**`iconOnly`** — renders a 36×36 icon button (same hover pattern as other header controls). `value`, `onChange`, `placeholder` ignored.

**`bare`** — renders a full-width flex row (icon + input) with no pill border or background. Used inside the overlay card. Layout and typography via inline styles to avoid Tailwind class compilation issues in new files. Icon dimmed to 48% opacity via a wrapping `<span>`; input text inherits full foreground.

- Fixed overlay at `z: 300`, backdrop `rgba(0,0,0,0.6)` + `backdropFilter: blur(1px)`
- Card: `max-width: 32rem`, `border-radius: 22px` (half input row height — pill when empty, consistent corners when results expand)
- `SearchInput bare` autofocuses on open; query resets on close
- Flattens all `WORKSHOP_ROUTES` children into a flat list with parent `sectionLabel`
- Case-insensitive substring filter
- **`HighlightMatch`** component: splits label at match index, renders matched slice with `color: var(--kol-surface-on-primary)`, `textDecoration: underline`, `textDecorationThickness: 2px`, `textUnderlineOffset: 3px`
- Section label rendered at 11px, 48% opacity, pushed right via `marginLeft: auto`
- Keyboard: `Escape` → close, `Enter` → navigate to first result + close
- Global shortcut listener in `WorkshopLayout` (`⌘K` / `Ctrl+K` / `Alt+B`)

## 4. Design System Mobility Plan

### Context

Discussed CSS architecture for making `@kol/ui` portable as a standalone design system. Findings documented as a reference plan.

### Files Changed

| File | Change |
|---|---|
| `docs/design-system-mobility.md` | **Created** — full architecture plan |

### Key Findings

- `theme.css` already IS the tokens layer (`@theme {}` block with all `--kol-*` properties, font faces, dark mode overrides) — no separate `tokens.css` needed
- `theme.css` requires Tailwind v4 (`@theme {}` directive) — any consumer needs Tailwind v4
- Font paths hardcoded to `/fonts/...` — needs documenting as a portability caveat
- Plan: carve `atoms.css` from `components.css` (typography scales, btn, input, tag, pill, icon animation) so another project can import `theme.css` + `atoms.css` as a self-contained design system
