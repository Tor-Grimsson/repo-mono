## Changes Made

### 1. ErrorBoundary: Link outside Router context
**File**: `apps/web/src/components/errors/ErrorBoundary.jsx`

ErrorBoundary wraps `<BrowserRouter>` in App.jsx, so when it catches an error and renders its fallback UI, `<Link>` from react-router-dom has no router context — `useContext()` returns null, causing a cascading crash.

**Fix**: Replaced `<Link to="/">` with `<a href="/">` and removed the unused `react-router-dom` import.

### 2. DashboardComponents: TDZ reference error
**File**: `apps/web/src/routes/workshop/DashboardComponents.jsx`

`useLayoutEffect` at line 119 referenced `allExpanded` and `toggleAll` before they were declared by `useSectionExpansion` on line 123. This is a temporal dead zone (TDZ) violation — `const`/`let` variables can't be accessed before their declaration.

**Fix**: Moved `useLayoutEffect` after the `useSectionExpansion` hook call.

### 3. TocColumn breakpoint: xl -> lg
**File**: `packages/ui/src/layout/ShellLayout.jsx`

Right sidebar (TocColumn) was hiding at `xl` (1280px). Changed to `lg` (1024px) to match the left sidebar breakpoint — both sidebars now hide/show at the same breakpoint.

## Decisions & Notes
- ErrorBoundary must never use router-dependent components since it sits outside the router tree
- Hook ordering matters — all hooks must be called before any `useLayoutEffect`/`useEffect` that depends on their return values
