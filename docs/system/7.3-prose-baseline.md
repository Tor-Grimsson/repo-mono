# 7.3 Prose Baseline Grid

## Overview
Visual alignment checker for verifying vertical rhythm and baseline grid alignment in prose typography. The baseline grid is now integrated directly into the main Prose styleguide page with a toggleable overlay.

## Implementation

### Inline Baseline Grid
**Location:** `apps/web/src/routes/styleguide/Prose.jsx` (lines 57-80)

The baseline grid is implemented as an inline SVG pattern overlay, controlled by a "Show/Hide Baseline Grid" toggle.

**Configuration:**
```jsx
const gridSize = 8 // 8px grid unit

{showGrid && (
  <svg
    className="absolute pointer-events-none"
    style={{
      opacity: 0.12,
      width: '200vw',
      height: '200vh',
      left: '-50vw',
      top: '-50vh'
    }}
  >
    <defs>
      <pattern id="grid" width={gridSize} height={gridSize} patternUnits="userSpaceOnUse">
        <path
          d={`M ${gridSize} 0 L 0 0 0 ${gridSize}`}
          fill="none"
          stroke="currentColor"
          strokeWidth="0.5"
        />
      </pattern>
    </defs>
    <rect width="100%" height="100%" fill="url(#grid)" />
  </svg>
)}
```

**Key Features:**
- Uses SVG `<pattern>` element to create repeating 8px grid
- Positioned absolutely with `pointer-events-none` to not interfere with content
- Grid lines use `currentColor` to respect theme (light/dark mode)
- Extended coverage (200vw × 200vh) ensures grid remains visible when zoomed out
- Toggleable via Tag control in the Prose page header

**Usage:**
Navigate to `/styleguide/prose` and click "Show Baseline Grid" to enable the overlay.

**Purpose:**
- Verify vertical rhythm alignment across all prose elements
- Check that line heights, margins, and padding align to 8px grid
- Visual QA tool for typography consistency
- Reference for developers implementing new prose components

## Grid Information
- **Grid Unit:** 8px (base, configurable via `gridSize` variable in Prose.jsx)
- **Line Height:** 150% (1.5) for body text
- **Base Font Size:** 16px
- **Vertical Rhythm:** All spacing should align to 8px increments

## Design System Integration
The baseline grid follows the same SVG pattern approach used in other apparatus components (like WavyCircleEditor), using inline SVG with `currentColor` for theme-aware styling.

## Architecture Notes

**Previous Architecture (deprecated):**
- Separate `BaselineGrid.jsx` component
- Separate `ProseBaseline.jsx` page
- Props-based configuration

**Current Architecture (2025-10-31):**
- Inline SVG grid in `Prose.jsx`
- Toggle control via Tag component
- Configuration via local variables
- All content and controls in single file

**Rationale:** Simplified architecture eliminates unnecessary abstraction layers. Grid is single-use and co-locating with prose examples makes configuration more discoverable.
