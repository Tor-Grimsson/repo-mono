# Components Overview

## Architecture

The Kolkrabbi design system follows an atomic design methodology with three primary levels:

- **Atoms** (6.1) - Basic building blocks (buttons, inputs, toggles)
- **Molecules** (6.2) - Combined components (form groups, cards, navigation)
- **Organisms** (7.x) - Full sections (headers, footers, complex layouts)

This document provides an overview of the component architecture and how atoms combine to form more complex UI elements.

## Component Patterns

### Responsive Sizing
Components use responsive sizing patterns:
- **sm**: 11px font, 12px padding (mobile)
- **md**: 12px font, 14px padding (tablet)
- **lg**: 14px font, 16px padding (desktop)

### Theme Adaptation
All components automatically adapt to light/dark themes using CSS custom properties:
- `var(--kol-surface-primary)`
- `var(--kol-surface-secondary)`
- `var(--kol-surface-on-primary)`
- `var(--kol-border-default)`

### Typography
Components use consistent typography scales:
- Body text: `var(--kol-font-family-body)`
- Mono text: `var(--kol-font-family-mono)`
- Display text: `var(--kol-font-family-rgrot-tight)`

## Usage Guidelines

### Importing Components
```javascript
import { Button, Dropdown, Input, Pill } from '@kol/ui';
```

### Customization
Components accept `className` and `style` props for customization:
```javascript
<Button className="custom-button" style={{ marginTop: '16px' }}>
  Click me
</Button>
```

### Size Variants
Most interactive components support size variants:
```javascript
<Button size="sm">Small</Button>
<Button size="md">Medium</Button>
<Button size="lg">Large</Button>
```

### Responsive Props
Some components accept responsive props:
```javascript
<Dropdown size={{ base: 'sm', md: 'md', lg: 'lg' }} />
```

## Best Practices

1. **Consistency**: Use consistent sizing across related components
2. **Accessibility**: All components include ARIA labels and keyboard navigation
3. **Performance**: Components use React.memo for expensive renders
4. **Theme**: Components adapt to themes automatically - avoid hardcoded colors
5. **Typography**: Use the defined font families and scales

## Component Dependencies

- **Icons**: All icon-based components import from `@kol/ui`
- **Styles**: Component styles come from `packages/ui/css/`
- **Themes**: Themes are defined in `packages/ui/theme.css`
