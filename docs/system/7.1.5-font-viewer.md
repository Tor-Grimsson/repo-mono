# 7.1.5 Font Preview Card

The font preview card is the first piece of the revived font viewer system. It
shows a static specimen inside a 400 × 560 card while exposing the same data
that powered the BX90000-style viewer: OpenType metadata, variation axes, and
grid-aware presentation.

## Component
- `apps/web/src/components/fontviewer/FontPreviewCard.jsx`
- Uses `FontLoader` utilities from `@kol/fontviewer`
- Default asset: `packages/fontviewer/src/assets/variFont/TGMalromurItalicVF.ttf`

## Layout
- Card shell (`max-w-[420px]`, `h-[560px]`) with surface/border tokens
- Header: title/subtitle + badge summarising axes count
- Preview well: centered text block, responsive font size, variation settings
- Controls: sample mode buttons, text input, sliders (font size + axes)
- Footer metrics: Units per em, glyph count, designer name

## Interaction States
- Sample modes: `glyph`, `word`, `sentence`
- Sliders wired to `@kol/ui` `Slider` component; values reflected instantly
- Automatically extracts default axis values from the font metadata
- Errors (failed font load) surface as `kol-mono-xs` danger text at bottom

## Usage
- Imported in `apps/web/src/routes/Demo.jsx` for rapid prototyping
- Future targets: `/tools/fontviewer/`, specimen pages, character set hovers
