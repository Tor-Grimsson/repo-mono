# CSS Components Reference

**Version:** 1.0
**Last Updated:** 2025-10-16
**Status:** Stable

> This chapter documents the reusable CSS component classes defined in `packages/ui/css/components.css`. For architectural context, see [`4.0-css-architecture.md`](./4.0-css-architecture.md).

## Overview

Component classes live in `packages/ui/css/components.css` within the `@layer components` block. These classes are consumed by React atoms in `packages/ui/src/atoms/` and provide consistent styling primitives across all apps in the monorepo.

**Key Principles:**
- All component classes consume semantic tokens from `theme.css`
- Classes adapt automatically to surface context (`.surface-inverse`, support bands)
- Prefer using React atoms from `@kol/ui` over raw class strings
- When adding new patterns, define them in `components.css` before creating React wrappers

## Typography Components

### Display Typography

#### `.kol-display`
Large display text for hero sections and marketing moments.

**Specs:**
- Font: Sohne Breit
- Size: 96px / 6rem
- Weight: 500 (medium)
- Line height: 100% (0.0em)
- Letter spacing: -0.04em
- Text transform: uppercase
- Usage: Hero headlines, marketing banners


Section-level titles and major headings.

**Specs:**

- Weight: 500 (medium)

- Letter spacing: -0.02em
- Text transform: uppercase

## Interactive Components

### Buttons

#### `.btn`
Base button component with semantic token integration.

**Specs:**
- Display: inline-flex
- Alignment: items-center, justify-center
- Padding: 12px 24px
- Border radius: 8px
- Font: Inherits from parent (use with `.text-control`)
- Transition: all 150ms ease
- Background: `var(--kol-container-primary)`
- Color: `var(--kol-container-on-primary)`
- Border: 1px solid `var(--kol-border-default)`

**States:**
- Hover: `background-color: var(--kol-container-primary-hover)`
- Active: `background-color: var(--kol-container-primary-active)`
- Focus: `outline: 2px solid var(--kol-border-focus)`, `outline-offset: 2px`
- Disabled: `opacity: 0.4`, `cursor: not-allowed`

```jsx
<button className="btn text-control">Default Button</button>
```

#### `.btn-accent`
Accent button for primary actions and CTAs.

**Specs:**
- Extends `.btn`
- Background: `var(--kol-accent-primary)`
- Color: `var(--kol-accent-on-primary)`
- Border: 1px solid `var(--kol-accent-primary)`

**States:**
- Hover: `background-color: var(--kol-accent-primary-strong)`
- Active: `background-color: var(--kol-accent-primary-strong)`, `transform: scale(0.98)`

```jsx
<button className="btn btn-accent text-control">Primary Action</button>
```

#### `.btn-danger`
Destructive button for delete and critical actions.

**Specs:**
- Extends `.btn`
- Background: `var(--kol-status-danger)`
- Color: `var(--kol-status-on-danger)`
- Border: 1px solid `var(--kol-status-danger)`

**States:**
- Hover: `background-color: var(--kol-status-danger-strong)`
- Active: `background-color: var(--kol-status-danger-strong)`, `transform: scale(0.98)`

```jsx
<button className="btn btn-danger text-control">Delete</button>
```

#### `.btn-ghost`
Ghost button with transparent background.

**Specs:**
- Extends `.btn`
- Background: transparent
- Color: `var(--foreground)`
- Border: 1px solid `var(--kol-border-default)`

**States:**
- Hover: `background-color: var(--kol-surface-secondary-hover)`
- Active: `background-color: var(--kol-surface-secondary-active)`

```jsx
<button className="btn btn-ghost text-control">Cancel</button>
```

### Sliders and Controls

#### `.slider`
Custom styled range input slider.

**Specs:**
- Width: 100%
- Height: 24px
- Background: transparent
- Cursor: pointer

**Track:**
- Height: 4px
- Background: `var(--kol-container-secondary)`
- Border radius: 2px

**Thumb:**
- Width: 16px
- Height: 16px
- Background: `var(--kol-accent-primary)`


## Data Display Components

### Data Tables

Data table component classes provide consistent styling for tabular data across the styleguide and documentation.

**Architecture:** Classes are separated into **cell classes** (with padding, applied to `<td>`/`<th>`) and **content classes** (no padding, applied to elements inside cells). This prevents double-padding issues when mixing content types.

#### Cell Classes (Applied to `<td>`/`<th>`)

##### `.dt-cell-title`
Column header styling for table titles.

**Specs:**
- Padding: 12px 16px (responsive: 8px 12px on viewports ≤768px)
- Font: Right Grotesk Mono
- Size: 0.75rem (12px)
- Weight: 400
- Line height: 130%
- Text transform: uppercase
- Color: `var(--kol-surface-on-primary)` (context-aware)
- Usage: `<th>` elements in table headers

```jsx
<th className="dt-cell-title">Token Name</th>
```

##### `.dt-cell-text`
Standard table cell text.

**Specs:**
- Padding: 12px 16px (responsive: 8px 12px on viewports ≤768px)
- Font: Right Grotesk Mono
- Size: 0.8125rem (13px) - improved from 12px for readability
- Weight: 400
- Line height: 140%
- Color: `var(--kol-surface-on-primary)` (context-aware)
- Usage: Primary content cells in tables

```jsx
<td className="dt-cell-text">Surface Primary</td>
```

##### `.dt-cell-meta`
Muted metadata cells with reduced emphasis.

**Specs:**
- Padding: 12px 16px (responsive: 8px 12px on viewports ≤768px)
- Font: Right Grotesk Mono
- Size: 0.625rem (10px)
- Weight: 400
- Line height: 130%
- Color: `color-mix(in srgb, var(--kol-surface-on-primary) 60%, transparent)` (context-aware with opacity)
- Max-width: 24rem (~384px) - prevents excessive text sprawl
- Usage: Secondary information, descriptions

**Note:** Max-width constraint follows best practice for optimal reading width (50-75 characters).

```jsx
<td className="dt-cell-meta">Used for page backgrounds</td>
```

##### `.dt-cell-metaStrong`
Emphasized metadata without opacity reduction.

**Specs:**
- Padding: 12px 16px (responsive: 8px 12px on viewports ≤768px)
- Font: Right Grotesk Mono
- Size: 0.625rem (10px)
- Weight: 400
- Line height: 130%
- Color: `var(--kol-surface-on-primary)` (context-aware)
- Usage: Important metadata, technical values

```jsx
<td className="dt-cell-metaStrong">#fcfbf8</td>
```

#### Content Classes (Applied to elements inside `<td>`)

##### `.dt-meta`
Muted text for use inside table cells (no padding).

**Specs:**
- Padding: none
- Font: Right Grotesk Mono
- Size: 0.625rem (10px)
- Weight: 400
- Line height: 130%
- Color: `color-mix(in srgb, var(--kol-surface-on-primary) 60%, transparent)` (context-aware with opacity)
- Max-width: 24rem (~384px)
- Usage: Nested text elements that need meta styling without extra padding

```jsx
<td className="dt-cell-text">
  <span className="kol-mono-xs">Primary Label</span>
  <p className="dt-meta">Additional description text</p>
</td>
```

##### `.dt-metaStrong`
Emphasized text for use inside table cells (no padding).

**Specs:**
- Padding: none
- Font: Right Grotesk Mono
- Size: 0.625rem (10px)
- Weight: 400
- Line height: 130%
- Color: `var(--kol-surface-on-primary)` (context-aware)
- Usage: Nested emphasized text without extra padding

```jsx
<td className="dt-cell-text">
  <span className="dt-metaStrong">Important note</span>
</td>
```

#### Legacy Classes (Backwards Compatibility)

The following classes are deprecated but maintained for backwards compatibility. They map to the new cell classes:

- `.dataTableTitle` → `.dt-cell-title`
- `.dataTableText` → `.dt-cell-text`
- `.dataTableMeta` → `.dt-cell-meta`
- `.dataTableMetaStrong` → `.dt-cell-metaStrong`

**Migration:** Update to new class names when editing files. Do not use legacy names in new code.

#### `.dataTablePair`
Special styling for paired token columns.

**Specs:**
- Extends `.dataTableText` or `.dataTableTitle`
- Min width: 200px
- Usage: Background/foreground token pair columns

```jsx
<th className="dataTableTitle dataTablePair">Token Pair</th>
```

#### `.dataTablePill`
Base inline status pill for table cells.

**Specs:**
- Display: inline-flex
- Padding: 2px 12px
- Border radius: 9999px (full)
- Font: Right Grotesk Mono
- Size: 0.75rem (12px)
- Weight: 400
- Usage: Status indicators, tags, badges

**Variants:**

`.dataTablePill-light` - Recommended/primary status
- Background: `var(--kol-surface-secondary)` (context-aware)
- Color: `var(--kol-surface-on-secondary)` (context-aware)
- Border: 1px solid `var(--kol-border-default)`

`.dataTablePill-muted` - Support/neutral status
- Background: `color-mix(in srgb, var(--kol-surface-on-primary) 16%, transparent)` (context-aware)
- Color: `var(--kol-surface-on-primary)` (context-aware)
- Border: none

`.dataTablePill-dark` - Limited/warning status
- Background: `var(--kol-surface-on-primary)` (context-aware)
- Color: `var(--kol-surface-primary)` (context-aware)
- Border: 1px solid `var(--kol-border-default)`

```jsx
<span className="dataTablePill dataTablePill-light border border-auto">Recommended</span>
<span className="dataTablePill dataTablePill-muted">Support</span>
<span className="dataTablePill dataTablePill-dark border border-auto">Limited Use</span>
```

**Important:** All variants use context-aware tokens that adapt when placed inside `.bg-surface-inverse` containers.

#### `.dataTableToken`
Inline token chip for displaying CSS variable names.

**Specs:**
- Display: inline-block
- Padding: 4px 8px
- Border radius: 4px
- Font: Sohne Mono
- Size: 11px / 0.6875rem
- Weight: 400 (regular)
- Background: `var(--kol-surface-secondary)` or utility class
- Border: 1px solid (when paired with utility)
- Usage: Token names, CSS variables, code snippets

```jsx
<span className="dataTableToken bg-fg-16 border border-surface-16">
  --kol-surface-primary
</span>
```

## Surface Utilities

### `.surface-panel`
Creates a context wrapper for cards and panels.

**Specs:**
- Sets custom properties for nested components
- `--surface-panel-bg`: Inherits from surface context
- `--surface-panel-fg`: Inherits foreground context
- Usage: Wrap cards, modals, dropdowns

```jsx
<div className="surface-panel rounded-2xl border border-auto p-6">
  <h3 className="kol-headline">Panel Content</h3>
</div>
```

### `.surface-inverse`
Inverts the color palette for sections.

**Specs:**
- Flips foreground/background tokens
- Updates all child component variables
- Affects `.bg-auto`, `.text-auto`, `.border-auto`
- Usage: Dark sections in light theme, light sections in dark theme

```jsx
<section className="surface-inverse">
  <div className="bg-auto text-auto p-8">
    Content inherits inverted palette
  </div>
</section>
```

## Context-Aware Utilities

### `.bg-auto`
Adaptive background color following surface context.

**Specs:**
- Background: `var(--component-surface)`
- Automatically resolves to:
  - `--kol-surface-primary` in default context
  - `--kol-surface-inverse` inside `.surface-inverse`
- Usage: Cards, panels, component backgrounds

```jsx
<div className="bg-auto p-6 rounded-xl">Auto background</div>
```

### `.text-auto`
Adaptive text color following surface context.

**Specs:**
- Color: `var(--component-fg)`
- Automatically resolves to:
  - `--kol-surface-on-primary` in default context
  - `--kol-surface-on-inverse` inside `.surface-inverse`
- Usage: Text, icons, any foreground content

```jsx
<p className="text-auto">Auto foreground color</p>
```

### `.border-auto`
Adaptive border color at 10% opacity.

**Specs:**
- Border color: `var(--component-border)`
- Opacity: 10% of foreground color
- Adapts to surface context
- Usage: Card borders, dividers, outlines

```jsx
<div className="border border-auto rounded-xl">Auto border</div>
```

### `.divider-auto`
Adaptive 1px divider line.

**Specs:**
- Height: 1px
- Background: `var(--component-border)`
- Width: Set with utility classes (`.w-full`, `.w-px h-full`)
- Usage: Horizontal and vertical dividers

```jsx
<!-- Horizontal -->
<div className="divider-auto w-full"></div>

<!-- Vertical -->
<div className="divider-auto w-px h-16"></div>
```

## Foreground Overlays

Geometric opacity scale for overlays, badges, and interactive states.

### `.bg-fg`
Solid foreground overlay (100% opacity).

**Specs:**
- Background: Current foreground color
- Light theme: `#1e1e21`
- Dark theme: `#f5f5f5`
- Usage: Pills, solid badges, emphasis elements

```jsx
<span className="bg-fg px-3 py-1 rounded-full">Badge</span>
```

### `.bg-fg-02` through `.bg-fg-64`
Graduated opacity overlays following geometric progression.

**Scale:** 2%, 4%, 8%, 16%, 32%, 64%

**Usage:**
- `.bg-fg-02`: Hairline highlights, subtle overlays
- `.bg-fg-04`: Hover pre-states, light scrims
- `.bg-fg-08`: Icon button backgrounds, subtle pills
- `.bg-fg-16`: Pressed states, filled toggles
- `.bg-fg-32`: Focus rings, emphasis overlays
- `.bg-fg-64`: High-contrast badges, feature banners

```jsx
<button className="bg-fg-08 hover:bg-fg-16 px-4 py-2 rounded">
  Ghost Button
</button>
```

## Border Utilities

### Foreground Borders

#### `.border-fg`
Solid border using foreground color.

**Specs:**
- Border color: Current foreground
- Light theme: `#1e1e21`
- Dark theme: `#f5f5f5`

#### `.border-fg-02` through `.border-fg-64`
Graduated opacity borders matching `.bg-fg-*` scale.

**Usage:** Pair with `.bg-fg-*` utilities at matching opacity levels.

```jsx
<div className="bg-fg-08 border border-fg-08 rounded-lg p-4">
  Matched background and border
</div>
```

### Surface Borders

#### `.border-surface`
Border using surface primary color (opposite of foreground).

**Specs:**
- Border color: `var(--kol-surface-primary)`
- Solves visibility problem for `.bg-fg` elements
- Usage: Borders on accent pills, high-contrast outlines

```jsx
<span className="bg-fg border border-surface px-3 py-1 rounded-full">
  Visible border on dark background
</span>
```

#### `.border-surface-02` through `.border-surface-64`
Graduated surface borders for nuanced outlines.

**Usage:** Provides visible borders on foreground-colored backgrounds.

```jsx
<div className="bg-fg-16 border border-surface-16 rounded-xl p-6">
  Subtle visible border
</div>
```

## State Utilities

Interactive state helpers using relative color mixing.

### Background States

#### `.hover:bg-surface-primary-hover`
5% foreground blend on hover.

#### `.active:bg-surface-primary-active`
10% foreground blend on active/pressed.

#### `.hover:bg-container-primary-hover`
Container hover state (5% blend).

#### `.active:bg-container-primary-active`
Container active state (10% blend).

**Example:**
```jsx
<button className="bg-container-primary hover:bg-container-primary-hover active:bg-container-primary-active">
  Interactive Button
</button>
```

### Border States

#### `.hover:border-hover`
16% opacity border on hover.

#### `.active:border-active`
Accent strong border on active.

#### `.focus-visible:border-focus`
Accent primary border for keyboard focus.

**Example:**
```jsx
<input className="border border-auto hover:border-hover focus-visible:border-focus" />
```

## Component Integration

### React Atom Usage

Most components in `packages/ui/src/atoms/` consume these classes internally. Prefer importing atoms over raw class strings:

```jsx
// Prefer this:
import { Button, SectionHeader } from '@kol/ui'
<Button variant="accent">Click me</Button>

// Over this:
<button className="btn btn-accent text-control">Click me</button>
```

### Adding New Components

When creating new reusable patterns:

1. Define the base classes in `packages/ui/css/components.css`
2. Use semantic tokens (`--kol-*`) for colors and spacing
3. Ensure classes work in both `.surface-inverse` and default contexts
4. Create React wrapper in `packages/ui/src/atoms/` or `molecules/`
5. Export from `packages/ui/src/index.js`
6. Document usage in this file

## Best Practices

### Token Usage
- Always use semantic tokens (`--kol-surface-*`, `--kol-container-*`) over raw primitives
- Test components in both light/dark themes
- Verify components inside `.surface-inverse` contexts

### Composition
- Combine typography classes with layout utilities
- Use data table classes for consistent tabular data
- Layer state utilities for interactive feedback

### Maintenance
- When updating a class, check all consuming atoms
- Keep classes generic and reusable
- Document edge cases and context requirements
