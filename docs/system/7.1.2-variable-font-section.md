## Animation System

### Animation Logic (lines 11-46)

**Algorithm:** Continuously animates weight between 300-900 at ~60fps using requestAnimationFrame

```jsx
useEffect(() => {
  if (!isAnimating) return

  let direction = 1              // 1 = increasing, -1 = decreasing
  let currentWeight = weight
  let lastTime = Date.now()

  const animate = () => {
    const now = Date.now()
    const delta = now - lastTime

    if (delta > 16) {            // ~60fps throttle (16ms)
      currentWeight += direction * 2  // Increment by 2

      if (currentWeight >= 900) {
        currentWeight = 900
        direction = -1           // Reverse direction at max
      } else if (currentWeight <= 300) {
        currentWeight = 300
        direction = 1            // Reverse direction at min
      }

      setWeight(currentWeight)
      lastTime = now
    }

    animationRef.current = requestAnimationFrame(animate)
  }

  animationRef.current = requestAnimationFrame(animate)

  return () => {
    if (animationRef.current) {
      cancelAnimationFrame(animationRef.current)
    }
  }
}, [isAnimating])
```

**Key Features:**
- **Delta time throttling** - Updates only every 16ms (~60fps)
- **Direction reversal** - Bounces between min/max weights
- **Cleanup** - Cancels animation on unmount or when paused
- **Dependency** - Only reruns when `isAnimating` changes

### Manual Control Handler (lines 48-53)

```jsx
const handleSliderChange = (value) => {
  setIsAnimating(false)  // Pause animation when user adjusts
  setWeight(value)       // Set to user's chosen value
}
```

**Behavior:** Moving the slider pauses animation and takes manual control.

## VariableFontDisplay Molecule

### Structure

**Layout:** Absolute positioning for text, relative flex for controls

```jsx
<div className="foundryCard w-full h-[60vh] p-10 relative">
  {/* Background layer - Absolutely positioned */}
  <p className="absolute inset-0 flex items-center justify-center">
    Variable
  </p>

  {/* Controls layer - Relative with z-10 */}
  <div className="relative z-10 h-full flex flex-col justify-between">
    {/* Top controls */}
    {/* Bottom controls */}
  </div>
</div>
```

**Why this pattern:**
- Text stays centered regardless of control layout (Figma "ignore auto layout")
- Controls float on top with `z-10`
- `justify-between` spaces top/bottom controls vertically

### Top Controls

```jsx
<div className="flex justify-between items-start">
  <div className="flex flex-col gap-1">
    <span className="kol-mono-xxs text-fg-32">AXIS:</span>
    <span className="kol-helper-xxs text-auto">WEIGHT</span>
  </div>
  <Pill variant="subtle">--vari {weight}</Pill>
</div>
```

**Components:**
- **Left:** AXIS label (32% opacity) + WEIGHT label (full opacity)
- **Right:** Pill showing current weight value with `--vari` prefix

### Bottom Controls

```jsx
<div className="flex items-center gap-4">
  <PlayPauseButton
    isPlaying={isAnimating}
    onToggle={onToggleAnimation}
  />
  <Slider
    min={minWeight}
    max={maxWeight}
    value={weight}
    onChange={onWeightChange}
    className="w-full"
    variant="minimal"
  />
</div>
```

**Components:**
- **PlayPauseButton:** 28×28px button with pause (❚❚) / play (▶) icons
- **Slider:** Minimal variant (no background/border), full width

## Technical Specifications

### Animation Performance

**Frame rate:** ~60fps (throttled with delta time)
**Weight change per frame:** 2 units
**Full cycle duration:**
- Range: 900 - 300 = 600 units
- Frames: 600 / 2 = 300 frames each direction
- Time at 60fps: 300 / 60 = 5 seconds each direction
- Total cycle: 10 seconds

**Memory usage:**
- Single RAF reference
- Minimal state (3 numbers + 1 boolean)
- No memory leaks (proper cleanup)

### Browser Compatibility

**Required features:**
- `requestAnimationFrame` (all modern browsers)
- CSS `color-mix()` (Chrome 111+, Safari 16.2+, Firefox 113+)
- Variable fonts (all modern browsers)

**Graceful degradation:**
- Animation falls back to no animation if RAF unavailable
- Colors fall back to solid if color-mix unavailable
