# 8.1 Home Structure

**Version:** 1.0
**Last Updated:** 2025-10-30
**Status:** Implementation reference for Home page
**Baseline:** `/apps/web/src/routes/Home.jsx`

> This chapter documents the **Home page structure** as the canonical example of the kolkrabbi design system's layout patterns. For general structural guidelines, see [8.0 Div & Section Structure](./8.0-div-structure.md).

---

## Overview

The Home page demonstrates the **correct structural pattern** for building pages in the kolkrabbi design system:

- Consistent wrapper hierarchy (main → main-wrapper → card-wrapper → section)
- Standardized spacing scales and breakpoints
- Proper surface context usage
- Mobile-first responsive patterns
- Component composition guidelines

---

## Home Page Root Structure

```jsx
<main className="min-h-screen w-full overflow-x-hidden">
  {/* Hero sections without wrapper */}
  <div>
    <HomeHero onVideoStart={onVideoStart} />
    <HomeAbout />
  </div>

  {/* Main content area */}
  <div className="main-wrapper">
    {/* Card-wrapped sections */}
    <div className="card-wrapper">
      <HomeCardFeatures />
    </div>

    <div className="card-wrapper">
      <HomeCardStory />
    </div>

    <div className="">
      <HomeHighlights />
    </div>

    <div className="card-wrapper">
      <HomeFoundry />
    </div>

    <div className="card-wrapper">
      <HomeWorkFeatures />
    </div>

    <div className="card-wrapper">
      <CmsGlobal />
    </div>

    <div className="card-wrapper">
      <HomeSignup />
    </div>
  </div>

  {/* Footer CTA without wrapper */}
  <CtaGlobal />
</main>
```

**Key Patterns:**
- Hero sections (`HomeHero`, `HomeAbout`) outside main-wrapper
- Most sections wrapped in `.card-wrapper` for subtle differentiation
- `HomeHighlights` bento grid without card-wrapper for full control
- `CtaGlobal` footer outside main-wrapper

## Section Types

### 1. Hero Section (Full Viewport)

**Component:** `HomeHero`
**Location:** `/apps/web/src/components/sections/home/HomeHero.jsx`

```jsx
<div className="relative h-dvh w-screen overflow-x-hidden">
  <div id="video-frame" className="relative z-10 h-dvh w-screen bg-surface-inverse">
    <video
      className="absolute inset-0 h-full w-full object-cover"
      autoPlay
      loop
      muted
      playsInline
      src={theme === 'dark' ? '/videos/vid-nrml-inverse.mov' : '/videos/vid-nrml.mov'}
    />

    {/* Text overlay - bottom left */}
    <div className="absolute bottom-0 left-0 p-12">
      <p className="kol-heading-md text-auto">Kolkrabbi Vinnustofa</p>
    </div>

    {/* Logo overlay - top right */}
    <div className="absolute right-8 top-8">
      <TgLogoInline theme={theme} />
    </div>
  </div>
</div>
```

**Characteristics:**
- `h-dvh` = dynamic viewport height (mobile-safe)
- `w-screen` = full viewport width
- `overflow-x-hidden` = prevents horizontal scroll
- `bg-surface-inverse` = theme-aware background
- Absolute positioned overlays
- Video element with `object-cover`

### 3. Feature Grid Section

**Component:** `HomeCardFeatures`
**Location:** `/apps/web/src/components/sections/home/HomeCardFeatures.jsx`

```jsx
<section className="w-full">
  <div className="w-full flex flex-col gap-8 md:gap-10 max-w-[1200px] mx-auto">
    {/* Header */}
    <div className="w-full pt-[224px]">
      <SectionLabel text="Selected Work" />
      <p className="kol-mono-sm text-auto opacity-60 mt-3 text-[12px] w-[30%]">
        A showcase of our design philosophy and craft
      </p>
    </div>

    {/* Feature Grid */}
    <div className="inline-flex flex-col md:flex-row md:h-72 gap-6">
      {features.map((feature, index) => (
        <CardFeatureItem
          key={index}
          {...feature}
        />
      ))}
    </div>

    {/* Actions */}
    <ButtonGroup
      buttons={[
        { text: 'View All Work', href: '/work' },
        { text: 'About Process', href: '/about' }
      ]}
      align="center"
      className="pt-10 pb-4"
    />
  </div>
</section>
```

**Pattern Breakdown:**
1. **Section wrapper:** `w-full` for full parent width
2. **Content container:** `max-w-[1200px] mx-auto` for centering
3. **Header area:** Large top padding (`pt-[224px]`) creates breathing room
4. **Grid area:** Responsive flex layout (`flex-col md:flex-row`)
5. **Actions area:** ButtonGroup with centered alignment

**Responsive Behavior:**
- Mobile: Vertical stack of features
- Tablet+: Horizontal row with fixed height (`md:h-72`)
- Gap scales from 32px → 40px (`gap-8 md:gap-10`)

### 4. Bento Grid Section

**Component:** `HomeHighlights`
**Location:** `/apps/web/src/components/sections/home/HomeHighlights.jsx`

```jsx
<section id="work" className="w-full">
  <div className="w-full max-w-[1200px] mx-auto flex flex-col gap-8">
    {/* Row 1: Full-width card */}
    <div className="self-stretch h-[640px] rounded inline-flex">
      <BentoCard
        className="flex-1"
        image="/img/work/project-a.jpg"
        title="Project A"
        category="Brand Identity"
      />
    </div>

    {/* Row 2: Full-width card */}
    <div className="self-stretch h-[640px] rounded inline-flex">
      <BentoCard
        className="flex-1"
        image="/img/work/project-b.jpg"
        title="Project B"
        category="Web Design"
      />
    </div>

    {/* Row 3: 1 large + 2 stacked */}
    <div className="self-stretch h-[640px] inline-flex gap-8">
      {/* Left: Large card */}
      <BentoCard
        className="flex-1"
        image="/img/work/project-c.jpg"
        title="Project C"
        category="Typography"
      />

      {/* Right: Stacked cards */}
      <div className="flex-1 inline-flex flex-col gap-6">
        <BentoCard
          className="self-stretch flex-1"
          image="/img/work/project-d.jpg"
          title="Project D"
          category="Packaging"
        />
        <BentoCard
          className="self-stretch flex-1"
          image="/img/work/project-e.jpg"
          title="Project E"
          category="Editorial"
        />
      </div>
    </div>
  </div>
</section>
```

**Pattern Details:**
- **Fixed row height:** All rows use `h-[640px]`
- **Self-stretch:** Cards fill parent width
- **Flex-1:** Equal-width distribution
- **Nested containers:** Right column uses nested flex for stacking
- **Gap-8:** 32px between rows
- **Gap-6:** 24px between nested stacked cards

**Why No card-wrapper:**
Bento grids need precise control over spacing and backgrounds. The card-wrapper's padding and border would interfere with the full-bleed aesthetic.

### 7. Blog Grid Section

**Component:** `CmsGlobal`
**Location:** `/apps/web/src/components/sections/blog/CmsGlobal.jsx`

```jsx
<section className="w-full">
  <div className="max-w-[1200px] mx-auto flex flex-col gap-12">
    {/* Header */}
    <div className="flex flex-col gap-3">
      <SectionLabel text="Latest Writing" />
      <h2 className="kol-heading-lg">From the Studio</h2>
    </div>

    {/* Mobile/Tablet: Mini cards */}
    <div className="flex flex-col gap-8 lg:hidden">
      {articles.map((article, index) => (
        <ArticleCardMini
          key={index}
          title={article.title}
          excerpt={article.excerpt}
          date={article.date}
          category={article.category}
          href={article.href}
        />
      ))}
    </div>

    {/* Desktop: Hero cards in grid */}
    <div className="hidden lg:grid gap-12 lg:grid-cols-3">
      {articles.map((article, index) => (
        <ArticleCardHero
          key={index}
          image={article.image}
          title={article.title}
          excerpt={article.excerpt}
          date={article.date}
          category={article.category}
          href={article.href}
        />
      ))}
    </div>
  </div>
</section>
```

**Pattern Details:**
- **Conditional rendering:** Different components per breakpoint
- **Mobile/Tablet:** `ArticleCardMini` in vertical stack (`gap-8`)
- **Desktop:** `ArticleCardHero` in 3-column grid (`lg:grid-cols-3`)
- **Gap-12:** 48px spacing (larger for visual articles)

## Content Container Patterns

### Pattern 1: Centered Content with Top Padding

```jsx
<div className="w-full flex flex-col gap-8 md:gap-10 max-w-[1200px] mx-auto">
  <div className="w-full pt-[224px]">
    <SectionLabel text="Selected Work" />

  </div>
  {/* Additional content */}
</div>
```

**Used by:** `HomeCardFeatures`

**Characteristics:**
- `pt-[224px]` = large top spacing for visual breathing room
- `gap-8 md:gap-10` = responsive gap scaling
- Constrains to 1200px max width

### Pattern 2: Padding-Based Spacing

```jsx
<div className="w-full flex flex-col max-w-[1200px] mx-auto pt-24">
  {/* Content */}
</div>
```

**Used by:** `HomeWorkFeatures`

**Characteristics:**
- `pt-24` = 96px top padding (6rem)
- Simpler spacing approach

### Pattern 3: Two-Column Layout

```jsx
<div className="max-w-[1200px] mx-auto">
  <div className="flex flex-col py-16 lg:flex-row gap-16">
    {/* Left: Fixed width image */}
    <div className="w-full lg:w-[400px] flex-shrink-0">
      <TiltCard src="/img/..." className="w-full aspect-[4/5]" />

    {/* Right: Flexible content */}
```

- `lg:w-[400px]` = fixed image column width
- `flex-1` = content expands to fill remaining space

## Baseline Settings

### Root Container
```jsx
<main className="min-h-screen w-full overflow-x-hidden">
```

### Section Wrapper Classes
- **Main wrapper:** `.main-wrapper` (p-8, flex flex-col, gap-8)
- **Card wrapper:** `.card-wrapper` (p-8, rounded, subtle bg)
- **No wrapper:** Hero sections, bento grids, footer CTA

### Default Section Structure
```jsx
<section className="w-full">
  <div className="max-w-[1200px] mx-auto flex flex-col gap-8">
```

### Content Max Width
- **Standard:** `max-w-[1200px]` (1200px)
- **Text content:** `max-w-[64rem]` (1024px)
- **Description text:** `w-[30%]` or `w-[60%]` (relative to parent)

### Default Breakpoints Used
- **md (768px):** Column grids, gap scaling, flex direction
- **lg (1024px):** Major layout changes, component variants

### Surface Contexts
- **Primary:** Default background
- **Inverse:** Hero sections (`HomeHero`), theme-flipped areas
- **Auto:** Text that adapts to parent context

### Standard Spacing Values
- **Section gap:** `gap-8` (32px) → `md:gap-10` (40px)
- **Section padding:** `p-8` (32px)
- **Vertical padding:** `py-16` (64px), `py-24` (96px)
- **Hero spacing:** `pt-[224px]` (224px), `mt-36` (144px)
