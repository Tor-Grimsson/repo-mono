# Font Viewer Extraction Component

**Component**: `apps/web/src/components/fontviewer/Extraction.jsx`

## Purpose
Lightweight specimen renderer that loads a font, renders an arbitrary glyph, and overlays the key typographic metrics (baseline, ascender, descender, cap height, x-height, side bearings) without any scrapbook styling. Designed to be composed inside higher-level viewers (static cards, pan-able inspection surfaces, etc.).

## Behavior
- Loads a font asynchronously via `FontLoader` and renders the provided glyph (defaults to `æ`).
- Computes metric positions from the font’s `os/2` + `hhea` tables and the actual rendered glyph size.
- Renders thin horizontal guides with labels for each vertical metric and optional vertical lines for left/right bearings.
- Provides boolean props (`showBaseline`, `showAscender`, `showDescender`, `showCapHeight`, `showXHeight`, `showBearings`) to toggle each guide/label independently.
- `glyph` prop updates the displayed glyph on the fly; `disableSelection` (default `true`) prevents text selection for cleaner interaction.
- Outputs no background/border—parent containers own layout. All guides are inside an absolute overlay so padding/positioning in parent containers does not affect metric alignment.

## Props
| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `fontUrl` | `string` | default variable font asset | Optional font source override |
| `glyph` | `string` | `'æ'` | Specimen glyph/string |
| `height` | `number` | `628` | Viewport height in px |
| `className` | `string` | `''` | Passed through to wrapper div |
| `showBaseline` | `boolean` | `true` | Toggle baseline guide + label |
| `showAscender` | `boolean` | `true` | Toggle ascender guide + label |
| `showDescender` | `boolean` | `true` | Toggle descender guide + label |
| `showCapHeight` | `boolean` | `true` | Toggle cap height guide + label |
| `showXHeight` | `boolean` | `true` | Toggle x-height guide + label |
| `showBearings` | `boolean` | `true` | Toggle side bearing guides + labels |
| `disableSelection` | `boolean` | `true` | Prevent text selection on legends/wrapper |

## Integrations
- **PanableExtraction** (`apps/web/src/components/fontviewer/PanableExtraction.jsx`): wraps `Extraction` in an overscanned draggable stage with inertial motion (labels off by default, enable via props). The inner component is rendered with `pointer-events: none` so the container owns all interaction.
- **Demo page** (`apps/web/src/routes/Demo.jsx`): showcases both the pan-able and static versions side-by-side for comparison.

## Notes
- Metric lines recompute whenever font data, glyph, or visibility props change. Bearings derive from glyph metrics (advance width + side bearings) so they remain aligned regardless of parent padding.
- No dependency on `FontInfoRenderer` or `MetricsOverlay`; logic is self-contained for reuse in web or tooling contexts.
- Keep `disableSelection` true when using the component inside interactive surfaces to avoid accidental text highlights while dragging.
