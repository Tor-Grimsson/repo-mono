# Prose Code Block Component - DEPRECATED

## ⚠️ Outdated Documentation

This document describes the **OLD** CodeBlock system which has been **COMPLETELY REPLACED**.

## What Changed?

The old CodeBlock system has been **completely refactored** and **deleted**. See the new documentation:

- **[SimpleCodeBlock - New System](./7.3.6-prose-simple-codeblock.md)**

## Old System (Deleted)

The previous CodeBlock implementation had multiple problems:

1. **Complex CSS conflicts** between `blog.css`, `prose.css`, and `utilities.css`
2. **Broken copy button positioning** that required complex calculations
3. **Multiple CodeBlock components** across the codebase
4. **CSS specificity issues** with variant-specific overrides

### What Was Deleted

- ❌ `/packages/ui/src/atoms/CodeBlock.jsx` - **DELETED**
- ❌ `/packages/ui/src/atoms/CopyButton.jsx` - **DELETED**
- ❌ `/apps/web/src/components/prose/blocks/CodeBlock.jsx` - **DELETED**
- ❌ `/apps/web/src/components/portable-text/CodeBlock.jsx` - **DELETED**
- ❌ Old CSS classes: `.code-block`, `.copy-button`, `.code-block-wrapper`

### Old CSS (Removed)

All CSS for the old system was removed from:
- `/packages/ui/css/prose.css`
- `/packages/ui/css/utilities.css`
- `/packages/ui/css/blog.css`

## New System (Active)

### Components Created

1. **`SimpleCodeBlockDefault.jsx`** - For `.kol-prose` (default, 65ch)
   - Font-size: 14px, padding: 20px, line-height: 1.5

2. **`SimpleCodeBlockWide.jsx`** - For `.kol-prose-wide` (90ch)
   - Font-size: 14px, padding: 24px, line-height: 1.6

3. **`SimpleCodeBlockCompact.jsx`** - For `.kol-prose-compact` (45ch)
   - Font-size: 12px, padding: 14px, line-height: 1.4

### Key Features

✅ **Unique class names** - All use `simple-` prefix (no conflicts)
✅ **Self-contained** - Copy button inside content container
✅ **Simple CSS** - All in `prose.css` (lines 867-1081)
✅ **Material Design interactions** - Stroke reveal animation
✅ **No background on code text** - Only container has background
✅ **Proper variant integration** - Each prose variant has its own component

### Integration

**PortableTextBlog.jsx** now exports 3 component sets:

```javascript
export const portableTextBlogComponents = {
  types: { code: SimpleCodeBlockDefault },
  // ...
}

export const portableTextBlogWideComponents = {
  types: { code: SimpleCodeBlockWide },
  // ...
}

export const portableTextBlogCompactComponents = {
  types: { code: SimpleCodeBlockCompact },
  // ...
}
```

### Usage in StackArticle

**Single Column** (wide prose):
```jsx
<div className="kol-prose-wide">
  <PortableText
    components={portableTextBlogWideComponents}  // Uses SimpleCodeBlockWide
  />
</div>
```

**Two Column** (default prose):
```jsx
<div className="kol-prose">
  <PortableText
    components={portableTextBlogComponents}  // Uses SimpleCodeBlockDefault
  />
</div>
```

## Benefits of New System

1. **Simplicity** - No complex CSS calculations
2. **Maintainability** - One component per variant
3. **No conflicts** - Unique class names
4. **Focused** - Each component designed for specific variant
5. **Clean interactions** - Material Design patterns

## Migration Guide

If you were using the old CodeBlock system:

**OLD**:
```jsx
import { CodeBlock } from '@kol/ui';
<CodeBlock code={code} variant="wide" />
```

**NEW** (Wide prose):
```jsx
import { portableTextBlogWideComponents } from '../components/prose/core/PortableTextBlog'
<PortableText
  value={content}
  components={portableTextBlogWideComponents}
/>
```
