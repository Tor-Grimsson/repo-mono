## Overview

The Stack article rendering system handles the display of blog posts and rich text content from Sanity CMS. It integrates Portable Text rendering with the kolkrabbi prose typography system to create beautiful, readable articles with syntax highlighting, images, quotes, and references.

### Current State (Pre-Migration)

**Location:** `apps/web/src/components/sections/stack-detail/RichTextStack.jsx`
**Status:** Active but needs refactoring
**Issues:**
- Uses deprecated tokens from blog.css
- Inline `color-mix()` calls instead of utilities
- Mixed layout and content rendering concerns
- Non-compliant with div-structure guidelines

### Target State (Post-Migration)

**New Location:** `apps/web/src/components/prose/layouts/ArticleLayout.jsx`
**Improvements:**
- Full token compliance (`--kol-*` system)
- Utility classes for all colors
- Separated layout from content rendering
- div-structure compliant
- Reusable ProseRenderer component

## Architecture

### Component Hierarchy

```
ArticleLayout.jsx                  (Full page layout)
├── ArticleHeader.jsx              (Header section)
│   ├── ArticleMeta                (Tags, date, author)
│   ├── ArticleTitle               (h1 heading)
│   └── ArticleHeroImage           (Cover image)
├── ProseRenderer.jsx              (Prose wrapper)
│   └── PortableText               (Sanity content)
│       ├── CodeBlock              (Syntax highlighted code)
│       ├── ImageBlock             (Images with captions)
│       ├── QuoteBlock             (Blockquotes)
│       └── ... (other blocks)
├── SourcesList.jsx                (References/bibliography)
└── ArticleFooter.jsx              (Footer with tags)
```

### Data Flow

```
Sanity CMS → GraphQL → StackDetail Route → ArticleLayout → PortableText → Blocks
```

## Component APIs

### ArticleLayout

**Location:** `apps/web/src/components/prose/layouts/ArticleLayout.jsx`

```jsx
import ArticleLayout from '@/components/prose/layouts/ArticleLayout'

export default function BlogPost() {
  return <ArticleLayout post={postData} />
}
```

**Props:**

```typescript
interface ArticleLayoutProps {
  post: {
    title: string                    // Article title
    excerpt?: string                 // Optional summary/lead
    publishedAt: string              // ISO date string
    tags?: string[]                  // Category tags
    coverImage?: {
      url: string
      alt?: string
    }
    author?: {
      name: string
      image?: { url: string }
    }
    body: PortableTextBlock[]        // Sanity content
    sources?: Array<{
      title: string
      url: string
      meta?: string
    }>
  }
}
```

**Layout Structure:**

```jsx
<section className="w-full">
  <div className="max-w-[1200px] mx-auto flex flex-col gap-8 py-16">

    {/* Header */}
    <header className="flex flex-col gap-6">
      {/* Tags */}
      {/* Title */}
      {/* Author & Meta */}
      {/* Excerpt */}
      {/* Cover Image */}
    </header>

    {/* Content */}
    <ProseRenderer variant="default">
      <PortableText value={post.body} components={portableTextComponents} />
    </ProseRenderer>

    {/* Sources */}
    {post.sources && <SourcesList sources={post.sources} />}

    {/* Footer */}
    <footer className="flex gap-2 flex-wrap border-t border-auto pt-8">
      {/* Tags */}
    </footer>

  </div>
</section>
```

## Article Header

### Tags

Uses `Pill` component with `variant="inverse"`:

```jsx
import { Pill } from '@kol/ui'

{tags?.length > 0 && (
  <div className="flex gap-2 flex-wrap">
    {tags.map((tag, i) => (
      <Pill key={i} variant="inverse" size="sm">
        {tag}
      </Pill>
    ))}
  </div>
)}
```

**Visual:** Inverse pills (light on dark in light mode, dark on light in dark mode)

### Title

Uses `.kol-heading-display` (or deprecated `.kol-heading-display` → migrate to `.kol-display-lg`):

```jsx
<h1 className="kol-display-lg mb-6">
  {post.title}
</h1>
```

**Typography:**
- Font: Right Grotesk Tight, 500 weight
- Size: `48px → 96px` (responsive clamp)
- Line height: 100%
- Transform: Uppercase

### Author & Meta

```jsx
<div className="flex items-center gap-4">
  {author && (
    <div className="flex items-center gap-3">
      {author.image?.url && (
        <img
          src={author.image.url}
          alt={author.name}
          className="w-12 h-12 rounded-full object-cover"
        />
      )}
      <div className="flex flex-col gap-1">
        <p className="kol-mono-sm font-medium">{author.name}</p>
        <p className="kol-text-sm text-fg-64">{formattedDate}</p>
      </div>
    </div>
  )}
  {readingTime && (
    <span className="kol-text-sm text-fg-64">• {readingTime}</span>
  )}
</div>
```

**Color utilities:**
- `.text-fg-64` - 64% foreground opacity for secondary text
- Replaces old: `style={{ color: 'color-mix(...)' }}`

### Excerpt

Lead paragraph with muted color:

```jsx
{excerpt && (
  <p className="kol-text-lg text-fg-64">
    {excerpt}
  </p>
)}
```

### Cover Image

Hero image with border and background:

```jsx
{coverImage && (
  <div className="rounded-lg overflow-hidden bg-surface-secondary border border-auto">
    <img
      src={coverImage.url}
      alt={coverImage.alt || post.title}
      className="w-full h-auto object-cover"
      style={{ maxHeight: '600px' }}
      loading="eager"  // Hero image loads immediately
    />
  </div>
)}
```

**Replaced:** `--kol-color-neutral-200` (undefined) → `.bg-surface-secondary`

## Portable Text Integration

### Configuration

**Location:** `apps/web/src/components/prose/core/PortableTextBlog.jsx`

```jsx
import { PortableText } from '@portabletext/react'
import CodeBlock from '../blocks/CodeBlock'
import ImageBlock from '../blocks/ImageBlock'
import QuoteBlock from '../blocks/QuoteBlock'

export const portableTextBlogComponents = {
  types: {
    code: CodeBlock,
    image: ImageBlock,
  },
  marks: {
    link: ({ value, children }) => {
      const target = (value?.href || '').startsWith('http') ? '_blank' : undefined
      return (
        <a
          href={value?.href}
          target={target}
          rel={target === '_blank' ? 'noopener noreferrer' : undefined}
        >
          {children}
        </a>
      )
    },
  },
  block: {
    normal: ({ children }) => <p>{children}</p>,
    h2: ({ children }) => <h2>{children}</h2>,
    h3: ({ children }) => <h3>{children}</h3>,
    h4: ({ children }) => <h4>{children}</h4>,
    blockquote: QuoteBlock,
  },
  list: {
    bullet: ({ children }) => <ul>{children}</ul>,
    number: ({ children }) => <ol>{children}</ol>,
  },
  listItem: {
    bullet: ({ children }) => <li>{children}</li>,
    number: ({ children }) => <li>{children}</li>,
  },
}
```

### Styling Inheritance

All Portable Text output is wrapped in `.kol-prose`, which automatically styles:
- `<h2>`, `<h3>`, `<h4>` - Section headings
- `<p>` - Body paragraphs
- `<ul>`, `<ol>`, `<li>` - Lists
- `<blockquote>` - Quotes
- `<a>` - Links

**No additional styling needed** - the prose.css handles everything.

## Content Blocks

### CodeBlock

**Location:** `apps/web/src/components/prose/blocks/CodeBlock.jsx`

Renders syntax-highlighted code using `react-syntax-highlighter`:

```jsx
import { Prism as SyntaxHighlighter } from 'react-syntax-highlighter'
import { oneDark } from 'react-syntax-highlighter/dist/esm/styles/prism'

export default function CodeBlock({ value }) {
  const { language, code, filename } = value

  return (
    <div className="code-block-wrapper">
      {filename && (
        <div className="code-filename kol-mono-xs text-fg-64 uppercase">
          {filename}
        </div>
      )}
      <div className="code-block bg-surface-tertiary rounded-lg p-4">
        <SyntaxHighlighter
          language={language || 'text'}
          style={customStyle}
          customStyle={{
            margin: 0,
            padding: 0,
            background: 'transparent',
          }}
        >
          {code}
        </SyntaxHighlighter>
      </div>
    </div>
  )
}
```

**Styling:**
- Background: `var(--kol-surface-tertiary)` (elevated surface)
- Font: `var(--kol-font-family-mono)`
- Theme-aware: Adapts to light/dark mode

### ImageBlock

**Location:** `apps/web/src/components/prose/blocks/ImageBlock.jsx`

Renders images with optional labels and captions:

```jsx
export default function ImageBlock({ value }) {
  const { asset, alt, label, caption } = value
  if (!asset) return null

  return (
    <figure className="kol-prose-figure my-8">
      {label && (
        <div className="kol-caption-label kol-helper-xs uppercase text-fg-48 mb-2">
          {label}
        </div>
      )}
      <img
        src={asset.url}
        alt={alt || ''}
        loading="lazy"
        className="w-full h-auto rounded-lg"
      />
      {caption && (
        <figcaption className="kol-caption-text kol-mono-sm-fine text-fg-64 mt-2">
          {caption}
        </figcaption>
      )}
    </figure>
  )
}
```

**Accessibility:**
- Semantic `<figure>` and `<figcaption>` elements
- Alt text required
- Lazy loading for performance

### QuoteBlock

Simple blockquote wrapper (can be extended):

```jsx
export default function QuoteBlock({ children }) {
  return <blockquote>{children}</blockquote>
}
```

**Styling:** Handled by `.kol-prose blockquote` in prose.css

## Sources & References

**Location:** `apps/web/src/components/prose/blocks/SourcesList.jsx`

Renders bibliography/references section:

```jsx
export default function SourcesList({ sources }) {
  if (!sources || sources.length === 0) return null

  return (
    <section className="sources-section border-t border-auto pt-8 mt-12">
      <h3 className="kol-heading-sm mb-4">Sources & References</h3>
      <ul className="sources-list space-y-2">
        {sources.map((source, i) => (
          <li key={i} className="kol-mono-sm">
            <a
              href={source.url}
              target="_blank"
              rel="noopener noreferrer"
              className="text-accent-primary hover:text-accent-primary-strong"
            >
              {source.title}
            </a>
            {source.meta && (
              <span className="text-fg-64 ml-2">— {source.meta}</span>
            )}
          </li>
        ))}
      </ul>
    </section>
  )
}
```

**Data structure:**
```typescript
interface Source {
  title: string    // "Design Systems, 2nd Edition"
  url: string      // "https://example.com"
  meta?: string    // "Alla Kholmatova, 2024"
}
```

## Performance Considerations

### Image Loading

```jsx
// Hero/cover image - load immediately
<img src={coverImage} loading="eager" />

// Content images - lazy load
<img src={contentImage} loading="lazy" />
```

### Code Splitting

Syntax highlighter is heavy (~150kb). Consider dynamic import:

```jsx
import dynamic from 'next/dynamic'

const CodeBlock = dynamic(() => import('./blocks/CodeBlock'), {
  loading: () => <div className="kol-mono-sm">Loading code...</div>,
  ssr: true
})
```

### Font Loading

Prose uses three font families - ensure they're preloaded:

```html
<link rel="preload" href="/fonts/RightGrotesk-Tight.woff2" as="font" />
<link rel="preload" href="/fonts/RightGrotesk-Narrow.woff2" as="font" />
<link rel="preload" href="/fonts/InterTight.woff2" as="font" />
<link rel="preload" href="/fonts/RightGrotesk-Mono.woff2" as="font" />
```

## Common Issues & Troubleshooting

### Images not loading

**Issue:** Sanity image URLs may need transformation
**Fix:** Use `@sanity/image-url` helper:

```jsx
import imageUrlBuilder from '@sanity/image-url'

const builder = imageUrlBuilder(sanityClient)

function urlFor(source) {
  return builder.image(source)
}

// Usage
<img src={urlFor(coverImage).width(1200).url()} />
```

### Code blocks not syntax highlighting

**Issue:** Language not recognized
**Fix:** Verify Sanity code block has `language` field:

```javascript
{
  name: 'code',
  type: 'code',
  options: {
    language: 'javascript',
    languageAlternatives: [
      { title: 'JavaScript', value: 'javascript' },
      { title: 'TypeScript', value: 'typescript' },
      { title: 'CSS', value: 'css' },
      { title: 'HTML', value: 'html' }
    ]
  }
}
```

### Blockquotes not styled

**Issue:** Portable Text may not be wrapped in `.kol-prose`
**Fix:** Ensure ProseRenderer wraps the PortableText:

```jsx
<ProseRenderer variant="default">
  <PortableText value={body} components={portableTextComponents} />
</ProseRenderer>
```

### Spacing issues

**Issue:** Inconsistent gaps between sections
**Fix:** Use system gap values consistently:

```jsx
<div className="flex flex-col gap-8">  {/* Not gap-6 or gap-10 */}
  <header />
  <article />
  <footer />
</div>
```
