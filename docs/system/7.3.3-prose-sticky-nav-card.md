# Prose StickyNavCard Component

**Component Type:** Molecule
**Location:** `packages/ui/src/molecules/StyleguideStickyCard.jsx`
**Related:** [CodeBlock](7.3.1-prose-code-block.md), [Blockquote](3.3-prose-text.md)

## Overview

StickyNavCard is a versatile navigation card component designed for the Prose styleguide system. It provides two distinct variants: an expanded version for initial display and a collapsed version for post-sticky navigation states.

## Component Structure

### Expanded Variant

Full-featured card with heading, description body, and bullet points for detailed navigation.

**Element:** `<article>`
**Layout:** Vertical flex with space-y-3
**Content:**
- Header row: Heading (left) + Index number (right)
- Optional body paragraph
- Optional bullet list

### Collapsed Variant

Minimal card showing only essential navigation elements after scroll threshold.

**Element:** `<article>`
**Layout:** Horizontal flex (justify-between)
**Content:**
- Header row: Heading (left) + Index number (right)
- No body or bullets

## Variants

### Default/Expanded

```jsx
<StickyNavCard
  heading="Typography Foundations"
  body="Understanding the core principles of type systems and vertical rhythm"
  bullets={[
    "Baseline grid alignment",
    "Harmonic scale progression"
  ]}
  index={0}
  isActive={false}
/>
```

**Use case:** Initial display in navigation sidebar or content overview sections.

### Collapsed

```jsx
<StickyNavCard
  heading="Typography Foundations"
  index={0}
  variant="collapsed"
/>
```

**Use case:** Post-sticky navigation state, compact navigation in tight spaces, or when space is limited.

## Props API

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `heading` | string | **Required** | Card title/heading text |
| `body` | string | `undefined` | Descriptive text body (expanded only) |
| `bullets` | array | `[]` | Bullet point items (expanded only) |
| `index` | number | **Required** | Zero-based index for numbering |
| `isActive` | boolean | `false` | Visual active state (expanded only) |
| `variant` | string | `'default'` | `'default'` or `'collapsed'` |

## Typography Classes

### Heading
- **Class:** `kol-helper-md uppercase`
- **Font:** Helper medium (monospace)
- **Case:** Uppercase
- **Color:**
  - Expanded inactive: `text-fg-48` (48% opacity)
  - Expanded active: `text-auto` (automatic)
  - Collapsed: `text-fg-48` (48% opacity)

### Index Number
- **Class:** `kol-mono-xs uppercase`
- **Font:** Mono extra-small
- **Case:** Uppercase
- **Format:** `#01`, `#02`, etc.
- **Color:**
  - Expanded inactive: `text-fg-48` (48% opacity)
  - Expanded active: `text-fg-80` (80% opacity)
  - Collapsed: `text-fg-48` (48% opacity)

### Body Text
- **Class:** `kol-mono-sm-fine`
- **Font:** Mono small fine
- **Color:**
  - Active: `text-fg-64` (64% opacity)
  - Inactive: `text-fg-32` (32% opacity)

### Bullet Points
- **Class:** `kol-mono-xs`
- **Font:** Mono extra-small
- **Color:** `text-fg-64` (64% opacity)
- **Marker:** `•` bullet

## Layout Patterns

### Expanded Structure
```jsx
<article className="space-y-3 rounded border p-6">
  <div className="flex items-start justify-between gap-3">
    <h3>{heading}</h3>
    <span>#{index + 1}</span>
  </div>
  {body && <p>{body}</p>}
  {bullets && <ul>{bullets}</ul>}
</article>
```

### Collapsed Structure
```jsx
<article className="rounded border border-fg-08 p-6">
  <div className="flex items-start justify-between gap-3">
    <h3 className="kol-helper-md uppercase text-fg-48">{heading}</h3>
    <span className="kol-mono-xs uppercase text-fg-48">#{index + 1}</span>
  </div>
</article>
```

## Implementation Notes

1. **Same Pattern:** Collapsed variant follows identical structure to expanded, just omits body/bullets
2. **Index Formatting:** Uses zero-based index, displays as `#01`, `#02`, etc.
3. **Element Type:** Both variants use `<article>` for semantic HTML
4. **Color Consistency:** All color tokens match design system opacity scale
5. **Typography Hierarchy:** Headings use helper font, index uses mono font

## Design Rationale

The StickyNavCard component implements a dual-state pattern commonly used in sticky navigation systems:

1. **Expanded State:** Provides full context for initial navigation
2. **Collapsed State:** Maintains visual continuity while saving space

This pattern allows the same component to adapt to different scroll positions without requiring multiple components or complex state management.
