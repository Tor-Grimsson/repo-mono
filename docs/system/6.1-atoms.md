# Atoms - Basic Building Blocks

Atoms are the fundamental UI components that cannot be broken down further. They form the foundation of the Kolkrabbi design system.

## Button Components

### Button
**File**: `packages/ui/src/atoms/Button.jsx`

Primary button component for all main actions.

**Props**:
- `variant`: 'primary' | 'secondary' | 'outline' | 'ghost' (default: 'primary')
- `size`: 'sm' | 'md' | 'lg' (default: 'md')
- `disabled`: boolean (default: false)
- `fullWidth`: boolean (default: false)
- `onClick`: function
- `children`: ReactNode
- `className`: string

**Usage**:
```javascript
<Button variant="primary" size="md" onClick={handleClick}>
  Click me
</Button>
```

**Variants**:
- `primary`: Filled background, primary color
- `secondary`: Filled background, secondary color
- `outline`: Transparent background, border
- `ghost`: No background, text only

**Sizes**:
- `sm`: padding, font-size
- `md`: padding, font-size
- `lg`: padding, font-size

### ButtonFixed
**File**: `packages/ui/src/atoms/ButtonFixed.jsx`

Fixed-position button that stays in place during scroll.

**Props**:
- `variant`: Same as Button
- `size`: Same as Button
- `position`: 'top-right' | 'bottom-right' | 'top-left' | 'bottom-left' (default: 'bottom-right')
- `onClick`: function
- `children`: ReactNode

**Usage**:
```javascript
<ButtonFixed position="bottom-right" onClick={scrollToTop}>
  ↑
</ButtonFixed>
```

### ButtonNav
**File**: `packages/ui/src/atoms/ButtonNav.jsx`

Navigation button with built-in icon and active states.

**Props**:
- `active`: boolean (default: false)
- `onClick`: function
- `href`: string (optional)
- `children`: ReactNode

**Usage**:
```javascript
<ButtonNav active={true} onClick={() => navigate('/home')}>
  Home
</ButtonNav>
```

### ControlButton
**File**: `packages/ui/src/atoms/ControlButton.jsx`

Generic control button for panels and controls.

**Props**:
- `active`: boolean (default: false)
- `onClick`: function
- `disabled`: boolean (default: false)
- `children`: ReactNode

**Usage**:
```javascript
<ControlButton active={isActive} onClick={toggleControl}>
  Play
</ControlButton>
```

## Form Components

### Input
**File**: `packages/ui/src/atoms/Input.jsx`

Text input component with consistent styling.

**Props**:
- `type`: 'text' | 'email' | 'password' | 'search' (default: 'text')
- `value`: string
- `onChange`: function
- `placeholder`: string
- `disabled`: boolean (default: false)
- `error`: boolean (default: false)
- `className`: string

**Usage**:
```javascript
<Input
  type="text"
  value={value}
  onChange={(e) => setValue(e.target.value)}
  placeholder="Enter text..."
/>
```

**Styling**:
- Uses `control-unified` CSS class
- Responsive padding and font sizes
- Error state with color indication

## Slider

### Slider
**File**: `packages/ui/src/atoms/Slider.jsx`

Range slider for selecting values.

**Props**:
- `value`: number
- `onChange`: function
- `min`: number (default: 0)
- `max`: number (default: 100)
- `step`: number (default: 1)
- `disabled`: boolean (default: false)

**Usage**:
```javascript
<Slider
  value={volume}
  onChange={setVolume}
  min={0}
  max={100}
  step={1}
/>
```

**Styling**:
- Custom track and thumb
- Responsive sizing
- Works with keyboard (arrow keys)

## Dropdown Components

### Dropdown
**File**: `packages/ui/src/atoms/Dropdown.jsx`

Single-select dropdown with smooth animations.

**Props**:
- `options`: Array<{label: string, value: any}>
- `value`: any
- `onChange`: function
- `size`: 'sm' | 'md' | 'lg' (default: 'md')
- `className`: string
- `fontSize`: string (optional)

**Usage**:
```javascript
<Dropdown
  options={[
    { label: 'Option 1', value: 'opt1' },
    { label: 'Option 2', value: 'opt2' }
  ]}
  value={selectedValue}
  onChange={setSelectedValue}
/>
```

### DropdownFixed
**File**: `packages/ui/src/atoms/DropdownFixed.jsx`

Fixed-style dropdown with different border radius handling.

**Props**: Same as Dropdown

**Usage**: Same as Dropdown

**Difference**: Uses fixed border radius values instead of CSS variables.

### TagFilterDropdown
**File**: `apps/web/src/components/ui/TagFilterDropdown.jsx`

Multi-select dropdown for filtering tags.

**Props**:
- `options`: Array<{label: string, value: any}>
- `selectedValues`: Set<any>
- `onChange`: function (receives value or null for "deselect all")
- `size`: 'sm' | 'md' | 'lg' (default: 'md')
- `className`: string

**Usage**:
```javascript
<TagFilterDropdown
  options={[
    { label: 'React', value: 'react' },
    { label: 'Vue', value: 'vue' }
  ]}
  selectedValues={selectedTags}
  onChange={handleTagToggle}
/>
```

**Features**:
- Multi-select capability
- "Deselect All" option
- Responsive sizing
- Active state indicators

## Tag and Pill Components

### Tag
**File**: `packages/ui/src/atoms/Tag.jsx`

Simple tag component.

**Props**:
- `variant`: 'default' | 'primary' | 'secondary' (default: 'default')
- `children`: ReactNode
- `className`: string

**Usage**:
```javascript
<Tag variant="primary">New</Tag>
```

### Pill
**File**: `packages/ui/src/atoms/Pill.jsx`

Badge/tag component with variants and responsive sizing.

**Props**:
- `variant`: 'outline' | 'subtle' | 'inverse' (default: 'outline')
- `size`: 'sm' | 'md' | 'lg' | 'responsive' (default: 'responsive')
- `children`: ReactNode
- `className`: string

**Usage**:
```javascript
<Pill variant="inverse" size="responsive">
  Featured
</Pill>
```

**Responsive Behavior**:
- `size="responsive"` automatically scales:
  - Mobile: 12px font
  - Tablet: 14px font
  - Desktop: 16px font

**Variants**:
- `outline`: Border with transparent background
- `subtle`: Filled with opacity
- `inverse`: Filled with inverse colors

## Styling

All atoms use CSS custom properties for theming:
- Colors: `var(--kol-surface-*)`
- Typography: `var(--kol-font-family-*)`
- Spacing: `var(--kol-spacing-*)`
- Borders: `var(--kol-border-*)`
