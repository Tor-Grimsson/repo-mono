**Status:** Active
**Last Updated:** 2025-10-30

Documentation for the image carousel component used in Work Detail pages, built with GSAP for smooth infinite scrolling with drag/throw interactions.

---

## Overview

The ImageCarousel component is a horizontal scrolling carousel that displays project images with momentum-based dragging, infinite looping, and gradient edge fades. Built using GSAP's Draggable and InertiaPlugin for physics-based interactions.

### Key Features

1. **Infinite Loop** - Seamless wrapping as images scroll off-screen
2. **Drag/Throw Interaction** - Users can grab and "throw" to spin the carousel with momentum
3. **Snapping** - Items snap to center position after throw
4. **Navigation Arrows** - Left/right buttons for step-by-step navigation
5. **Gradient Fades** - Edge overlays fade images into background
6. **Responsive** - Adapts item sizes and gradient widths to viewport

## Visual Design

### Layout Specifications

**Container:**
- Height: `80vh` (80% of viewport height)
- Width: `100%` (full viewport width)
- Background: Transparent (images show against page background)
- Overflow: Hidden

**Carousel Items:**
- Aspect Ratio: `3:2` (landscape)
- Width:
  - Mobile: `90vw` (90% of viewport)
  - Desktop (md+): `70vw` (70% of viewport)
- Spacing: `32px` horizontal padding (16px per side via `px-8`)
- Border Radius: `4px` (standard rounded)

**Gradient Overlays:**
- Position: Fixed to left and right edges
- Width:
  - Mobile: `128px` (8rem / w-32)
  - Tablet (md): `192px` (12rem / w-48)
  - Desktop (lg): `256px` (16rem / w-64)
- Color: `#151518` (dark background)
- Gradient: Solid 24px, then fade to transparent
- Z-index: `10` (above carousel items)
- Pointer Events: None (allows dragging through overlays)

### Gradient Implementation

```jsx
{/* Left Gradient Fade */}
<div
  className="absolute left-0 top-0 bottom-0 w-32 md:w-48 lg:w-64 z-10 pointer-events-none"
  style={{
    background: 'linear-gradient(to right, #151518 0%, #151518 24px, #15151800 100%)'
  }}
/>

{/* Right Gradient Fade */}
<div
  className="absolute right-0 top-0 bottom-0 w-32 md:w-48 lg:w-64 z-10 pointer-events-none"
  style={{
    background: 'linear-gradient(to left, #151518 0%, #151518 24px, #15151800 100%)'
  }}
/>
```

**Gradient Breakdown:**
- `#151518 0%` - Solid color at edge
- `#151518 24px` - Remains solid for first 24px
- `#15151800 100%` - Fully transparent at far edge (00 = alpha channel)
- Direction: `to right` (left overlay), `to left` (right overlay)

## Interaction Behavior

### Dragging

**How it works:**
1. User clicks/touches carousel
2. GSAP Draggable enables horizontal drag
3. Carousel items move with cursor/touch
4. On release, momentum continues (inertia)
5. Items snap to nearest center position

**Configuration:**
```jsx
const loop = horizontalLoop(boxes, {
  paused: true,      // No autoplay
  draggable: true,   // Enable drag
  center: true,      // Snap to center
  onChange: (element, index) => {
    setActiveIndex(index)  // Track active item
  }
})
```

### Navigation Buttons

**Left/Right Arrows:**
- Position: Absolute, vertically centered
- Left: `left-8` (32px from edge)
- Right: `right-8` (32px from edge)
- Size: `48×48px` (w-12 h-12)
- Background: `bg-fg-04` (4% opacity)
- Hover: `bg-fg-08` (8% opacity)
- Shape: `rounded-full` (circular)
- Z-index: `20` (above gradients)
- Transition: `200ms` color change

**Click Behavior:**
```jsx
const handleNext = () => {
  loopRef.current?.next({ duration: 0.4, ease: 'power1.inOut' })
}

const handlePrev = () => {
  loopRef.current?.previous({ duration: 0.4, ease: 'power1.inOut' })
}
```

**Icon Implementation:**
```jsx
{/* Left Arrow */}
<svg width="20" height="20" viewBox="0 0 20 20" fill="none">
  <path d="M12 4L6 10L12 16" stroke="currentColor" strokeWidth="2" strokeLinecap="round" strokeLinejoin="round"/>

{/* Right Arrow */}
```

## GSAP Implementation

### horizontalLoop Helper Function

The carousel uses a custom GSAP helper function that creates an infinite horizontal loop with the following features:

**Core Functionality:**
- Calculates total width of all items
- Creates seamless loop by animating xPercent
- Items wrap from end back to start (and vice versa)
- Responsive to window resize

**Key Configuration:**
```javascript
function horizontalLoop(items, config) {
  // config options:
  // - paused: true/false (autoplay)
  // - draggable: true/false (enable drag)
  // - center: true/false (snap to center vs left edge)
  // - speed: number (pixels per second for auto-scroll)
  // - onChange: callback (fires when active item changes)
}
```

**Timeline Methods:**
```javascript
tl.next(vars)       // Advance to next item
tl.previous(vars)   // Go to previous item
tl.toIndex(index)   // Jump to specific index
tl.closestIndex()   // Get current centered item
```

### Draggable Configuration

```javascript
draggable = Draggable.create(proxy, {
  trigger: items[0].parentNode,  // Drag area
  type: 'x',                     // Horizontal only
  inertia: true,                 // Enable momentum
  snap(value) {                  // Snap to nearest item
    // Calculate closest item position
    // Return snapped position
  },
  onPress() {
    // Pause timeline
    // Store initial state
  },
  onDrag: align,                 // Update during drag
  onThrowUpdate: align,          // Update during throw
  onRelease() {
    // Sync to closest item
  }
})[0]
```

**Inertia/Throw Behavior:**
- Physics-based momentum continues after release
- Velocity determines how far it "throws"
- Automatically snaps to nearest item when settling
- Smooth deceleration curve

## Performance Considerations

### GSAP Optimization

- Uses `xPercent` instead of `transform: translateX()` for smoother performance
- Pre-renders timeline for instant startup
- Efficient RAF (RequestAnimationFrame) usage
- Hardware acceleration via transforms

### Image Loading

- Sanity CDN handles optimization automatically
- Progressive loading for large images
- Lazy loading not required (images in viewport)

### Resize Handling

```jsx
window.addEventListener('resize', onResize)

// Cleanup on unmount
return () => {
  loop.kill()
  window.removeEventListener('resize', onResize)
}
```

## Known Issues & Limitations

### Current Limitations

1. **No Keyboard Navigation** - Only mouse/touch and buttons work
2. **Fixed Height** - 80vh may not suit all content needs
3. **Single Aspect Ratio** - All images forced to 3:2 regardless of source
4. **activeIndex Unused** - Tracked but not displayed
5. **No Touch Indicators** - Mobile users may not realize they can drag

### Browser Compatibility

**Requires:**
- Modern browsers with GSAP support
- InertiaPlugin (included in GSAP)
- CSS `aspect-ratio` support (fallback needed for older browsers)
