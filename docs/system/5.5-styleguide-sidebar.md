# Styleguide Sidebar Documentation

The styleguide uses a sophisticated, collapsible sidebar navigation with expandable sections and responsive behavior.

## Layout Structure

**Container Grid:**
```javascript
className={`mx-auto flex w-full flex-col lg:grid ${gridTemplateClass}`}
```

**Two-Column Layout:**
- **Left Column**: Sidebar (aside)
- **Right Column**: Main content (main)

## Sidebar Dimensions

### Expanded State
- **Width**: 260px
- **Grid Column**: `lg:grid-cols-[260px_minmax(0,1fr)]`
- **Logo**: Wordmark (h-6 w-auto)
- **Title**: "Design System" (text-[48px])
- **Navigation**: Full display with labels
- **Theme Toggle**: Full button (ThemeToggleButton)

### Collapsed State
- **Width**: 96px
- **Grid Column**: `lg:grid-cols-[96px_minmax(0,1fr)]`
- **Logo**: Logomark only (h-10 w-10)
- **Title**: Hidden
- **Navigation**: Icons only, circular buttons
- **Theme Toggle**: Compact icon-only button

## Padding & Spacing

### Sidebar Container
```javascript
className={`relative border-0 px-4 py-6 lg:sticky lg:top-0 lg:flex lg:h-screen lg:flex-col lg:border-r border-fg-08 ${asidePadding} lg:py-10`}
```

**Padding:**
- **Mobile/Tablet**: `px-4 py-6`
- **Desktop Expanded**: `lg:px-6 lg:py-10`
- **Desktop Collapsed**: `lg:px-4 lg:py-10`

**Other Spacing:**
- **Nav Gap (Expanded)**: `gap-2` (between nav items)
- **Nav Gap (Collapsed)**: `gap-3` (between icon buttons)
- **Section Gap**: `gap-6` (between header and nav)
- **Divider**: Full width `.divider-auto`

### Content Areas
- **Logo Area**: `gap-4` when collapsed, items-center
- **Nav Items**: `px-4 py-2` for text buttons
- **Dropdown Menu**: `w-60` width, `p-3` padding, `gap-1` between items

## Icons

### Icon Mapping
```javascript
const ICON_MAP = {
  'styleguide-home': 'styleguide',
  foundations: 'foundation',
  components: 'component'
}

const resolveIconName = (route) => {
  if (route.icon) return route.icon
  return ICON_MAP[route.id] ?? 'arrow-downright'
}
```

**Available Icons:**
- `styleguide` - Home/Introduction
- `foundation` - Colors, Typography, Spacing
- `component` - Components (Atoms, Molecules, Organisms)
- `arrow-downright` - Default fallback
- Additional route-specific icons via `route.icon`

**Icon Sizes:**
- Navigation items: 16px
- Theme toggle: 18px
- Sidebar toggle: 16px

**Icon Usage:**
- All nav items have icons
- Expandable groups show +/- indicator (text, not icon)
- Theme toggle uses dual icon swap animation

## State Management

### Local State
```javascript
const [expandedItems, setExpandedItems] = useState(() => {
  const active = findActiveGroup()
  return active ? { [active.id]: true } : {}
})

const [isCollapsed, setIsCollapsed] = useState(false)
```

**State Variables:**
- `expandedItems`: Object mapping group IDs to boolean (expanded/collapsed)
- `isCollapsed`: Boolean for sidebar collapsed state

### State Handlers

**Toggle Group:**
```javascript
const toggleGroup = (id) => {
  setExpandedItems((prev) => ({
    ...prev,
    [id]: !prev[id]
  }))
}
```

**Close Group:**
```javascript
const closeGroup = (id) => {
  setExpandedItems((prev) => ({
    ...prev,
    [id]: false
  }))
}
```

**Toggle Sidebar:**
```javascript
const toggleSidebar = () => {
  setIsCollapsed((prev) => !prev)
  setExpandedItems({})
}
```

**Auto-Expand Active Group:**
```javascript
useEffect(() => {
  const active = findActiveGroup()
  if (active) {
    setExpandedItems((prev) => (prev[active.id] ? prev : { ...prev, [active.id]: true }))
  }
}, [normalizedPath])
```

## Breakpoints

### Desktop (lg: 1024px+)
- **Layout**: Two-column grid
- **Sidebar**: Visible and sticky
- **Navigation**: Full sidebar nav
- **Theme Toggle**: In sidebar bottom

### Mobile/Tablet (< 1024px)
- **Layout**: Single column flex
- **Sidebar**: Hidden
- **Top Bar**: Contains theme toggle and dropdown navigation
- **Dropdown**: Replaces sidebar navigation

**Mobile Navigation:**
```javascript
<div className="lg:hidden px-4 pt-6 sm:px-8">
  <div className="flex items-center justify-between gap-4">
    <ThemeToggleButton variant="compact" />
    <div className="min-w-[200px]">
      <Dropdown options={dropdownOptions} value={currentDropdownValue} />
    </div>
  </div>
</div>
```

**Responsive Classes:**
- `hidden lg:flex` - Hide sidebar nav on mobile
- `lg:hidden` - Show mobile dropdown only on mobile
- `sm:px-8` - Adjust padding on small screens
- `min-w-[200px]` - Ensure dropdown has minimum width

## Dropdown Navigation (Mobile)

### Options Structure
```javascript
const dropdownOptions = [
  // Flattened routes with labels
  // Format: { label: "Section: Page", value: "/styleguide/path" }
]
```

**Current Value Detection:**
```javascript
const currentDropdownValue = useMemo(() => {
  const match = dropdownOptions.find((option) => {
    if (option.value === '/styleguide') {
      return normalizedPath === '/styleguide'
    }
    return normalizedPath === option.value || normalizedPath.startsWith(`${option.value}/`)
  })
  return match ? match.value : '/styleguide'
}, [dropdownOptions, normalizedPath])
```

**Behavior:**
- Matches current path or child paths
- Falls back to `/styleguide` if no match
- Updates on navigation
