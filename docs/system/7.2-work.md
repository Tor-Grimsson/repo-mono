# 7.2 Work Components

## WorkControlsPanel

**Location:** `apps/web/src/components/styleguide/molecules/WorkControlsPanel.jsx`

**Purpose:** Display-only control panel showing the Work page animation controls. Used in styleguide to document the control panel structure.

### Structure

```jsx
<div className="control-panel w-full">
  <div className="flex flex-col gap-4">
    {/* 8 Sliders - single column */}
    <Slider label="Intensity" ... />
    <Slider label="Frequency" ... />
    <Slider label="Breath Time" ... />
    <Slider label="Breath Amp" ... />
    <Slider label="Separation" ... />
    <Slider label="Global Scale" ... />
    <Slider label="Global Time" ... />
    <Slider label="Circles" ... />
  </div>

  {/* Bottom text labels */}
  <div className="flex justify-between kol-mono-xs pt-4">
    <span>Quantize [OFF]</span>
    <span>Snap</span>
    <span>Hide</span>
  </div>
</div>
```

### Layout

- **Outer wrapper:** `control-panel` class with full width
- **Sliders container:** `flex flex-col gap-4` (vertical stacking, 16px gap)
- **Bottom labels:** `flex justify-between` (spread across full width)
  - Left: "Quantize [OFF]"
  - Center: "Snap"
  - Right: "Hide"

### Typography

- **Bottom labels:** `kol-mono-xs` (monospace, extra small)
- **Full opacity:** 100% (no opacity reduction)

### Slider Configuration

All sliders use `variant="minimal"` (no background/border styling)

| Slider | Min | Max | Default Value |
|--------|-----|-----|---------------|
| Intensity | 0 | 100 | 75 |
| Frequency | 0 | 100 | 50 |
| Breath Time | 0 | 100 | 50 |
| Breath Amp | 0 | 100 | 50 |
| Separation | 0 | 100 | 50 |
| Global Scale | 0 | 100 | 75 |
| Global Time | 0 | 100 | 50 |
| Circles | 1 | 20 | 8 |

### Usage

**In Styleguide:**
```jsx
import WorkControlsPanel from './WorkControlsPanel'

<SurfacePreviewGrid>
  <SurfacePreviewGrid.Surface>
    <WorkControlsPanel />
  </SurfacePreviewGrid.Surface>

  <SurfacePreviewGrid.Surface inverse>
    <WorkControlsPanel />
  </SurfacePreviewGrid.Surface>
</SurfacePreviewGrid>
```

### Key Differences from Live Work Page

**WorkControlsPanel (Styleguide):**
- Display-only (no functional state)
- Static values
- Empty onChange handlers
- Single responsive instance

**WorkHeroSection (Live):**
- Fully functional with state management
- Interactive controls
- Real onChange handlers updating animation parameters
- Complex control configuration system

### Related Components

- **Slider atom** (`packages/ui/src/atoms/Slider.jsx`) - Used for all 8 parameter controls
- **WorkHeroSection** (`apps/web/src/components/sections/work/WorkHeroSection.jsx`) - Live implementation with full interactivity

### Design Tokens

- **control-panel class:** Provides border, background, border-radius, padding (defined in CSS)
- **kol-mono-xs:** Monospace typography at extra-small size
- **Slider minimal variant:** Transparent background, no border, inherits surface colors

### Responsive Behavior

Component is naturally responsive:
- Single column layout at all breakpoints
- Sliders stretch to full width
- Bottom labels use justify-between to fill width
- No breakpoint-specific overrides needed

### Notes

- This is a **documentation component only** - not used in production Work page
- Bottom labels are text-only (not clickable buttons)
- "[OFF]" state shown statically - actual Work page has toggle state
- Created for styleguide to show control panel structure without complex state logic
