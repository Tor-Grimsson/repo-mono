# StackHeroTall Component (v7.2.2)

**Status:** Active  
**Last Updated:** 2025-10-30  
**Version:** 7.2.2 – Stack Hero Tall Variant  
**Parent Doc:** [7.2-work.md](./7.2-work.md)

Tall variant of the Stack hero section that reserves additional vertical space so downstream cards can overlap the hero artwork by ~128px without manual padding hacks.

---

## Overview

`StackHeroTall` wraps `StackHero` and exposes the same content props while swapping in a taller container preset:

- Extra bottom padding across breakpoints for controlled overlap
- Minimum height bumped to 90vh so the background image dominates the viewport
- Same background image treatment and typography stack as the base hero
- Built-in dark-to-transparent gradient overlay to keep copy legible against bright artwork
- Center-aligned content wrapper with responsive translate utilities handled at the route level

Use this variant on the Stack landing route when you need the featured article card to peek over the hero.

## Default Layout Preset

```jsx
const StackHeroTall = ({
  containerClassName = 'relative px-8 lg:px-14 pb-32 sm:pb-40 lg:pb-48 xl:pb-56 flex items-end justify-center min-h-[90vh] overflow-hidden',
  contentClassName,
  ...rest
})
```

**Key values**
- `pb-32 sm:pb-40 lg:pb-48 xl:pb-56` → reserves ≥128px for overlapping cards
- `min-h-[90vh]` → keeps the background image full-height
- `overflow-hidden` → ensures the image crop remains clean

You can override `containerClassName` or `contentClassName` when a page needs different spacing, but keep the flex alignment for consistent typography placement. The content block now defaults to centered alignment with a max width of `520px`, ensuring the hero copy remains centered from mobile through desktop.

|------|------|---------|-------|

## Implementing the Overlap

In `Stack.jsx`, pair the hero with responsive negative margins to float the featured article card into the hero by ~128px:

```jsx
<section className="relative bg-surface-primary text-auto">
  <StackHeroTall />
</section>

{latestArticle && (
  <section
    aria-label="Featured article"
    className="relative z-10 px-6 sm:px-8 -mt-48 sm:-mt-56 md:-mt-64 lg:-mt-72 mb-16"
  >
    <div className="max-w-[1200px] mx-auto">
      <div className="bg-surface-primary border border-auto p-6 sm:p-8 rounded">
        <ArticleCardHero article={latestArticle} />
      </div>
    </div>
  </section>
)}
```

**Overlap math**
- `pb-32` (8rem) base padding + `-mt-48` (12rem) offset → 4rem (64px) intrusion beyond the reserved padding, producing ~128px visual overlap.
- Larger breakpoints scale both the padding and negative margin to keep the proportion consistent.

## Customising the Stack Hero

1. **Increase/decrease overlap**  
   Adjust the negative margin scale (`-mt-*`) while keeping the padding in sync. Maintain at least `-mt-32` to avoid visual separation lines.

2. **Swap background imagery**  
   Pass a new `src` and optional `objectPosition` to refine the crop:
   ```jsx
   <StackHeroTall
     src="/img/stack/custom-hero.png"
     objectPosition="center"
   />
   ```

3. **Shift copy placement**  
   Override `contentClassName` if the layout needs different width alignment. Example:
   ```jsx
   <StackHeroTall contentClassName="relative z-10 flex-col gap-2 max-w-lg text-left" />
   ```

Keep changes documented here and in `docs/SESSION-LOGS/` if you alter defaults so future agents understand the tuned values.
