## Font System Architecture

### Right Grotesk Family
All Right Grotesk variants now share a unified `font-family: 'RightGrotesk'` name, differentiated by `font-stretch` and `font-weight` properties.

**Available Widths:**
- **Narrow**: `font-stretch: condensed`, `font-weight: 500`
- **Tight**: `font-stretch: extra-condensed`, `font-weight: 500`

**Removed Variants** (as of v2.0):
- ~~Compact~~ → Use Narrow instead
- ~~Tall~~ → Use Tight instead
- ~~Bold~~ → Use Inter Tight with appropriate weight

### Right Grotesk Mono Family
Monospace variant for technical content, code, and UI labels.

**Available Styles:**
- **Medium**: `font-weight: 500`, `font-style: normal`
- **Fine**: `font-weight: 300`, `font-style: normal`
- **Fine Italic**: `font-weight: 300`, `font-style: italic`

**Font Files:**
- `PPRightGroteskMono-Medium.woff`
- `PPRightGroteskMono-Fine.woff`
- `PPRightGroteskMono-FineItalic.woff`

### CSS Variables
```css
--font-family-rgrot-narrow: 'RightGrotesk', 'Inter Tight', sans-serif;
--font-family-rgrot-tight: 'RightGrotesk', 'Inter Tight', sans-serif;
--font-family-body: 'Inter Tight', system-ui, -apple-system, sans-serif;
--font-family-mono: 'RightGroteskMono', 'SFMono-Regular', Consolas, 'Liberation Mono', Menlo, monospace;
--font-family-heading: var(--font-family-rgrot-tight);
--font-family-base: var(--font-family-body);
```

## Recommended Combinations
- **Mono Status Label** — `kol-mono-text-label`
  Use for section toggles, collapsible headers, and miniature status badges. The class bakes in mono font, uppercase, and 0.2em tracking.
- **Card Caption** — `kol-mono-text text-xs opacity-70`
  Ideal for metadata rows, table captions, or utility explanations inside previews.
- **Hero Subtitle** — `kol-label kol-label-compact` stacked with `.text-auto`
  Combines the compact uppercase label with adaptive color for hero support copy.

## Core Families
- **Right Grotesk Tight** (`extra-condensed`) – Display/section typography, uppercase voice
- **Right Grotesk Narrow** (`condensed`) – Content headings with high readability
- **Inter Tight** – Body copy and long-form reading
- **Right Grotesk Mono** – Tag controls, metadata, code snippets

Font family tokens are defined in `packages/ui/theme.css` and consumed via shared atoms. Importing `@kol/ui/theme.css` in an app guarantees the fonts are available.

## Heading Hierarchy
- **Display & Section**: `.kol-heading-display`, `.kol-heading-section`, `.kol-heading-section-small`, `.kol-heading-subsection`
- **Content Headings**: `.kol-heading-xl`, `.kol-heading-lg`, `.kol-heading-md`, `.kol-heading-sm`
- **Legacy Aliases**: `.kol-h1` → `.kol-heading-xl`, `.kol-h2` → `.kol-heading-lg`, `.kol-h3` → `.kol-heading-md`, `.kol-h4` → `.kol-heading-sm`. These remain until the 2025-11-01 cleanup.

## Body & Utility Text
- `.kol-text` / `.kol-body` for default paragraphs
- `.kol-text-sm` / `.kol-body-sm` for captions and dense UI
- `.kol-body-lg` for marketing blurbs or highlighted copy
- `.kol-mono-text` / `.kol-mono-body` for technical descriptions or code, keeping line-height at 125%
- `.kol-label` and `.kol-label-compact` power SectionLabel/SectionHeader atoms—use them instead of ad-hoc uppercase classes

## Implementation Tips
1. **Use atoms first**: Components like `<SectionHeader>` and `<Tag>` already map the correct classes. Reach for raw classes only when building new primitives.
2. **Pair with `.text-auto`**: Ensures automatic contrast adjustments across light/dark and inverse surfaces.
3. **Respect responsive steps**: Avoid hardcoding font sizes—let the media queries baked into the class scaling handle device differences.
4. **Use font-stretch for width**: When customizing, use `font-stretch: condensed` or `font-stretch: extra-condensed` rather than separate font families.

## @font-face Configuration

All fonts are loaded via `packages/ui/theme.css`:

```css
@font-face {
  font-family: 'RightGrotesk';
  src: url('/fonts/PPRightGrotesk-NarrowMedium.woff') format('woff');
  font-stretch: condensed;
  font-weight: 500;
  font-display: swap;
}

@font-face {
  font-family: 'RightGrotesk';
  src: url('/fonts/PPRightGrotesk-TightMedium.woff') format('woff');
  font-stretch: extra-condensed;
  font-weight: 500;
  font-display: swap;
}

@font-face {
  font-family: 'RightGroteskMono';
  src: url('/fonts/PPRightGroteskMono-Medium.woff') format('woff');
  font-weight: 500;
  font-style: normal;
  font-display: swap;
}

@font-face {
  font-family: 'RightGroteskMono';
  src: url('/fonts/PPRightGroteskMono-Fine.woff') format('woff');
  font-weight: 300;
  font-style: normal;
  font-display: swap;
}

@font-face {
  font-family: 'RightGroteskMono';
  src: url('/fonts/PPRightGroteskMono-FineItalic.woff') format('woff');

  font-display: swap;
}
```

## Migration Notes (v2.0)

### Breaking Changes
- Removed `--font-family-rgrot-compact` (use `--font-family-rgrot-narrow`)
- Removed `--font-family-rgrot-bold` (use `--font-family-body` with weight)
- Removed `--font-family-rgrot-tall` (use `--font-family-rgrot-tight`)
- All Right Grotesk variants now share `font-family: 'RightGrotesk'`
- Use `font-stretch` property to control width (condensed, extra-condensed)

### What Changed
1. **Unified Font Family**: All Right Grotesk widths consolidated under single family name
2. **Added Mono Fine**: New lighter weight (300) for refined technical UI
3. **Font Stretch**: Width variations now use CSS `font-stretch` property
4. **Token Cleanup**: Removed legacy `--color-accent` and updated all `--component-*` references to `--kol-*`

### Migration Completed
- ✅ 4 instances of Compact → Narrow
- ✅ 1 instance of Tall → Tight
- ✅ 0 instances of Bold (already using Inter Tight)
- ✅ All hardcoded font names updated in tokens.js
- ✅ TypeSample.jsx resolver updated
- ✅ 2 new Mono font files added
