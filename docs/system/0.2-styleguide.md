## Overview

The styleguide (`/styleguide`) is a comprehensive documentation site for the Kolkrabbi design system. It contains **18 pages** organized into sections covering typography, colors, components, animations, and more.

**Base URL:** `kolkrabbi.com/styleguide/`

## Usage Guidelines

### For Designers
- Use styleguide to understand component behavior
- Reference design tokens for consistency
- Check component variants before designing
- Use live demos to test interactions

### For Developers
- Styleguide shows canonical component implementations
- Props are documented with TypeScript types
- Code examples are copy-paste ready
- Use styleguide to resolve implementation questions

### For Content
- Styleguide sections follow atomic design
- Components are documented from atoms → organisms
- Each component links to related documentation
- Component updates should update styleguide

## Adding New Styleguide Pages

When adding new styleguide documentation:

1. **Create Route Component** in `apps/web/src/routes/styleguide/`
2. **Update Router** in `apps/web/src/App.jsx`
3. **Add Navigation Link** in `Navbar.jsx`
4. **Document Purpose** in this file (0.2-styleguide.md)
5. **Add to Styleguide Menu** if applicable

**File Naming Convention:**
- Use kebab-case for filenames
- Component pages: `ComponentsAtoms.jsx`, `ComponentsMolecules.jsx`
- System pages: `Typography.jsx`, `Colors.jsx`
- Nested routes: Create subdirectory (e.g., `apparatus/WavyCircle.jsx`)
