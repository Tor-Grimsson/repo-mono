# Molecules - Combined Components

Molecules are combinations of atoms that form more complex UI elements with specific functionality.

## Control Components

### ControlPanel
**File**: `packages/ui/src/molecules/ControlPanel.jsx`

Panel container for controls and settings.

**Structure**:
```javascript
<ControlPanel>
  <ControlPanel.Section title="Section Title">
    <Slider />
    <ToggleSwitch />
  </ControlPanel.Section>
  <ControlPanel.Section title="Another Section">
    <Dropdown />
  </ControlPanel.Section>
</ControlPanel>
```

**Props**:
- `children`: ReactNode
- `className`: string

**Section Props**:
- `title`: string
- `children`: ReactNode

### Controls Panel (variants)
**Files**:
- `packages/ui/src/molecules/ControlPanel.jsx`
- `packages/ui/src/molecules/ControlPanelMinimal.jsx`
- `packages/ui/src/molecules/ControlPanelDense.jsx`

**Variants**:
- **Default**: Standard spacing and typography
- **Minimal**: Reduced padding, compact layout
- **Dense**: Tight spacing for data-heavy interfaces

**Usage**:
```javascript
<ControlPanel>
  <ControlPanel.Section title="Audio Settings">
    <div className="control-panel-row">
      <label>Volume</label>
      <Slider value={volume} onChange={setVolume} />
    </div>
  </ControlPanel.Section>
</ControlPanel>
```

## Table Components

### Table
**File**: `packages/ui/src/molecules/Table.jsx`

Data table component with responsive design.

**Structure**:
```javascript
<Table>
  <Table.Header>
    <Table.Row>
      <Table.HeaderCell>Name</Table.HeaderCell>
      <Table.HeaderCell>Email</Table.HeaderCell>
    </Table.Row>
  </Table.Header>
  <Table.Body>
    <Table.Row>
      <Table.Cell>John Doe</Table.Cell>
      <Table.Cell>john@example.com</Table.Cell>
    </Table.Row>
  </Table.Body>
</Table>
```

**Props**:
- `children`: ReactNode
- `className`: string

**Subcomponents**:
- `Table.Header`: Table header container
- `Table.Body`: Table body container
- `Table.Row`: Table row
- `Table.HeaderCell`: Header cell (with sorting)
- `Table.Cell`: Regular cell

**Features**:
- Responsive (horizontal scroll on mobile)
- Sortable columns
- Striped rows
- Hover states

**Usage**:
```javascript
<Table>
  <Table.Header>
    <Table.Row>
      <Table.HeaderCell sortable onSort={handleSort}>
        Name
      </Table.HeaderCell>
      <Table.HeaderCell sortable onSort={handleSort}>
        Email
      </Table.HeaderCell>
    </Table.Row>
  </Table.Header>
  <Table.Body>
    {users.map(user => (
      <Table.Row key={user.id}>
        <Table.Cell>{user.name}</Table.Cell>
        <Table.Cell>{user.email}</Table.Cell>
      </Table.Row>
    ))}
  </Table.Body>
</Table>
```

## Theme Components

### ThemeToggle
**File**: `packages/ui/src/atoms/ThemeToggle.jsx`

Dark/light mode toggle component.

**Features**:
- Automatic theme detection
- Smooth transition animation
- Icon animation
- System preference detection

**Props**:
- `onToggle`: function (receives 'dark' | 'light')
- `className`: string

**Usage**:
```javascript
<ThemeToggle onToggle={(theme) => setTheme(theme)} />
```

**Behavior**:
- Click to toggle between light and dark
- Automatically detects system preference
- Persists choice in localStorage
- Smooth icon rotation during transition

### ThemeToggleButton
**File**: `packages/ui/src/atoms/ThemeToggleButton.jsx`

Button variant of theme toggle.

**Props**: Same as ThemeToggle

**Usage**:
```javascript
<ThemeToggleButton onToggle={handleThemeChange} />
```

## Section Components

### SectionToggle
**File**: `packages/ui/src/molecules/SectionToggle.jsx`

Expandable section with animated chevron.

**Props**:
- `label`: string
- `isExpanded`: boolean
- `onToggle`: function
- `children`: ReactNode (optional, for custom content)

**Usage**:
```javascript
<SectionToggle
  label="Advanced Settings"
  isExpanded={isExpanded}
  onToggle={() => setIsExpanded(!isExpanded)}

  <div>Advanced settings content</div>
</SectionToggle>
```

## Form Molecules

### InputGroup
Combines Input with label and helper text.

**Structure**:
```javascript
<InputGroup>
  <InputGroup.Label>Email</InputGroup.Label>
  <Input />
  <InputGroup.HelpText>We'll never share your email</InputGroup.HelpText>
</InputGroup>
```

### ToggleGroup
Group of toggle buttons for single or multi-select.

**Usage**:
```javascript
<ToggleGroup>
  <ToggleButton active={selected === 'option1'}>
    Option 1
  </ToggleButton>
  <ToggleButton active={selected === 'option2'}>
    Option 2
  </ToggleButton>
</ToggleGroup>
```

## Layout Molecules

### Container
**File**: `packages/ui/src/atoms/Container.jsx`

Centered container with max-width.

**Props**:
- `children`: ReactNode
- `size`: 'sm' | 'md' | 'lg' | 'xl' (default: 'lg')
- `className`: string

**Sizes**:
- `sm`: max-width 640px
- `md`: max-width 768px
- `lg`: max-width 1024px
- `xl`: max-width 1280px

**Usage**:
```javascript
<Container size="lg">
  <main>Content</main>
</Container>
```

### Grid
Responsive grid system.

**Usage**:
```javascript
<Grid cols={{ base: 1, md: 2, lg: 3 }} gap="4">
  <div>Item 1</div>
  <div>Item 2</div>
  <div>Item 3</div>
</Grid>
```

## Card Molecules

## Styling

Molecules use the same theming system as atoms:
- CSS custom properties
- Responsive design patterns
- Consistent spacing scale
- Typography system

## Best Practices

1. **Composition**: Molecules should compose atoms in predictable ways
2. **Flexibility**: Accept customization via props
3. **Consistency**: Maintain consistent styling across variants
4. **Accessibility**: Include ARIA labels and keyboard navigation
5. **Performance**: Use React.memo for expensive renders
