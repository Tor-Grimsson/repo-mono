# 7.4 Collections Components

> **Purpose:** Documents the component hierarchy and relationships for collection-specific UI components (Logomarks & Illustrations)
> **Status:** Active reference
> **Last Updated:** 2025-11-02

## Overview

Collection components follow atomic design principles: atoms → molecules → organisms → sections. This document maps the component hierarchy and explains how they compose together to create the Logomarks and Illustrations collection pages.

### CollectionFilters (Organism)

**Location:** `apps/web/src/components/sections/collections/CollectionFilters.jsx`

**Purpose:** Interactive filtering interface for collections with tag-based filter controls

**Structure:**
```jsx
<div>
  {/* Header with count */}
  <div className="flex items-center justify-between mb-4">
    <h2 className="kol-mono-sm-fine">Logomark Collection</h2>
    <p className="kol-mono-sm-fine">{logomarks.length} of {totalCount} marks</p>
  </div>

  <Divider />

  {/* Filter controls */}
  <div className="flex items-center justify-between mb-4">
    <h3 className="kol-heading-md">Filter Collection</h3>
    <button onClick={clearAllFilters}>Clear all ({activeFilters.size})</button>
  </div>

  {/* Collection categories (optional) */}
  {showCollectionCategories && (
    <div className="grid grid-cols-1 md:grid-cols-2 lg:grid-cols-4 gap-3">
      {collections.map(collection => (
        <div className="bg-surface-secondary rounded-lg p-4 border border-auto">
          {/* Collection category content */}
        </div>
      ))}
    </div>
  )}

  {/* Filter groups */}
  <div className="space-y-6">
    {renderFilterGroup('Category', 'category', categories)}
    {renderFilterGroup('Type', 'type', types)}
    {renderFilterGroup('Year', 'year', years)}
  </div>
</div>
```

**Props:**
- `logomarks: array` - Array of logomark data objects
- `onFilterChange: (filters: Set) => void` - Callback when filters change
- `collections: array` - Optional collection categories to display
- `totalCount: number` - Total number of items in collection
- `showCollectionCategories: boolean` - Whether to show collection categories section

**Filter Logic:**
- Filters use Set-based state management
- Each filter creates a `type:value` key (e.g., "category:Technology")
- Multiple filters can be active simultaneously (OR logic)
- Clicking a tag toggles it on/off

### CollectionGrid (Molecule)

**Location:** `apps/web/src/components/sections/collections/CollectionGrid.jsx`

**Purpose:** Renders a responsive grid of collection items, automatically selecting appropriate card component

**Structure:**
```jsx
<div className="grid grid-cols-1 sm:grid-cols-2 lg:grid-cols-3 gap-6">
  {items.map((item) =>
    isIllustrations ? (
      <CollectionCardIllustration
        key={item.illustrationName}
        illustration={item}
      />
    ) : (
      <CollectionCardLogo
        key={item.id || item.logoName}
        logomark={item}
      />
    )
  )}
</div>
```

**Props:**
- `logomarks: array` - Array of logomark objects (optional)
- `illustrations: array` - Array of illustration objects (optional)

**Behavior:**
- Uses `illustrations` prop if provided, otherwise `logomarks`
- Auto-detects rendering mode based on which prop is provided
- Renders `CollectionCardIllustration` for illustrations
- Renders `CollectionCardLogo` for logomarks

## Card Components

### CollectionCardLogo (Molecule)

**Location:** `apps/web/src/components/sections/collections/CollectionCardLogo.jsx`

**Purpose:** Individual card displaying a logomark with hover interaction and metadata overlay

**Structure:**
```jsx
<div className="group relative aspect-square bg-surface-primary border border-auto rounded overflow-hidden hover:border-hover transition-all duration-300 cursor-pointer">
  {/* Logo container with padding */}
  <div className="absolute inset-0 flex items-center justify-center p-4">
    <div className={`transition-all duration-300 ${isHovered ? 'scale-110' : 'scale-100'}`}>
      <Logomark name={logomark.logoName} size={logoSize} />
    </div>
  </div>

  {/* Hover overlay */}
  <div className="relative z-10 p-6 flex flex-col justify-end h-full min-h-[200px]">
    <div className={`space-y-3 transition-opacity duration-300 ${isHovered ? 'opacity-100' : 'opacity-0 pointer-events-none'}`}>
      <h3 className="kol-mono-text mb-1">{logomark.name}</h3>
      <p className="kol-mono-sm-fine text-fg-48">{logomark.description}</p>

      <div className="flex flex-wrap gap-2">
        <Tag variant="light" size="sm">{logomark.type}</Tag>
        <Tag variant="muted" size="sm">{logomark.year}</Tag>
      </div>
    </div>
  </div>
</div>
```

**Props:**
- `logomark: object` - Logomark data object with properties: logoName, name, type, year, description

**Sizing Logic:**
- Wordmarks: 160px (wider logos need more space)
- Other types: 96px

**Interactions:**
- Hover triggers 110% scale on logo
- Info panel fades in on hover
- Border changes to hover state color on hover

## Data Flow

### Logomarks Page Flow:

```
Logomarks.jsx
  ├── CollectionHero (static)
  ├── CollectionFilters
  │   ├── Receives: logomarks, onFilterChange, collections, totalCount
  │   └── Provides: Filter state management
  ├── CollectionGrid
  │   └── Renders: CollectionCardLogo components
  └── ProjectsList
      └── Renders: Link-wrapped archive entries
```

### Filtering Data Flow:

1. **CollectionFilters** manages filter state (Set of active filters)
2. **Parent page** (Logomarks.jsx) receives filtered data via `useMemo`
3. **Filtered array** passed to `CollectionGrid` for rendering

**Example:**
```jsx
// In Logomarks.jsx
const filteredLogomarks = useMemo(() => {
  if (filters.size === 0) return logomarks
  return logomarks.filter((logomark) => {
    return Array.from(filters).some((filterKey) => {
      const [filterType, filterValue] = filterKey.split(':')
      return logomark[filterType] === filterValue
    })
  })
}, [filters])

// Pass to CollectionGrid
<CollectionGrid logomarks={filteredLogomarks} />
```

## Usage Examples

### Basic Collection Page

```jsx
import { logomarks, filterData, logomarkCollections } from '../../data/logomarks'
import CollectionGrid from '../../components/sections/collections/CollectionGrid'
import CollectionFilters from '../../components/sections/collections/CollectionFilters'
import CollectionHero from '../../components/sections/collections/CollectionHero'
import ProjectsList from '../../components/sections/work/ProjectsList'

export default function Logomarks() {
  const [filters, setFilters] = useState(new Set())

  const filteredLogomarks = useMemo(() => {
    // Filter logic here
  }, [filters])

  const handleFilterChange = (newFilters) => {
    setFilters(newFilters)
  }

  return (
    <main className="min-h-screen w-full overflow-x-hidden bg-surface-primary">
      <CollectionHero />
      <div className="main-wrapper">
        <div className="max-w-[1200px] mx-auto">
          <div className="py-12">
            <CollectionFilters
              logomarks={logomarks}
              onFilterChange={handleFilterChange}
              collections={logomarkCollections}
              totalCount={logomarks.length}
            />
            <CollectionGrid logomarks={filteredLogomarks} />
            <ProjectsList projects={projects} />
          </div>
        </div>
      </div>
    </main>
  )
}
```

## Styling & Theming

### Color Usage:
- **CollectionCardLogo**: `bg-surface-primary` (adapts to theme)
- **CollectionCardIllustration**: `bg-opacity-hex-fixed-88` (fixed light gray, consistent across themes)

### Responsive Behavior:
- **Grid**: 1 column (mobile) → 2 columns (sm) → 3 columns (lg)
- **Gaps**: 6 units (24px) between cards
- **Cards**: Always square aspect ratio (`aspect-square`)

### Hover States:
- Logo/Illustration: 110% scale (`scale-110`)
- Border: Changes to `border-hover` color
- Info Panel: Fades in (`opacity-100`) with pointer-events disabled when hidden
