# StackHighlightsGrid Component (v7.2.3)

**Status:** Active  
**Last Updated:** 2025-10-30  
**Version:** 7.2.3 – Stack Highlights Grid  
**Parent Doc:** [7.2-work.md](./7.2-work.md)

Responsive grid that surfaces the latest Stack articles in paired cards, mirroring the Work page project grid but using article data and the `ArticleCardHero` molecule.

---

## Overview

`StackHighlightsGrid` pulls a slice of Stack articles and renders them in a two-column grid inside a `card-wrapper`. Each tile wraps `ArticleCardHero` with the subtle `bg-fg-02` surface tint so it blends into the surrounding Stack layout while keeping consistent hover behavior.

Use this component directly inside the Stack main wrapper before the filter/search section. It already handles its own internal padding and border treatment, so no additional `card-wrapper` is required.

## Layout Specs

- Grid: `grid grid-cols-1 md:grid-cols-2`
- Gaps: `gap-6 xl:gap-8`
- Card surface: `bg-fg-02 border border-auto rounded p-6 sm:p-8`
- Container: `max-w-[1200px] mx-auto flex flex-col gap-8 py-8`
- Section header: `SectionLabel` + horizontal `Divider`

---

## Props

| Prop | Type | Default | Notes |
|------|------|---------|-------|
| `articles` | `Array` | `[]` | Slice of article objects (already transformed for `ArticleCardHero`) |
| `label` | `String` | `"Stack Highlights"` | Section heading; overrides `SectionLabel` copy |

Only the first four articles are rendered; the component protects against missing slugs/titles when generating keys.

---

## Usage Example

```jsx
import StackHighlightsGrid from '../components/sections/stack-detail/StackHighlightsGrid'

<section className="card-wrapper">
  <StackHighlightsGrid articles={highlightArticles} />
</section>
```

In `Stack.jsx`, `highlightArticles` always pulls the first four posts returned from Sanity. The browse section excludes those keys so highlights never duplicate below.
