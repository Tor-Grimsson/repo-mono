## Notes
- Values derive from the live token map in `packages/ui/theme.css`; always cross-check there before modifying.
- Context utilities rely on `--component-*` variables. If they resolve unexpectedly, confirm the ancestor surface wrapper (`.surface-inverse`, support bands, etc.).
- For in-depth rationale, contrast data, and visual examples, see [`2.0-color-system.md`](./2.0-color-system.md) and the `/styleguide/colors` route.
