# Foundry Feature Cards Documentation (v7.1.4)

**Status:** Active
**Last Updated:** 2025-10-30
**Version:** 7.1.4 - Feature Cards Sections

## Purpose

Complete documentation of four foundry sections that showcase typeface information using card-based layouts:
1. **FoundryTypefaceDetails** - Font metadata with FeatureGrid molecule
2. **FoundryLicenseQuestions** - Dual CTA section with responsive Divider
3. **FoundryTypefacePairing** - Font comparison cards with PairingsList molecule
4. **FoundryOtherTypefaces** - Typeface showcase with TypefaceCard atoms and active state

## Overview

All four sections share common patterns:
- Standard section wrapper (`w-full py-12 lg:py-16`)
- Max-width container (`max-w-[1200px]`)
- Use FoundrySection header component (except FoundryLicenseQuestions)
- Atomic design composition (atoms → molecules → sections)
- Consistent hover/active states (80% opacity → 100%)

---

## 1. FoundryTypefaceDetails

### Purpose
Displays typeface metadata (Designer, Categories, Styles, Format) in a responsive grid with dual CTA buttons for downloading and viewing specimen.

### Component Hierarchy

```
FoundryTypefaceDetails (apps/web/src/components/sections/foundry/)
├── FoundrySection (header component)
│   ├── Label ("Font Details")
│   └── No dropdown (showDropdown: false)
│
├── FeatureGrid (molecule, variant="row")
│   └── FeatureCard[] (4 cards in row layout)
│       ├── Title + Icon (foundation)
│       └── Description
│
└── ButtonGroup (molecule)
    ├── Button ("Download Font", variant="primary")
    └── Button ("View Specimen", variant="outline")
```

### File Locations

**Section Component:**
- `apps/web/src/components/sections/foundry/FoundryTypefaceDetails.jsx` (39 lines)

**Molecules:**
- `packages/ui/src/molecules/foundry/FeatureGrid.jsx` (45 lines)
- `packages/ui/src/molecules/ButtonGroup.jsx`

**Atoms:**
- `packages/ui/src/atoms/foundry/FeatureCard.jsx`
- `packages/ui/src/atoms/Button.jsx`

### Data Structure

```jsx
const details = [
  { title: 'Designer', description: 'Tor Grimsson', icon: 'foundation' },
  { title: 'Categories', description: 'Serif, Italic, Display', icon: 'foundation' },
  { title: 'Styles', description: '4 Weights', icon: 'foundation' },
  { title: 'Format', description: 'OTF, WOFF2', icon: 'foundation' }
]
```

**Props passed to FeatureGrid:**
- `features={details}` - Array of 4 metadata objects
- `variant="row"` - Horizontal row layout (not grid)

### Layout Specifications

**FeatureGrid "row" variant:**
- Mobile: `flex flex-col gap-4` (stacked vertically)
- Desktop (md+): `flex-row md:h-40 gap-4` (horizontal row, fixed 160px height)
- Each FeatureCard: `flex-1` (equal width distribution)

**ButtonGroup spacing:**
- Container: `flex flex-col items-center gap-2 pt-10 pb-4`
- Buttons: Horizontal alignment, centered

### Active State Pattern

**FeatureGrid tracks hover:**
```jsx
const [activeIndex, setActiveIndex] = useState(null)

// Passed to each card
isActive={activeIndex === index}
onMouseEnter={() => setActiveIndex(index)}
```

**Result:**
- Last hovered card stays at 100% opacity
- Other cards: 50% opacity default, 100% on hover

### Typography Classes

| Element | Class | Size | Weight |
|---------|-------|------|--------|
| Section label | via FoundrySection | - | - |
| Card title | `.kol-helper-uc-md` | 16px | 470 (Medium) |
| Card description | `.kol-mono-sm-fine` | 12px-16px (responsive) | 300 (Light) |
| Button text | Built into Button component | - | - |

```
    ├── Divider (responsive variant)

    └── Questions Section
        ├── h3 ("QUESTIONS?", .kol-label-compact-lg)
        ├── p (.kol-mono-sm-fine, text-fg-32)
        └── Button ("Get in touch!", variant="outline")
```

### File Locations

**Section Component:**
- `apps/web/src/components/sections/foundry/FoundryLicenseQuestions.jsx` (36 lines)

**Atoms:**
- `packages/ui/src/atoms/Button.jsx`
- `packages/ui/src/atoms/Divider.jsx`

### Layout Specifications

**Container flex behavior:**
```jsx
<div className="max-w-[1200px] mx-auto flex flex-col md:flex-row gap-24 md:gap-12">
```

- Mobile: `flex-col gap-24` (96px spacing between sections)
- Desktop (md+): `flex-row gap-12` (48px spacing between sections)

**Individual sections:**
```jsx
<div className="w-full flex flex-col gap-6 items-center text-center">
```

- Full width within flex container
- Vertically stacked content (heading, paragraph, button)
- 24px gap between elements
- Center-aligned text and items

### Divider Component Pattern

**Implementation:**
```jsx
<Divider variant="horizontal" className="md:hidden" />
<Divider variant="vertical" className="hidden md:flex" />
```

**Divider component structure:**
```jsx
// Vertical variant includes wrapper for flex behavior
if (isVertical) {
  return (
    <div className="self-stretch flex justify-center items-center">
      <div className="bg-fg-08" style={{ width: '1px', height: '100%' }} />
    </div>
  )
}

// Horizontal variant is simple
return <div className="bg-fg-08 h-px w-full" />
```

**Key insight:**
- Vertical divider needs wrapper div with `self-stretch` to fill flex row height
- Wrapper handles flex alignment, inner div is exactly 1px wide
- Both use `bg-fg-08` (8% foreground opacity)

### Typography Classes

| Element | Class | Size | Transform | Opacity |
|---------|-------|------|-----------|---------|
| Section heading | `.kol-label-compact-lg` | 24px-28px (responsive) | uppercase | 100% |
| Body text | `.kol-mono-sm-fine` | 12px-16px (responsive) | none | 32% (text-fg-32) |

**Line breaks:**
- `<br />` tags used for deliberate line breaks in paragraphs
- Maintains consistent two-line structure across screen sizes

**Props passed to TypefaceCard:**

- `subtitle` - Variant name (sentence case)

### Active State Pattern

**State management:**
```jsx
const [activeIndex, setActiveIndex] = useState(null)

// Passed to each card
isActive={activeIndex === index}
onMouseEnter={() => setActiveIndex(index)}
```

**Result:**
- Default: All cards 80% opacity
- Hover: 100% opacity + 24% border
- Active (last hovered): Persists at 100% opacity + 24% border
- Hover over another card: That card becomes active, previous loses active state

### Layout Specifications

**Grid layout:**
```jsx
<div className="grid grid-cols-1 md:grid-cols-2 lg:grid-cols-4 gap-6">
```

- Mobile: 1 column (stacked)
- Tablet (md+): 2 columns
- Desktop (lg+): 4 columns (all in one row)
- Gap: 24px between cards

**TypefaceCard structure:**
```jsx
<div className="typeface-card bg-surface-inverse p-4 rounded flex flex-col gap-6 cursor-pointer">
```

- Background: Inverse surface (white on dark theme)
- Padding: 16px all sides
- Border radius: 4px
- Layout: Vertical flex with 24px gaps between sections

### Hover/Active State Styling

**CSS implementation** (`packages/ui/css/components.css`):

```css
  opacity: 1;
}
```

**State transitions:**
- Default: 8% border, 80% opacity
- Hover OR Active: 24% border, 100% opacity
- Smooth 300ms transition on all properties

## Common Patterns Across All Sections

### Section Wrapper Structure

All four sections use the same wrapper:
```jsx
<section className="w-full py-12 lg:py-16">
  <div className="max-w-[1200px] mx-auto flex flex-col gap-8">
    {/* Content */}
  </div>
</section>
```

**Responsive padding:**
- Mobile: `py-12` (48px vertical)
- Desktop (lg+): `py-16` (64px vertical)

**Content container:**
- Max width: 1200px (constrains content on large screens)
- Centered: `mx-auto`
- Vertical flex layout: `flex flex-col gap-8` (32px gap)

### FoundrySection Header Usage

Three of four sections use FoundrySection:
```jsx
<FoundrySection
  variant="label"           // Shows text label instead of badge
  label="[Section Name]"     // Label text
  showDropdown={false}       // No Roman/Italic selector
/>
```

**Exception:** FoundryLicenseQuestions doesn't use FoundrySection (uses direct h3 elements instead)

### Hover Effect Patterns

**Two distinct patterns used:**

1. **Opacity-based (TypefaceCard):**
   - Default: 80% opacity
   - Hover/Active: 100% opacity
   - Use case: When you want entire card to fade

2. **Background-based (PairingCard, FeatureCard):**
   - Default: Transparent background
   - Hover: 1% background tint
   - Use case: When you want subtle fill on hover

**Both patterns share:**
- Border: 8% default → 24% on hover
- Transition: `all 0.3s ease`

### Active State Pattern (Persistent Hover)

Used in FeatureGrid and TypefaceCard:

```jsx
// Section-level state
const [activeIndex, setActiveIndex] = useState(null)

// Props passed to each card
isActive={activeIndex === index}
onMouseEnter={() => setActiveIndex(index)}
```

**Behavior:**
- Last hovered card stays "active" even after mouse leaves
- Visual feedback: Same styling as hover state
- Helps user track which item they last interacted with

### Typography Scale

**Heading styles:**
- `.kol-label-compact-lg` (24-28px, uppercase) - Section headings
- `.kol-helper-uc-s` (14px, uppercase) - Card titles
- `.kol-helper-uc-md` (16px, uppercase) - Feature titles

**Body styles:**
- `.kol-mono-sm-fine` (12-16px, weight 300) - Secondary text, tags
- `.kol-helper-fine-xxs` (10px, weight 100) - Small labels, italic text
- `.kol-helper-fine-xxxs` (8px, weight 100) - Fine print descriptions

**Display style:**
- `.foundry-title` (28px or 64px, TGMalromur italic) - Málrómur specimens

### Border & Color Utilities

**Border classes:**
- `border border-fg-08` - Default 8% opacity border
- Hover states: CSS `color-mix()` to 24%

**Background classes:**
- `bg-surface-inverse` - White on dark theme
- `bg-fg-08` - 8% foreground tint

**Text opacity classes:**
- `text-fg-32` - 32% opacity (very subtle)
- `text-fg-48` - 48% opacity (medium)
- `text-fg-64` - 64% opacity (visible but de-emphasized)

## Data Flow Patterns

### Static Data (No State Management)

**FoundryTypefaceDetails:**
```jsx
const details = [/* static array */]
// Passed directly to FeatureGrid
<FeatureGrid features={details} variant="row" />
```

**FoundryTypefacePairing:**
```jsx
const pairings = [/* static array */]
// Passed directly to PairingsList
<PairingsList pairings={pairings} />
```

**FoundryOtherTypefaces:**
```jsx
const typefaces = [/* static array */]
// Mapped with active state
{typefaces.map((typeface, index) => (
  <TypefaceCard {...typeface} isActive={...} onMouseEnter={...} />
))}
```

**FoundryLicenseQuestions:**
- No data structure (inline content)
- Fully static JSX

### State Management (Active Index Pattern)

**Used in:**
- FeatureGrid molecule (internal state)
- FoundryOtherTypefaces section (section-level state)

**Pattern:**
```jsx
const [activeIndex, setActiveIndex] = useState(null)

// In render:
{items.map((item, index) => (
  <Card
    key={index}
    isActive={activeIndex === index}
    onMouseEnter={() => setActiveIndex(index)}
  />
))}
```

**Why this pattern:**
- Persists last hovered card styling
- Simple boolean prop (`isActive`)
- Parent owns state, children receive props
- Easy to test and reason about

**Layout:**
- CSS Grid and Flexbox (GPU-accelerated)
- No JavaScript positioning
- CSS transitions for smooth effects

### Browser Compatibility

**Required features:**
- CSS Grid (all modern browsers)
- CSS Flexbox (all modern browsers)
- CSS `color-mix()` (modern browsers, fallback to hex values)
- React 18+ (all modern browsers)
- Variable fonts (all modern browsers)

**Graceful degradation:**
- color-mix() falls back to solid colors in old browsers
- Grid/Flexbox have wide support
