## Overview

The grid system provides visual guides for layout alignment, typography verification, and interactive drawing. It includes baseline grids for typography and coordinate grids for canvas-based tools.

### Grid Types

1. **Baseline Grid** - Horizontal lines for typography alignment
2. **Axes Grid** - X/Y axes for coordinate systems
3. **Modular Grid** - Column/row systems for layouts

---

## Baseline Grid

Used for verifying typography alignment, vertical rhythm, and spacing consistency.

### Component

```jsx
import { BaselineGrid } from '@kol/ui'

<div className="relative">
  <BaselineGrid
    gridSize={8}
    strokeWidth={0.5}
    opacity={0.12}
    color="currentColor"
    horizontalOnly={true}
    id="baseline-grid"
  />
  {/* Your content here */}
</div>
```

### Props

| Prop | Type | Default | Description |
|------|------|---------|-------------|
| `gridSize` | number | `8` | Grid unit size in pixels |
| `strokeWidth` | number | `0.5` | Line thickness |
| `opacity` | number | `0.12` | Line opacity (0-1) |
| `color` | string | `'currentColor'` | CSS color value |
| `horizontalOnly` | boolean | `true` | Show only horizontal lines |
| `id` | string | `'baseline-grid'` | Unique pattern ID |
| `className` | string | `''` | Additional CSS classes |
| `style` | Object | `{}` | Inline styles |

### Usage Patterns

#### Typography Verification

```jsx
<article className="kol-prose">
  <BaselineGrid gridSize={8} opacity={0.12} />
  <h1>Article Title</h1>
  <p>Body text aligned to baseline grid...</p>
</article>
```

#### Toggle Visibility

```jsx
const [showGrid, setShowGrid] = useState(false)

<div className="relative">
  {showGrid && <BaselineGrid gridSize={8} />}
  <div className="content">
    {/* Content */}
  </div>
</div>
```

#### Multiple Grids

```jsx
<div className="relative">
  <BaselineGrid gridSize={8} id="grid-8" color="var(--kol-accent-primary)" opacity={0.2} />
  <BaselineGrid gridSize={16} id="grid-16" color="var(--kol-status-danger)" opacity={0.15} />
  <div className="content">
    {/* Content with 8px primary grid, 16px secondary grid */}
  </div>
</div>
```

### Grid Sizes

**8px (Standard)**
- Default for typography
- Matches 8pt baseline grid system
- Most common for design work

**4px (Fine)**
- Detailed typography
- Dense layouts
- Precision alignment

**16px (Coarse)**
- Section spacing
- Component-level alignment
- Layout rhythm

## Axes Grid

Coordinate grid with X/Y axes for canvas-based tools and drawing applications.

### Implementation Pattern

```jsx
const CANVAS_SIZE = 800
const CANVAS_CENTER = { x: CANVAS_SIZE / 2, y: CANVAS_SIZE / 2 }

const AxesGrid = ({ showGrid, zoom = 1, strokeColor = 'var(--kol-border-strong)' }) => {
  if (!showGrid) return null

  return (
    <g transform={`translate(${CANVAS_CENTER.x * (1 - zoom)}, ${CANVAS_CENTER.y * (1 - zoom)}) scale(${zoom})`}>
      {/* Horizontal axis */}
      <line
        x1="0"
        y1={CANVAS_CENTER.y}
        x2={CANVAS_SIZE}
        y2={CANVAS_CENTER.y}
        stroke={strokeColor}
        strokeWidth={1}
      />
      {/* Vertical axis */}
      <line
        x1={CANVAS_CENTER.x}
        y1="0"
        x2={CANVAS_CENTER.x}
        y2={CANVAS_SIZE}
        stroke={strokeColor}
        strokeWidth={1}
      />
    </g>
  )
}
```

### Props

| Prop | Type | Description |
|------|------|-------------|
| `showGrid` | boolean | Toggle grid visibility |
| `zoom` | number | Zoom level (affects transform) |
| `strokeColor` | string | Axis color |
| `canvasSize` | number | Canvas dimensions |
| `center` | Object | Center point coordinates |

### Usage in Canvas

```jsx
<svg width="100%" height="100%" viewBox={`0 0 ${CANVAS_SIZE} ${CANVAS_SIZE}`}>
  <AxesGrid showGrid={ui.showGrid} zoom={params.zoom} />
  <g id="content">
    {/* Drawing content */}
  </g>
</svg>
```

## Grid Philosophy

### Baseline Grids

**Purpose:** Verify typography alignment and vertical rhythm

**When to use:**
- Typography testing
- Spacing verification
- Design system development
- Styleguide creation

**When NOT to use:**
- Production UI (too distracting)
- Over content (impacts readability)

### Axes Grids

**Purpose:** Provide coordinate reference for drawing tools

**When to use:**
- Interactive drawing apps
- Canvas-based editors
- SVG manipulation tools
- Mathematical visualizations

**When NOT to use:**
- Static content
- Text-heavy layouts
- Production interfaces

## Design Guidelines

### Visual Weight

**Baseline Grid:**
- Low opacity (0.08-0.15)
- Thin lines (0.5-1px)
- Minimal color impact
- Subtle presence

**Axes Grid:**
- Medium opacity (0.3-0.6)
- Visible lines (1-2px)
- Clear color contrast
- Prominent reference

### Color Strategy

**Use semantic tokens:**
```jsx
// Good - semantic color
<BaselineGrid color="var(--kol-surface-on-primary)" />

// Good - muted color
<BaselineGrid color="var(--kol-border-subtle)" />

// Avoid - hardcoded colors
<BaselineGrid color="#cccccc" />
```

### Performance

- Grids are SVG-based (scalable, efficient)
- Pattern-based rendering (no per-line DOM nodes)
- Pointer events disabled (performance optimization)
- Large viewport coverage with SVG transforms

## Technical Implementation

### SVG Pattern Generation

```jsx
<defs>
  <pattern id="grid" width={gridSize} height={gridSize} patternUnits="userSpaceOnUse">
    <path d="M 0 0 L gridSize 0" fill="none" stroke="currentColor" strokeWidth="0.5" />
  </pattern>
</defs>
<rect width="100%" height="100%" fill="url(#grid)" />
```

**Key features:**
- `patternUnits="userSpaceOnUse"` - Pattern uses absolute pixel units
- Path-based rendering - Efficient SVG drawing
- Pattern replication - Automatic tiling across viewport

### Large Viewport Coverage

```jsx
style={{
  width: '200vw',      // 2x viewport width
  height: '200vh',     // 2x viewport height
  left: '-50vw',       // Center on viewport
  top: '-50vh',
}}
```

**Why 200vw/200vh:**
- Covers full viewport even when zoomed
- Provides margin for scroll
- Single pattern scales universally

### Pattern ID Uniqueness

```jsx
// Multiple grids need unique IDs
<BaselineGrid id="grid-primary" />
<BaselineGrid id="grid-secondary" />
```

**Critical:** When using multiple grids in the same component, each must have a unique `id` prop to avoid SVG pattern conflicts.

## Migration Guide

### From Inline SVG

**Old:**
```jsx
{showGrid && (
  <svg style={{ opacity: 0.12, /* ... */ }}>
    <defs>
      <pattern id="grid">
        <path d="M 0 0 L 8 0" />
      </pattern>
    </defs>
    <rect fill="url(#grid)" />
  </svg>
)}
```

**New:**
```jsx
{showGrid && <BaselineGrid gridSize={8} opacity={0.12} />}
```

### From CSS Grid

CSS Grid is for **layout**. SVG grids are for **visual guides**. Different purposes!

- CSS Grid: Structural layout
- SVG Grid: Visual reference

## Best Practices

### DO

✅ Use for typography verification
✅ Keep opacity low (0.08-0.15)
✅ Toggle visibility for users
✅ Use semantic colors
✅ Unique IDs for multiple grids

### DON'T

❌ Leave grids on in production
❌ Use high opacity (distracting)
❌ Hardcode colors
❌ Skip ID uniqueness
❌ Use for layout (use CSS Grid instead)
