# StackBrowseArticles Component (v7.2.4)

**Status:** Active  
**Last Updated:** 2025-10-30  
**Version:** 7.2.4 – Stack Browse Articles  
**Parent Doc:** [7.2-work.md](./7.2-work.md)

Two-column article browser for the Stack landing page. Combines the search input, tag filter dropdown, and `ArticleCardMini` rows into a single section that matches the latest Figma design.

---

## Overview

`StackBrowseArticles` replaces the legacy mixed hero/grid block. It receives prepared article data from `Stack.jsx`, honours the active search text and tag filters, and renders results in a responsive two-column list.

- Title defaults to “Browse Articles”
- Search input shares the `control-unified` pattern
- Tag filter reuses `TagFilterDropdown`
- Results render with the updated `ArticleCardMini` (mono title, two-line summary, helper meta)
- Empty state messaging changes when filters remove all matches

---

## File Location

- Component: `apps/web/src/components/sections/stack-detail/StackBrowseArticles.jsx`

## Layout Specs

- Wrapper: `card-wrapper` (handled by route) → max width `1200px`, vertical spacing `py-10`, gap `10`
- Header: `kol-heading-section`, followed by `Divider`
- Controls row: search input (mobile full width) + optional tag dropdown (right aligned on `lg+`)
- Results: `grid grid-cols-1 lg:grid-cols-2 gap-8 lg:gap-12`
- Load more: optional button centred beneath the grid (`control-unified`)

## Props

| Prop | Type | Default | Notes |
|------|------|---------|-------|
| `title` | `string` | `"Browse Articles"` | Heading label |
| `articles` | `Array` | `[]` | Filtered article data (already transformed by route) |
| `searchTerm` | `string` | `''` | Controlled input value |
| `onSearchChange` | `(value: string) => void` | `undefined` | Called on input change |
| `tagOptions` | `Array<{label, value}>` | `[]` | Dropdown options; hides control when empty |
| `selectedTags` | `Set<string>` | `new Set()` | Passed through to dropdown |
| `onTagToggle` | `(tag: string | null) => void` | `undefined` | Receives dropdown toggles |
| `isFiltering` | `boolean` | `false` | Adjusts empty-state copy |
| `showLoadMore` | `boolean` | `false` | Displays load-more control |
| `onLoadMore` | `() => void` | `undefined` | Button handler (disabled when missing) |

Articles expect the following shape (matching `Stack.jsx` transform):

```js
{
  title: string,
  slug: string,
  image: string,
  summary: string,
  meta: string[] // date, reading time
}
```

## Usage Example (Stack.jsx)

```jsx
<section className="card-wrapper">
  <StackBrowseArticles
    articles={filteredArticles}
    searchTerm={searchTerm}
    onSearchChange={setSearchTerm}
    tagOptions={tagOptions}
    selectedTags={selectedTags}
    onTagToggle={handleTagToggle}
    isFiltering={isFiltering}
    showLoadMore={filteredArticles.length > 0}
  />
</section>
```

The route still owns data loading, highlight selection, and filter state. `StackBrowseArticles` renders whatever the route hands it.
