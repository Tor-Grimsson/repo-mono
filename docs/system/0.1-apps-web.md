## Route Configuration

Routes are defined in `apps/web/src/App.jsx`:

```jsx
// Main routes
<Route path="/" element={<Home />} />
<Route path="/work" element={<Work />} />
<Route path="/work/:slug" element={<WorkDetail />} />
<Route path="/foundry" element={<Foundry />} />
<Route path="/stack" element={<Stack />} />
<Route path="/stack/:slug" element={<StackDetail />} />
<Route path="/demo" element={<Demo />} />

// Collection routes
<Route path="/collections/logomarks" element={<Logomarks />} />
<Route path="/collections/illustrations" element={<Illustrations />} />

// Styleguide route (nested routing handled in Styleguide.jsx)
<Route path="/styleguide/*" element={<Styleguide />} />
```

**Nested Routes in Styleguide.jsx:**
The Styleguide component uses nested routing. Routes are defined in `apps/web/src/routes/Styleguide.jsx`:

```jsx
// Styleguide nested routes
<Route index element={<Introduction />} />
<Route path="logo" element={<Logo />} />
<Route path="colors" element={<Colors />} />
<Route path="typography" element={<Typography />} />
<Route path="prose" element={<Prose />} />
<Route path="apparatus/wavy-circle" element={<ApparatusWavyCircle />} />
<Route path="icons" element={<Icons />} />
<Route path="type-report" element={<TypeReport />} />
<Route path="pages/logomarks" element={<Logomarks />} />
<Route path="pages/illustrations" element={<Illustrations />} />
<Route path="components/atoms" element={<ComponentsAtoms />} />
<Route path="components/molecules" element={<ComponentsMolecules />} />
<Route path="components/organisms" element={<ComponentsOrganisms />} />
<Route path="animations" element={<Animations />} />
<Route path="spacing" element={<Spacing />} />

// Redirect routes
<Route path="apparatus" element={<Navigate to="apparatus/wavy-circle" replace />} />
<Route path="pages" element={<Navigate to="pages/logomarks" replace />} />
<Route path="components" element={<Navigate to="components/atoms" replace />} />
```

## Layout Structure

All routes are wrapped in a common layout shell (`SiteLayout`):

```
SiteLayout
├── Navbar (fixed, auto-hide on scroll)
├── <Outlet /> (route content)
└── Footer (optional, based on route)
```

**Navbar Navigation:**
```
Logo (link to /)
│
├── Work → /work
├── Collections
│   ├── Logomarks → /collections/logomarks
│   └── Illustrations → /collections/illustrations
├── Foundry → /foundry
├── Stack → /stack
├── Demo → /demo
└── Styleguide → /styleguide
    └── (nested routes)
```

## Data Flow

### Static Data
- **Logomarks**: `src/data/logomarks.js` - Static array of logomark data
- **Illustrations**: `src/data/illustrations.js` - Static array of illustration data
- **Filters**: Generated from data arrays

### Dynamic Data (Sanity CMS)
- **Projects**: Fetched from Sanity via `getAllProjects()`
- **Fallback**: Static data used when CMS unavailable
- **Caching**: Results cached in component state

### Filtering Pattern
```jsx
// State
const [filters, setFilters] = useState(new Set())

// Filter logic
const filteredData = useMemo(() => {
  if (filters.size === 0) return data
  return data.filter(item => {
    return Array.from(filters).some(filterKey => {
      const [type, value] = filterKey.split(':')
      return item[type] === value
    })
  })
}, [filters])

// UI
<CollectionFilters onFilterChange={setFilters} />
<CollectionGrid data={filteredData} />
```

## Collection Pages Structure

### Logomarks & Illustrations Pages

Both collections follow the same structure with slight variations:

**Common Sections:**
1. **CollectionHero** - Full viewport hero with gradient background
2. **CollectionFilters** - Tag-based filtering interface
3. **CollectionGrid** - Responsive grid of cards
4. **ProjectsList** - Featured work section

**Key Differences:**

| Feature | Logomarks | Illustrations |
|---------|-----------|---------------|
| Background | `bg-surface-primary` (adapts to theme) | `bg-opacity-hex-fixed-88` (fixed light gray) |
| Card Size | Wordmark: 160px, Others: 96px | All: 320px |
| Border | `border-auto` | `border-auto` |
| Padding | `p-4` | `p-4` |
