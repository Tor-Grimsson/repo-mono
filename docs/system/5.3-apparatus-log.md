## Entries

### Wavy Circle Editor
- **Route:** `/styleguide/apparatus/wavy-circle`
- **Component:** `apps/web/src/components/styleguide/apparatus/WavyCircleEditor.jsx`
- **Summary:** Parametric wave generator for Bézier circle experimentation. Supports symmetric node/handle editing, zoom, grid overlays, SVG export, and clipboard path copy.
- **Controls:** Reuses design-system sliders, buttons, and toggle patterns from the work control panel. Includes shared `ToggleBracket` (On/Off) and `ToggleSwitch` atoms for future reuse.
- **Structure:** Refactored into `WavyCircleControls`, `WavyCircleCanvas`, and `useWavyCircleEditor` hook to separate UI from geometry/state logic (2025-10-31).
- **Grid Overlay:** Four quadrant backgrounds anchored at the canvas center keep grid lines snapping to (0,0) while tracking zoom (2025-10-31).

**Enhancement Backlog**
