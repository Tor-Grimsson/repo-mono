Reference article layout used for editorial-style Stack content. Built from the design handoff in `_import/codepen/rich-prose.jsx`, adapted to the design-system tokens (`@kol/ui`) and div-structure guidelines.

---

## Overview

`RichProseArticle` is a self-contained demo article that exercises our typographic scale (`kol-heading-display`, `kol-prose`, helper text) alongside the mono helper classes and inverse pill tags.

- Hero header with tags (`Pill` inverse variant), author meta, excerpt, and hero image
- Summary sidebar containing quick highlights of the article sections
- Main article body using `kol-prose` with headings, lists, callouts, and code blocks
- Optional quote & closing paragraphs per section

The component ships with a `SAMPLE_RICH_PROSE_ARTICLE` constant for immediate rendering, and can accept structured article data via props.

## Layout Structure

```jsx
<main className="bg-surface-primary text-auto">
  <header> ... hero content ... </header>
  <Divider />
  <section className="grid lg:grid-cols-[aside,content]">
    <aside> ... summary cards ... </aside>
    <article className="kol-prose"> ... sections ... </article>
  </section>
</main>
```

- Uses global surface tokens (`bg-surface-primary`, `text-auto`)
- Summary bullets rely on `kol-helper-md`, `kol-mono-sm-fine`, and `kol-mono-xs`, wrapped in a sticky container (`lg:sticky lg:top-28`) with active-state highlighting tied to scroll position via `IntersectionObserver`
- Callout card uses `bg-surface-secondary/40`, `border-auto`, `kol-mono-sm` for the command snippet

---

## Props

| Prop | Type | Default | Notes |
|------|------|---------|-------|
| `article` | `RichProseData` | `SAMPLE_RICH_PROSE_ARTICLE` | Full dataset for tags, meta, sections |

`RichProseData` shape:

```ts
type RichProseData = {
  tags: string[]
  title: string
  excerpt?: string
  author?: { name: string, avatar?: string, role?: string }
  date?: string
  readingTime?: string
  heroImage?: string
  summary?: Array<{ heading: string, body?: string, bullets?: string[] }>
  sections: Array<{
    title?: string
    paragraphs?: string[]
    listIntro?: string
    ordered?: string[]
    codeTitle?: string
    code?: string[]
    quote?: string
    closing?: string
  }>
}
```

## Usage Example

```jsx
import RichProseArticle, { SAMPLE_RICH_PROSE_ARTICLE } from
  '@web/components/sections/stack-detail/RichProseArticle'
```
