## Overview

The SourcesItem component provides a standardized way to display sources, references, and citations within prose content. It's designed to work seamlessly with the prose typography system and uses the existing `.sources-section` CSS classes from `prose.css`.

### Component Location

**File:** `/packages/ui/src/molecules/SourcesItem.jsx`

**Export:** Available as `SourcesItem` from `@kol/ui` package:

```javascript
import { SourcesItem } from '@kol/ui';
```

---

## Component API

### Props

| Prop | Type | Required | Description | Example |
|------|------|----------|-------------|---------|
| `number` | string | ✅ | Numbered identifier for the source | `"01"`, `"1"`, `"02"` |
| `title` | string | ✅ | Title of the source (also link text) | `"The Elements of Typographic Style"` |
| `href` | string | ✅ | URL for the external link | `"https://webtypography.net/"` |
| `meta` | string | ✅ | Additional metadata/description | `"Robert Bringhurst · Essential reading"` |

### Basic Usage

```jsx
<SourcesItem
  number="01"
  title="The Elements of Typographic Style"
  href="https://webtypography.net/"
  meta="Robert Bringhurst · Essential reading on typography"
/>
```

## Usage Patterns

### In Prose Pages

The component is designed to be used within a `.sources-section` wrapper:

```jsx
<div className="sources-section">
  <h3>Sources & References</h3>
  <ul className="sources-list">
    <SourcesItem
      number="01"
      title="The Elements of Typographic Style"
      href="https://webtypography.net/"
      meta="Robert Bringhurst · Essential reading on typography"
    />
    <SourcesItem
      number="02"
      title="Interactive Typography"
      href="https://betterwebtypography.com/"
      meta="Jakob Schneider · Practical typography guide"
    />
  </ul>
</div>
```

### Within Cards

Can be embedded inside card content (e.g., in the Prose styleguide):

```jsx
<div>
  <DesCard
    name="Sources"
    description="References and citations"
    details="External links · Metadata · Numbered items"
  />

  <div className="sources-section">
    <h3>Further Reading</h3>
    <ul className="sources-list">
      <SourcesItem
        number="01"
        title="Typography Handbook"
        href="https://typographyhandbook.com/"
        meta="Essential typography reference"
      />
    </ul>
  </div>
</div>
```

### With Prose Variants

Works with all prose variants (`.kol-prose`, `.kol-prose-wide`, `.kol-prose-compact`):

```jsx
<div className="kol-prose-compact">
  <p>Content...</p>

  <div className="sources-section">
    <h3>References</h3>
    <ul className="sources-list">
      <SourcesItem ... />
    </ul>
  </div>
</div>
```

## Design Tokens

The component uses these design tokens (defined in `theme.css`):

- **Colors:**
  - `--kol-accent-primary` - Link color
  - `--kol-accent-primary-strong` - Link hover color
  - `--kol-border-default` - Border color
  - `--kol-surface-primary` - Background color
  - `--kol-color-fg-64` - Number text (64% opacity)
  - `--kol-color-fg-48` - Metadata text (48% opacity)

- **Typography:**
  - `--kol-font-family-mono` - Font family for all text
  - Font size: `14px` (body), `12px` (metadata)
  - Line height: `150%` (body), normal (metadata)

- **Spacing:**
  - Gap between items: `1rem`
  - Item padding: `1.5rem`
  - Content gap: `0.5rem`

## Integration

### With Prose System

The SourcesItem is designed to work with the prose typography system:

- **Typography:** Uses mono font for technical/reference feel
- **Spacing:** Aligns with 8px baseline grid
- **Colors:** Uses semantic tokens for automatic theming
- **Responsive:** No fixed width, adapts to container

### With Sanity/CMS

Can be used with dynamic data from Sanity:

```jsx
// In a Sanity page component
<div className="sources-section">
  <h3>Sources</h3>
  <ul className="sources-list">
    {sources.map((source, index) => (
      <SourcesItem
        key={index}
        number={String(index + 1).padStart(2, '0')}
        title={source.title}
        href={source.url}
        meta={source.author}
      />
    ))}
  </ul>
</div>
```

## Accessibility

### Semantic HTML

The component renders semantic HTML:

```html
<li>
  <span class="source-number">01</span>
  <div class="source-content">
    <a href="...">Title</a>
    <span class="source-meta">Meta</span>
  </div>
</li>
```

### Link Accessibility

- Links have proper `href` attributes
- External links should include `target="_blank"` and `rel="noopener noreferrer"`
- Links have descriptive text (title + meta provide context)

### Best Practices

1. **Descriptive Titles:** Use full, descriptive source titles
2. **Meaningful Meta:** Include author, publication, or other relevant details
3. **Numbering:** Use consistent numbering format (e.g., "01", "02" or "1", "2")
4. **External Links:** Always add `target="_blank"` and `rel="noopener noreferrer"` for external URLs
