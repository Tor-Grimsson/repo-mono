# Article + Sanity Integration Guide

## Overview

The Article page is now fully integrated with Sanity CMS and dynamically fetches content based on URL parameters.

## Setup

### 1. Sanity Environment Variables

Configure these in `apps/web/.env`:

```bash
VITE_SANITY_PROJECT_ID=your_project_id
VITE_SANITY_DATASET=production
VITE_SANITY_API_VERSION=2025-01-01
VITE_SANITY_USE_CDN=true
```

### 2. Create a Blog Post in Sanity

1. Start Sanity Studio: `cd apps/studio && npm run dev`
2. Create a new "Blog Post" document
3. Fill in the fields:
   - **Title**: Your article title
   - **Slug**: Auto-generated from title (e.g., "my-first-post")
   - **Excerpt**: Short summary (max 300 characters)
   - **Author**: Reference to an Author document
   - **Published At**: Publication date/time
   - **Cover Image**: Hero image
   - **Tags**: Array of strings
   - **Body**: Rich text content (supports headings, paragraphs, images, code blocks)
   - **Sources & References**: Optional array of source objects

### 3. Access the Article

Navigate to: `/article/[slug]`

For example, if your slug is "my-first-post":
```
http://localhost:5173/article/my-first-post
```

## Component Architecture

### Article Page (`/routes/Article.jsx`)

**Features:**
- Fetches data from Sanity using `BLOG_DETAIL` query
- Dynamic routing with URL slug parameter
- Loading and error states
- Automatic reading time calculation (200 WPM)
- Date formatting
- Source formatting for SourcesSection component

**Data Flow:**
```
URL: /article/my-post
  ↓
useParams() extracts slug
  ↓
sanityClient.fetch(BLOG_DETAIL, { slug })
  ↓
Renders ArticleHeader with data
  ↓
Renders ProseContent (static demo content)
  ↓
Renders SourcesSection (if sources exist)
```

### ArticleHeader Component

**Props:**
- `tags`: Array of strings (from Sanity)
- `title`: String (from Sanity)
- `authorName`: String (from Sanity author.name)
- `authorTitle`: String (from Sanity author.bio or fallback)
- `date`: Formatted date string
- `readingTime`: Calculated string (e.g., "5 min read")
- `excerpt`: String (from Sanity)
- `heroImage`: Image URL or "placeholder"

## Query Structure

### BLOG_DETAIL Query

Located in: `packages/content/src/queries.ts`

```typescript
export const BLOG_DETAIL = `*[_type == "blog" && slug.current == $slug][0]{
  _id,
  title,
  "slug": slug.current,
  excerpt,
  publishedAt,
  author->{
    _id,
    name,
    "slug": slug.current,
    bio,
    image{
      ...,
      asset->{
        url,
        metadata{dimensions, lqip}
      }
    }
  },
  tags,
  coverImage{
    ...,
    asset->{
      url,
      metadata{dimensions, lqip}
    }
  },
  body[],
  sources[]{
    title,
    url,
    meta
  },
  relatedProjects[]->{
    _id,
    title,
    "slug": slug.current,
    description,
    thumbnail{
      ...,
      asset->{
        url,
        metadata{dimensions, lqip}
      }
    }
  }
}`
```

## Sanity Schema Structure

### Blog Document

Located in: `packages/content/src/schemas/types/blog.ts`

**Fields:**
- `title` (string, required)
- `slug` (slug, required)
- `excerpt` (text, max 300 chars)
- `author` (reference to author)
- `publishedAt` (datetime, required)
- `featured` (boolean)
- `coverImage` (image)
- `thumbnail` (image)
- `body` (array of blocks: text, images, code)
- `tags` (array of strings)
- `relatedProjects` (array of references)
- `sources` (array of objects: title, url, meta)

### Author Document

Located in: `packages/content/src/schemas/types/author.ts`

**Fields:**
- `name` (string, required)
- `slug` (slug, required)
- `bio` (text)
- `image` (image)
- `email` (string)
- `website` (url)
- `social` (object: twitter, linkedin, github)

## Next Steps

### 1. Implement Portable Text Renderer

Create a component to render Sanity's Portable Text format:

```typescript
// Example structure
const PortableTextRenderer = ({ blocks }) => {
  return blocks.map(block => {
    switch (block._type) {
      case 'block':
        return renderBlock(block);
      case 'image':
        return renderImage(block);
      case 'code':
        return renderCode(block);
      default:
        return null;
    }
  });
};
```

### 2. Generate Table of Contents

Parse body blocks for H2/H3 headings:

```typescript
const generateTOC = (body) => {
  return body
    .filter(block => block._type === 'block' && block.style === 'h2')
    .map((block, index) => ({
      heading: block.children[0].text,
      index
    }));
};
```
