# 7.1 Foundry Components

> **Purpose:** Documents the component hierarchy and relationships for foundry-specific UI components
> **Status:** Active reference
> **Last Updated:** 2025-10-29

## Overview

Foundry components follow atomic design principles: atoms → molecules → organisms → sections. This document maps the component hierarchy and explains how they compose together.

---

## Reusable Components

### FoundrySection (Header Component)

**Location:** `apps/web/src/components/sections/foundry/components/FoundrySection.jsx`

**Purpose:** Reusable header for foundry sections showing font name and style controls

**Structure:**
```jsx
<>
  {/* Header with pill and dropdown */}
  <div className="w-full flex flex-col gap-4 md:flex-row md:justify-between md:items-center">
    {/* Left: Málrómur pill with AA icon */}
    <div className="px-6 py-3 bg-auto-inverse rounded-full border border-fg-08">
      <span className="kol-mono-xs text-auto-inverse">Málrómur</span>
      <span className="kol-mono-xs text-auto-inverse font-semibold">AA</span>
    </div>

    {/* Right: Style dropdown */}
    <Dropdown
      options={[
        { label: 'Roman', value: 'roman' },
        { label: 'Italic', value: 'italic' }
      ]}
      value={selectedStyle}
      onChange={onStyleChange}
    />
  </div>

  {/* Divider */}
  <div className="h-px bg-opacity-hex-12" />
</>
```

**Props:**
- `selectedStyle: string` - Current style variant ('roman' | 'italic')
- `onStyleChange: (style: string) => void` - Callback when style changes

**Usage Pattern:**
Parent section manages state and passes to FoundrySection, which controls roman/italic for all child components.

## Font Preview Components

### FontPreviewItem (Organism)

**Location:** `packages/ui/src/organisms/foundry/FontPreviewItem.jsx`

**Purpose:** Complete interactive font preview with controls and text display

**Component Structure:**
```jsx
<div className="foundryCard foundryCardPadded">
  <FontControlsPanel
    styleOptions={styleOptions}
    weightOptions={weightOptions}
    selectedStyle={styleVariant}
    selectedWeight={weight}
    onStyleChange={setStyleVariant}
    onWeightChange={setWeight}
    size={displaySize}
    onSizeChange={handleSizeChange}
    sizeMin={sliderMin}
    sizeMax={sliderMax}
    leading={leading}
    onLeadingChange={setLeading}
    spacing={spacing}
    onSpacingChange={setSpacing}
    compactOnDesktop={compactOnDesktop}
    fontLabel="Málrómur"
    additionalControls={additionalControls}
  />

  {/* Text display area with auto-sizing */}
  <div ref={containerRef} className="flex-1 w-full overflow-hidden">
    <p ref={textRef} style={{ fontSize, fontWeight, lineHeight, letterSpacing }}>
      {visibleText}
    </p>
  </div>
</div>
```

**Features:**
- Auto-sizing via binary search algorithm
- Manual size adjustment with slider
- Text clipping to fit container
- Style and weight selection
- Leading (line-height) and spacing (letter-spacing) controls
- Responsive layout with compact mode

**Key Props:**
- `initialSize: number` - Starting font size (default: 96)
- `text: string` - Text to display
- `initialLineHeight: number` - Initial line height 90-140 range (default: 100)
- `fontStyle: string` - Font style ('normal' | 'italic')
- `textClassName: string` - Additional text classes
- `compactOnDesktop: boolean` - Hide some controls on desktop

**State Management:**
FontPreviewItem manages its own internal state:
- `styleVariant` - Roman/Italic selection
- `weight` - Font weight (Thin through Black)
- `size` - Current font size
- `leading` - Line-height adjustment (0-50)
- `spacing` - Letter-spacing adjustment (-20 to 20)

### FontControlsPanel (Molecule)

**Location:** `packages/ui/src/molecules/foundry/FontControlsPanel.jsx`

**Purpose:** Grouped font controls for customization

**Component Structure:**
```jsx
<div className="flex flex-col gap-3 w-full">
  <div className="fpsMainWrapper">
    {/* Buttons - Badge + Dropdowns */}
    <div className="fpsButtonsWrapper">
      <FontBadge>{fontLabel}</FontBadge>
      <Dropdown /* Style */ />
      <Dropdown /* Weight */ />
    </div>

    {/* Additional Controls (optional) */}
    {additionalControls}

    {/* Sliders */}
    <div className="flex flex-col gap-3">
      <Slider label="Size" />
      <Slider label="Leading" />
      <Slider label="Spacing" />
    </div>
  </div>
</div>
```

**Composed Of:**
- `FontBadge` (atom) - Font name pill
- `Dropdown` (atom) - Style and weight selection
- `Slider` (atom) - Size, leading, spacing controls

**Key Props:**
- `styleOptions: Array<{label, value}>` - Style dropdown options
- `weightOptions: Array<{label, value}>` - Weight dropdown options
- `selectedStyle: string` - Current style
- `selectedWeight: string` - Current weight
- `size: number` - Current font size
- `sizeMin: number` - Minimum size (default: 12)
- `sizeMax: number` - Maximum size (default: 300)
- `leading: number` - Line-height adjustment (0-50)
- `spacing: number` - Letter-spacing adjustment (-20 to 20)
- `compactOnDesktop: boolean` - Hide certain controls on desktop
- `fontLabel: string` - Font name for badge (default: 'Málrómur')
- `additionalControls: ReactNode` - Optional additional controls

## Style Components

### StyleCard (Atom)

**Location:** `packages/ui/src/atoms/foundry/StyleCard.jsx`

**Purpose:** Individual font weight display card with hover/active states

**Structure:**
```jsx
<div className="style-card">
  <div className="style-card-left">
    <div className="style-card-text">{label}</div>
  </div>
  <div className="style-card-right">
    <div className="style-card-text">{weight}</div>
  </div>
</div>
```

**Props:**
- `label: string` - Weight label (e.g., "Bold", "Light")
- `weight: number` - Numeric weight value (100-900)
- `italic: boolean` - Whether to apply italic style
- `isActive: boolean` - Whether this card is currently selected
- `onMouseEnter: () => void` - Callback fired on mouse enter
- `onClick: () => void` - Callback fired on click

**States:**
- **Inactive:** `border-fg-08`, text at 50% opacity, label bottom/number top
- **Active/Hover:** `border-fg-24`, text at 100% opacity, label top/number bottom (flipped)

**CSS Classes:** See `packages/ui/css/components.css`
- `.style-card` - Container with 120px height
- `.style-card-text` - Text elements with opacity transitions
- `.style-card-left` - Left column (label)
- `.style-card-right` - Right column (number)
- `.style-card.active` - Active state styles

---

### StylesGrid (Molecule)

**Location:** `packages/ui/src/molecules/foundry/StylesGrid.jsx`

**Purpose:** Vertical list of StyleCard components

**Structure:**
```jsx
<div className="flex flex-col gap-3">
  {styles.map(style => (
    <StyleCard
      label={style.label}
      weight={style.weight}
      italic={isItalic}
      isActive={currentStyle?.label === style.label}
      onMouseEnter={() => onStyleHover?.(style)}
      onClick={() => onStyleClick?.(style)}
    />
  ))}
</div>
```

**Props:**
- `styles: Array<{label, weight}>` - Array of style objects
- `currentStyle: Object` - Currently selected style object
- `isItalic: boolean` - Whether to display all styles as italic
- `onStyleHover: (style) => void` - Callback fired when hovering
- `onStyleClick: (style) => void` - Callback fired when clicking

## Usage Patterns

### 1. Section with Shared Style Control

Both FoundryStyleSection and FontPreviewSection follow this pattern:

```jsx
const Section = () => {
  // Parent section manages style state
  const [selectedStyleVariant, setSelectedStyleVariant] = useState('italic')
  const isItalic = selectedStyleVariant === 'italic'

  return (
    <section className="w-full py-12 lg:py-16">
      <div className="max-w-[1200px] mx-auto flex flex-col gap-8">
        {/* Header controls style for entire section */}
        <FoundrySection
          selectedStyle={selectedStyleVariant}
          onStyleChange={setSelectedStyleVariant}
        />

        {/* Child components receive italic state */}
        <ChildComponents isItalic={isItalic} />
      </div>
    </section>
  )
}
```

**Benefits:**
- Single source of truth for style variant
- Consistent styling across all preview items in section
- Reusable header component

### 2. Grid Layout Pattern

FontPreviewSection uses responsive grid:

```jsx
<div className="grid grid-cols-1 lg:grid-cols-2 gap-4">
  {previews.map((preview, index) => (
    <div
      key={index}
      className={preview.colSpan === 2 ? 'col-span-1 lg:col-span-2' : 'col-span-1'}
    >
      <FontPreviewItem {...preview} />
    </div>
  ))}
</div>
```

**Responsive behavior:**
- Mobile: Single column (all items full width)
- Desktop: 2 columns with optional full-width items (`colSpan: 2`)

- ✅ Typography classes (`kol-mono-xs`)
