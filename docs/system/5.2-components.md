## Table Molecule

**Location:** `packages/ui/src/molecules/Table.jsx`

### Purpose

Reusable data table molecule with column configuration, custom renderers, and theme-aware styling. Used for displaying structured tabular data with semantic HTML.

### Component Structure

```jsx
<Table
  caption="Accessible table caption"
  columns={columns}
  rows={rows}
  className="optional-wrapper-class"
/>
```

### Props

| Prop | Type | Required | Description |
|------|------|----------|-------------|
| `caption` | string | No | Accessible table caption (visually hidden with `sr-only`) |
| `columns` | Array<Object> | Yes | Column definitions (see Column Configuration below) |
| `rows` | Array<Object> | Yes | Array of data objects to display |
| `className` | string | No | Additional classes for table wrapper |

### Column Configuration

Each column object supports:

```javascript
{
  header: 'Column Header',           // Column header text
  accessor: 'dataKey',                // Key to access data in row object
  render: (row) => <JSX />,          // Optional custom render function
  className: 'dt-cell-text',         // Optional cell class
  headerClassName: 'dt-cell-title',  // Optional header class
  style: { maxWidth: '280px' }       // Optional inline styles
}
```

### Default Styling

**Wrapper:**
- Border: `border border-auto` (adaptive 8% opacity)
- Rounded corners: `rounded` (4px)
- Overflow: `overflow-x-auto` (horizontal scroll on small screens)

**Table:**
- Width: `min-w-full` (full width of container)
- Text alignment: `text-left`
- Text color: `text-auto` (theme-aware)

**Header:**
- Background: `bg-container-primary` (adaptive container background)
- Bottom border: `border-b border-auto`
- Typography: `dt-cell-title` class (uppercase, tracking)

**Body:**
- Vertical alignment: `align-top`
- Row borders: `border-b border-auto` (except last row)
- Text color: `text-auto`

**Cell Borders:**
- Right border on all cells except last column: `border-r border-auto`

### Example Usage

**Simple table with default rendering:**

```jsx
const columns = [
  { header: 'Name', accessor: 'name' },
  { header: 'Value', accessor: 'value' }
]

const rows = [
  { name: 'Item 1', value: '100' },
  { name: 'Item 2', value: '200' }
]

<Table caption="Simple data table" columns={columns} rows={rows} />
```

**Table with custom renderers (color tokens example):**

```jsx
const columns = [
  {
    header: 'Token',
    accessor: 'token',
    className: 'dt-cell-text',
    render: (row) => (
      <span className="dataTableToken bg-fg-08">{row.token}</span>
    )
  },
  {
    header: 'Light Mode',
    accessor: 'light',
    className: 'dt-cell-metaStrong',
    render: (row) => (
      <div className="flex items-center gap-3">
        <span
          className="w-6 h-6 rounded border border-auto"
          style={{ backgroundColor: row.light.hex }}
        />
        <span className="kol-mono-text text-xs">{row.light.label}</span>
      </div>
    )
  },
  {
    header: 'Usage',
    accessor: 'usage',
    className: 'dt-cell-meta',
    style: { maxWidth: '280px' }
  }
]

const rows = [
  {
    id: 'surface-primary',
    token: '--kol-surface-primary',
    light: { label: '#fafafa', hex: '#fafafa' },
    usage: 'App background, primary containers.'
  }
]

<Table caption="Color tokens" columns={columns} rows={rows} />
```

### Typography Classes

Standard table typography classes used:

| Class | Usage | Font | Size | Weight |
|-------|-------|------|------|--------|
| `dt-cell-title` | Header cells | Right Grotesk Mono | 10px | 500 (Medium) |
| `dt-cell-text` | Standard body cells | Right Grotesk Mono | 12px | 400 (Regular) |
| `dt-cell-meta` | Secondary info cells | Right Grotesk Mono | 10px | 300 (Light) |
| `dt-cell-metaStrong` | Emphasized meta cells | Right Grotesk Mono | 11px | 470 (Medium) |

### Accessibility

**Semantic HTML:**
- Uses proper `<table>`, `<thead>`, `<tbody>` structure
- `<th scope="col">` for column headers
- `<caption>` with `sr-only` class (hidden visually, available to screen readers)

**Keyboard Navigation:**
- Native table keyboard navigation supported
- Scrollable container is keyboard accessible

**ARIA:**
- Proper table semantics automatically inferred by assistive technology
- Caption provides context for screen readers

### Theme Adaptation

Table automatically adapts to theme context:

**Default (Dark) Theme:**
- Border: 8% white opacity
- Background: Dark container background
- Text: Light foreground

**Inverse (Light) Theme:**
- Border: 8% black opacity
- Background: Light container background
- Text: Dark foreground

**No additional code needed** - uses `border-auto`, `bg-container-primary`, and `text-auto` utilities.

### Responsive Behavior

**Mobile (<768px):**
- Horizontal scroll enabled via `overflow-x-auto`
- Table maintains full structure (no column hiding)
- Min-width enforced on table (`min-w-full`)

**Tablet (768px+):**
- Full table visible if columns fit
- Scroll only if content exceeds viewport

**Desktop (1024px+):**
- Same as tablet (no specific breakpoint changes)

### Design Tokens Used

**Borders:**
- `border-auto` → `var(--kol-border-default)` (8% foreground opacity)

**Backgrounds:**
- `bg-container-primary` → `var(--kol-container-primary)` (adaptive container background)

**Text:**
- `text-auto` → `var(--kol-surface-on-primary)` (adaptive foreground color)

**Radius:**
- `rounded` → 4px border radius

### Key Features

1. **Column-based configuration** - Define columns once, reuse for multiple tables
2. **Custom renderers** - Full control over cell content with render functions
3. **Theme-aware** - Automatic dark/light mode adaptation
4. **Accessible** - Semantic HTML with proper ARIA support
5. **Responsive** - Horizontal scroll on small screens
6. **Flexible styling** - Support for custom classes and inline styles per column
7. **Type-safe** - Clear prop types and column configuration structure

### Performance Considerations

**Rendering:**
- Pure functional component (no class component overhead)
- Efficient mapping over columns and rows
- No unnecessary re-renders (no internal state)

**Memory:**
- No event listeners or subscriptions
- Data passed as props (controlled component)
- No ref usage

**Optimization:**
- Uses row keys (`row.id ?? row.token ?? rowIndex`) for efficient React reconciliation
- Minimal DOM nesting (semantic table structure)
- CSS handles all styling (no JavaScript layout calculations)

### Future Enhancements

**Potential additions:**
1. Sorting support (column header clicks)
2. Filtering support (search/filter rows)
3. Pagination support (split large datasets)
4. Column resizing (drag column borders)
5. Fixed header on scroll (sticky positioning)
6. Row selection (checkboxes)
7. Expandable rows (nested content)
8. Export to CSV/JSON
