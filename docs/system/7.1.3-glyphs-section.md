## Data Flow & State Management

### GlyphsSection State

```jsx
const [selectedStyle, setSelectedStyle] = useState('italic') // Font style (italic/roman)
const [showAll, setShowAll] = useState(false)               // Show 2 or all 6 categories
```

**State flows to:**
1. **FoundrySection** - Controls `selectedStyle` via dropdown
2. **GlyphCategory** - Receives `fontStyle` derived from `selectedStyle`
3. **Conditional Rendering** - Controls visibility of gradient overlay and button

### Derived Values

```jsx
const visibleCategories = showAll ? glyphCategories : glyphCategories.slice(0, 2)
```

Shows first 2 categories (Uppercase, Lowercase) when collapsed, all 6 when expanded.

### Props Passed to FoundrySection

```jsx
<FoundrySection
  variant="label"                      // Shows text label instead of badge
  label="Character Set"                 // Label text to display
  selectedStyle={selectedStyle}         // 'italic' or 'roman'
  onStyleChange={setSelectedStyle}      // Callback for dropdown
/>
```

### Props Passed to GlyphCategory

```jsx
<GlyphCategory
  key={category.key}                                         // Unique key for mapping
  title={category.title}                                     // "Uppercase", "Lowercase", etc.
  glyphs={glyphSets[category.key]}                          // Array of characters
  fontStyle={selectedStyle === 'italic' ? 'italic' : 'normal'} // Derived font style
/>
```

### Props Flow: GlyphCategory → GlyphGrid → GlyphItem

```jsx
// GlyphCategory.jsx
<GlyphGrid glyphs={glyphs} fontStyle={fontStyle} />

// GlyphGrid.jsx
{glyphs?.map((glyph, index) => (
  <GlyphItem key={index} glyph={glyph} fontStyle={fontStyle} />
))}

// GlyphItem.jsx
<div style={{ fontFamily: 'TGMalromur', fontStyle: fontStyle }}>
  {glyph}
</div>
```

## Show/Hide Pattern with Gradient Overlay

### Collapsed State (Default)

**Shows:**
- First 2 categories: Uppercase, Lowercase
- Gradient fade overlay on bottom
- "Show All Glyphs" button

**Implementation:**
```jsx
const [showAll, setShowAll] = useState(false)
const visibleCategories = showAll ? glyphCategories : glyphCategories.slice(0, 2)
```

### Gradient Overlay Specifications

**Figma Values:**
- Stop 1: 13% position, `#121215` at 0% opacity
- Stop 2: 86% position, `#121215` at 100% opacity

**CSS Implementation:**
```jsx
<div
  className="absolute bottom-0 left-0 right-0 h-64 pointer-events-none"
  style={{
    background: 'linear-gradient(to bottom, rgba(18, 18, 21, 0) 13%, rgba(18, 18, 21, 1) 86%)'
  }}
/>
```

**Key properties:**
- `absolute` - Positioned over the lowercase category
- `bottom-0` - Aligned to bottom of grid container
- `h-64` - Height of 256px (covers ~bottom third of lowercase grid)
- `pointer-events-none` - Doesn't block interaction with glyphs underneath

### Button Positioning

```jsx
<div className="absolute bottom-0 left-0 right-0 flex justify-center">
  <Button
    onClick={() => setShowAll(true)}
    variant="outline"
  >
    Show All Glyphs
  </Button>
</div>
```

**Positioning:**
- `absolute bottom-0` - Sits at very bottom of container, on top of gradient
- `justify-center` - Horizontally centered
- Appears where gradient transition has mostly occurred (~70-80% opacity)

### Conditional Rendering Pattern

```jsx
{!showAll && (
  <>
    {/* Gradient Overlay */}
    <div className="..." style={{ background: '...' }} />

    {/* Show All Button */}
    <div className="...">
      <Button onClick={() => setShowAll(true)}>Show All Glyphs</Button>
    </div>
  </>
)}
```

**React Pattern Explanation:**

**`&&` Operator (Logical AND):**
- Left side: condition (`!showAll`)
- Right side: JSX to render
- **How it works:** If left is `false`, React renders nothing (short-circuit). If `true`, renders right side.
- **Use case:** Show/hide without an else case

**Alternative (Ternary):**
```jsx
{!showAll ? (
  <>...</>
) : null}
```

**Both are standard React practice.** The `&&` pattern is more concise and commonly used when you only need to conditionally show something (no else branch).

### Expanded State

**Shows:**
- All 6 categories mapped from `glyphCategories`
- No gradient overlay
- No button

**Trigger:**
```jsx
onClick={() => setShowAll(true)}
```

**Cannot collapse back** - Once expanded, stays expanded (common pattern for "show more" UIs).

### Structure

**File:** `packages/ui/src/molecules/foundry/GlyphCategory.jsx` (30 lines)

```jsx
<div className="w-full flex flex-col gap-4">
  <h3 className="kol-helper-s" style={{ letterSpacing: '0.2em' }}>
```

**Props:**
- `title` - Category display name (e.g., "Uppercase")
- `glyphs` - Array of characters to display
- `fontStyle` - 'normal' or 'italic' (passed to GlyphGrid)
- `className` - Additional styling (optional)

### Typography Override

**Class:** `kol-helper-s` (14px uppercase, letter-spacing 0.05em)

**Override:** Inline `letterSpacing: '0.2em'`

**Why override?**
- Default helper spacing (0.05em) is too tight for category labels
- 0.2em provides better visual separation for uppercase labels
- Inline override is acceptable for one-off adjustments

**Pattern:**
```jsx
<h3 className="kol-helper-s" style={{ letterSpacing: '0.2em' }}>
```

Uses typography class for font/size/weight/transform, overrides only letter-spacing.

## GlyphGrid Molecule

### Structure

**File:** `packages/ui/src/molecules/foundry/GlyphGrid.jsx` (34 lines)

```jsx
<div className="flex flex-wrap gap-4 w-full">
  {glyphs?.map((glyph, index) => (
    <GlyphItem key={index} glyph={glyph} fontStyle={fontStyle} />
  ))}
</div>
```

**Layout:**
- `flex flex-wrap` - Wraps glyphs into rows
- `gap-4` - 16px spacing between glyphs
- `w-full` - Takes full container width

**Props:**
- `glyphs` - Array of characters
- `fontStyle` - Passed to each GlyphItem
- `glyphsGridRef` - Optional ref (not used in GlyphsSection)
- `className` - Additional classes

### Array Mapping Pattern

```jsx
{glyphs?.map((glyph, index) => (
  <GlyphItem key={index} glyph={glyph} fontStyle={fontStyle} />
))}
```

**React Pattern Explanation:**

**Optional Chaining (`?.`):**
- Safely accesses `.map()` even if `glyphs` is undefined/null
- Prevents runtime errors

**Arrow Function with Parentheses:**
```jsx
.map((item) => (
  <Component />
))
```

**Parentheses `( )` = Implicit return**
- Directly returns JSX without `return` keyword
- Use when you don't need logic before rendering

**Braces `{ }` = Explicit return required**
```jsx
.map((item) => {
  const processed = doSomething(item)
  return <Component data={processed} />
})
```

**Use when:**
- Need to run logic before returning
- Need multiple statements
- Need to declare variables

**In this case:** Simple direct mapping, so parentheses `( )` are used.

### Structure

**File:** `packages/ui/src/atoms/foundry/GlyphItem.jsx` (30 lines)

```jsx
<div
  className="hoverFlipTheme aspect-square border rounded-lg flex items-center justify-center text-3xl leading-none transition-colors duration-300 w-16 h-16"
```

**Props:**
- `glyph` - Single character to display
- `fontStyle` - 'normal' or 'italic' (default: 'normal')
- `className` - Additional classes

**Styling:**
- **Size:** `w-16 h-16` (64×64px), `aspect-square` enforces 1:1 ratio
- **Text:** `text-3xl` (30px), `leading-none` (tight line-height)
- **Border:** `rounded-lg` (8px), `border` (1px solid)
- **Layout:** `flex items-center justify-center` (centered glyph)
- **Interaction:** `hoverFlipTheme` (custom class that flips theme colors on hover)
- **Transition:** `transition-colors duration-300` (smooth color changes)

**Inline Styles:**
- `fontFamily: 'TGMalromur'` - Variable font
- `fontStyle: fontStyle` - Controlled by dropdown (italic/roman)
- `borderColor: 'var(--kol-border-default)'` - Adaptive theme color

### hoverFlipTheme Pattern

**Purpose:** On hover, swaps foreground and background colors

**Typical implementation:**
```css
.hoverFlipTheme:hover {
  background-color: var(--kol-surface-on-primary);
  color: var(--kol-surface-primary);
}
```

Creates visual feedback when hovering over individual glyphs.

## React Patterns Reference

### Conditional Rendering

**`&&` Pattern (Logical AND):**
```jsx
{condition && <Component />}
```
- If `condition` is false: renders nothing
- If `condition` is true: renders `<Component />`
- **Use case:** Show/hide without else branch

**Ternary Pattern:**
```jsx
{condition ? <ComponentA /> : <ComponentB />}
```
- If `condition` is true: renders `<ComponentA />`
- If `condition` is false: renders `<ComponentB />`
- **Use case:** Show one of two options (if/else)

**Both are standard React practice.** Choose based on readability and intent.

### Array Mapping

**Implicit Return (Parentheses):**
```jsx
{items.map((item) => (
  <Component key={item.id} value={item.value} />
))}
```
- Parentheses `( )` = automatic return
- No `return` keyword needed
- **Use when:** Directly rendering JSX

**Explicit Return (Braces):**
```jsx
{items.map((item) => {
  const processed = transform(item)
  return <Component key={item.id} value={processed} />
})}
```
- Braces `{ }` = function body, requires `return`
- **Use when:** Need logic before returning JSX

### Optional Chaining

```jsx
{glyphs?.map((glyph) => ...)}
```

- `?.` safely accesses `.map()` even if `glyphs` is null/undefined
- Prevents "Cannot read property 'map' of undefined" errors
- **Standard practice** for defensive programming
