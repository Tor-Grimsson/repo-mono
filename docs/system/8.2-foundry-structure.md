# 8.2 Foundry Structure

**Version:** 1.0
**Last Updated:** 2025-10-30
**Status:** Implementation reference for Foundry page
**Baseline:** `/apps/web/src/routes/Foundry.jsx`

> This chapter documents the **Foundry page structure** for showcasing the TG Málrómur typeface. For general structural guidelines, see [8.0 Div & Section Structure](./8.0-div-structure.md).

---

## Overview

The Foundry page demonstrates a **hybrid structural pattern** optimized for typeface presentation:

- Uses `.pagePadding` instead of `<main>` wrapper
- Most sections as direct children (no card-wrapper)
- Selected sections wrapped in main-wrapper + card-wrapper
- Consistent `py-12 lg:py-16` vertical padding
- Full-bleed image sections for visual rhythm
- Specialized components for typeface features

---

## Foundry Page Root Structure

```jsx
<div className="pagePadding pb-8 flex flex-col gap-6 md:gap-8 bg-surface-primary">
  {/* Hero section */}
  <FoundryHero />

  {/* Content sections - direct children */}
  <ImageSection src="/img/tgm/hero.png" alt="TG Málrómur showcase" />
  <FoundryStyleSection />
  <ImageSection src="/img/features/card-item-base-7.png" alt="Showcase" />
  <FontPreviewSection />
  <ImageSection src="/img/features/card-item-base-1.png" alt="Showcase" />
  <VariableFontSection />
  <FoundryCharacterSets />
  <ImageSection src="/img/features/card-item-base-6.png" alt="Showcase" />
  <FoundryOpentypeFeatures />

  {/* Feature card sections - no wrapper */}
  <FoundryTypefaceDetails />
  <FoundryLicenseQuestions />

  {/* Card sections - wrapped */}
  <div className="main-wrapper">
    <div className="card-wrapper">
      <FoundryTypefacePairing />
    </div>
    <div className="card-wrapper">
      <FoundryOtherTypefaces />
    </div>
  </div>

  {/* Footer CTA */}
  <CtaGlobal />
</div>
```

**Key Patterns:**
- `.pagePadding` provides consistent outer padding
- `gap-6 md:gap-8` creates responsive vertical rhythm
- ImageSection components provide visual breaks
- Only pairing and other typefaces sections use card-wrapper
- All sections use `py-12 lg:py-16` for consistent vertical spacing

- **Gap-6:** 24px between cards

```jsx
<div className="main-wrapper">
  <div className="card-wrapper">
```

- Mobile: 1 column, vertical stack
- Tablet: 2 columns (`md:grid-cols-2`)

- Gap-6 (24px) between all cards
- Hover: Border 8% → 24%, opacity 80% → 100%

## Structural Patterns

### Pattern 1: Full-Width Sections (No Wrapper)

**Used by:** `FoundryTypefaceDetails`, `FoundryLicenseQuestions`

```jsx
<section className="w-full py-12 lg:py-16">
  <div className="max-w-[1200px] mx-auto flex flex-col gap-8">
    {/* Content */}
  </div>
</section>
```

**Characteristics:**
- Direct children of root container (no card-wrapper)
- Manage own vertical padding (`py-12 lg:py-16`)
- Clean, open presentation
- Used for informational/metadata sections

### Pattern 2: Card-Wrapped Sections

**Used by:** `FoundryTypefacePairing`, `FoundryOtherTypefaces`

```jsx
<div className="main-wrapper">
  <div className="card-wrapper">
    <section className="w-full">
      <div className="max-w-[1200px] mx-auto flex flex-col gap-8">
        {/* Content */}
      </div>
    </section>
  </div>
</div>
```

**Characteristics:**
- Grouped together in single main-wrapper block
- Each wrapped in card-wrapper for subtle differentiation
- No section-level vertical padding (card-wrapper provides it)
- Used for interactive/showcase sections

### Pattern 3: Image Break Sections

**Used by:** `ImageSection` components

```jsx
<ImageSection src="/img/features/card-item-base-7.png" alt="Showcase" />
```

**Characteristics:**
- Full-bleed images
- Provides visual rhythm between content sections
- No padding or gap management
- Acts as visual divider

## Spacing Strategy

### Vertical Rhythm

The Foundry page uses **consistent vertical spacing** with responsive scaling:

```jsx
// Root container
<div className="pagePadding pb-8 flex flex-col gap-6 md:gap-8">
```

- **Mobile:** `gap-6` (24px) between sections
- **Desktop:** `md:gap-8` (32px) between sections

### Section Internal Padding

All content sections follow the same pattern:

```jsx
<section className="w-full py-12 lg:py-16">
```

- **Mobile:** `py-12` (48px) vertical padding
- **Desktop:** `lg:py-16` (64px) vertical padding

### Internal Content Gaps

Standard gap-8 (32px) between content blocks:

```jsx
<div className="flex flex-col gap-8">
```

### Special Cases

**License/Questions Section:**
- Mobile gap: `gap-24` (96px) - extra space for clarity
- Desktop gap: `md:gap-12` (48px) - compact side-by-side

**Pairing Cards:**
- Gap-4 (16px) between cards - tighter for related content

**Typeface Cards:**
- Gap-6 (24px) between cards - standard grid spacing

## Migration Notes

When creating new foundry-style pages:

1. ✓ Use `.pagePadding` for root container
2. ✓ Apply `gap-6 md:gap-8` for section rhythm
3. ✓ Use `py-12 lg:py-16` consistently for sections
4. ✓ Reserve card-wrapper for interactive/showcase sections
5. ✓ Use FoundrySection component for headers
6. ✓ Implement responsive grids with md/lg breakpoints
7. ✓ Use foreground opacity utilities for visual hierarchy
8. ✓ Add Image sections for visual rhythm
9. ✓ Keep content within `max-w-[1200px]`
10. ✓ Use active state tracking for interactive elements
