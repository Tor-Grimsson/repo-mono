# 8.0 Div & Section Structure

> **Baseline:** Home.jsx (as of 2025-10-29)
> **Purpose:** Standard patterns for page layout, section composition, spacing, and breakpoints
> **Status:** Canonical reference for all page structures (Foundry, Work, Stack, etc.)

## Overview

The Home page represents the **correct structural pattern** for building pages in the kolkrabbi design system. It demonstrates:

- Consistent wrapper hierarchy (main → main-wrapper → card-wrapper → section)
- Standardized spacing scales and breakpoints
- Proper surface context usage
- Mobile-first responsive patterns
- Component composition guidelines

---

## Root Container Pattern

### Main Element Structure
```jsx
<main className="min-h-screen w-full overflow-x-hidden">
  {/* Hero sections without wrapper */}
  <div>
    <HomeHero />
    <HomeAbout />
  </div>

  {/* Main content area */}
  <div className="main-wrapper">
    {/* Sections with card-wrapper... */}
  </div>

  {/* Footer CTA without wrapper */}
  <CtaGlobal />
</main>
```

**Key Characteristics:**
- `<main>` tag for semantic HTML
- `min-h-screen` ensures full viewport coverage
- `w-full` for full-width layouts
- `overflow-x-hidden` prevents horizontal scroll issues

## Section Wrapper Patterns

### 1. Hero Wrapper (No Card)
**Usage:** Full-bleed hero sections (HomeHero, HomeAbout)

```jsx
<div>
  <HomeHero onVideoStart={onVideoStart} />
  <HomeAbout />
</div>
```

**Characteristics:**
- No padding or gap utilities
- Sections manage their own spacing
- Full viewport control (h-dvh, w-screen)

### 2. Main Wrapper
**CSS Definition:** `packages/ui/css/utilities.css:79-81`

```css
.main-wrapper {
  @apply p-8 flex flex-col gap-8;
}
```

**Usage:** Primary content container

```jsx
<div className="main-wrapper">
  {/* Contains card-wrapper children */}
</div>
```

**Breakdown:**
- `p-8` = 32px padding (2rem) all sides
- `flex flex-col` = vertical stacking
- `gap-8` = 32px spacing between sections

### 3. Card Wrapper
**CSS Definition:** `packages/ui/css/utilities.css:83-87`

```css
.card-wrapper {
  background-color: color-mix(in srgb, var(--kol-surface-on-primary) 2%, transparent);
  border: 1px solid color-mix(in srgb, var(--kol-surface-on-primary) 8%, transparent);
  @apply p-8 rounded;
}
```

**Usage:** Individual section containers with subtle background

```jsx
<div className="card-wrapper">
  <HomeCardFeatures />
</div>
```

**Characteristics:**
- Subtle tinted background (2% on-primary)
- Border with 8% opacity for definition
- `p-8` = 32px internal padding
- `rounded` = border-radius

### 4. Hybrid Pattern (No Card-Wrapper)
**Usage:** Sections that need main-wrapper spacing but no card treatment

```jsx
<div className="">
  <HomeHighlights />
</div>
```

**Note:** Empty className indicates the section manages its own styling entirely

## Component Composition

### Section-Level Structure

All section components follow this internal pattern:

```jsx
const HomeComponent = () => {
  return (
    <section className="w-full">
      <div className="max-w-[1200px] mx-auto flex flex-col gap-8">
        {/* Section content */}
      </div>
    </section>
  )
}
```

**Breakdown:**
- `<section>` = semantic HTML5 element
- `w-full` = section fills parent width
- `max-w-[1200px]` = content constrains to 1200px
- `mx-auto` = centers content horizontally
- `flex flex-col` = vertical content flow
- `gap-8` = 32px spacing between content blocks

### Content Container Patterns

#### Pattern 1: Centered Content with Top Padding
```jsx
<div className="w-full flex flex-col gap-8 md:gap-10 max-w-[1200px] mx-auto">
  <div className="w-full pt-[224px]">
    <SectionLabel text="Selected Work" />
    {/* Header content */}
  </div>
  {/* Additional content */}
</div>
```

**Used by:** HomeCardFeatures
**Characteristics:**
- `pt-[224px]` = large top spacing for visual breathing room
- `gap-8 md:gap-10` = responsive gap scaling
- Constrains to 1200px max width

#### Pattern 2: Padding-Based Spacing
```jsx
<div className="w-full flex flex-col max-w-[1200px] mx-auto pt-24">
  {/* Content */}
</div>
```

**Used by:** HomeWorkFeatures
**Characteristics:**
- `pt-24` = 96px top padding (6rem)
- Simpler spacing approach

#### Pattern 3: Two-Column Layout
```jsx
<div className="max-w-[1200px] mx-auto">
  <div className="flex flex-col py-16 lg:flex-row gap-16">
    {/* Left: Fixed width image */}
    <div className="w-full lg:w-[400px] flex-shrink-0">
      <TiltCard src="/img/..." className="w-full aspect-[4/5]" />
    </div>

    {/* Right: Flexible content */}
    <div className="flex-1 py-16">
      {/* Content */}
    </div>
  </div>
</div>
```

**Used by:** HomeFoundry
**Characteristics:**
- `py-16` = 64px vertical padding (4rem)
- `gap-16` = 64px gap between columns (4rem)
- `lg:flex-row` = stack mobile, side-by-side desktop
- `lg:w-[400px]` = fixed image column width
- `flex-1` = content expands to fill remaining space

## Surface Context Hierarchy

### Context Definitions

The Home page uses surface tokens to create visual hierarchy:

**Primary Context (Default):**
```jsx
// Implicit - no className needed
<section className="w-full">
```
- Uses `var(--kol-surface-primary)` background
- Uses `var(--kol-surface-on-primary)` text

**Inverse Context (Dark on Light / Light on Dark):**
```jsx
<div className="bg-surface-inverse">
  <video src={theme === 'dark' ? 'videos/vid-nrml-inverse.mov' : 'videos/vid-nrml.mov'} />
</div>
```
- Uses `var(--kol-surface-inverse)` background
- Flips with theme changes

**Auto Text (Theme-Aware):**
```jsx
<p className="kol-heading-md text-auto">Kolkrabbi Vinnustofa</p>
```
- `text-auto` applies theme-aware text color
- Automatically adjusts to parent surface context

### Card-Wrapper Surface Treatment

```css
background-color: color-mix(in srgb, var(--kol-surface-on-primary) 2%, transparent);
border: 1px solid color-mix(in srgb, var(--kol-surface-on-primary) 8%, transparent);
```

Creates subtle differentiation without hard surface context change.

## Spacing Scale Reference

### Standard Gap Values

| Value | Pixels | Rem | Usage |
|-------|--------|-----|-------|
| `gap-2` | 8px | 0.5rem | Tight spacing (tags, small elements) |
| `gap-3` | 12px | 0.75rem | Form fields |
| `gap-5` | 20px | 1.25rem | Related content groups |
| `gap-6` | 24px | 1.5rem | Card grid items |
| `gap-8` | 32px | 2rem | **Standard section gap** (most common) |
| `gap-10` | 40px | 2.5rem | Enhanced section gap (md+ breakpoint) |
| `gap-12` | 48px | 3rem | Large section dividers |
| `gap-16` | 64px | 4rem | Major layout divisions |

### Standard Padding Values

| Value | Pixels | Rem | Usage |
|-------|--------|-----|-------|
| `p-6` | 24px | 1.5rem | Tight card padding (mobile) |
| `p-8` | 32px | 2rem | **Standard padding** (main-wrapper, card-wrapper) |
| `p-12` | 48px | 3rem | Hero text overlays |
| `py-16` | 64px (V) | 4rem | Section vertical padding |
| `py-24` | 96px (V) | 6rem | Large section padding |
| `pt-[224px]` | 224px | 14rem | Hero offset spacing (HomeCardFeatures) |

### Responsive Padding Patterns

```jsx
// Mobile-to-desktop progression
<div className="p-6 md:p-8">
  {/* 24px → 32px */}
</div>

// Vertical-only responsive
<div className="py-16 lg:py-24">
  {/* 64px → 96px */}
</div>
```

## Breakpoint Strategy

### Tailwind Breakpoint System

```js
// tailwind.config.js (default)
{
  sm: '640px',
  md: '768px',
  lg: '1024px',
  xl: '1280px',
  '2xl': '1536px'
}
```

### Mobile-First Philosophy

**All base styles are mobile.**
Breakpoint prefixes (`md:`, `lg:`) apply **upward** from that size.

```jsx
// Base = mobile, md+ = tablet/desktop
<div className="flex-col md:flex-row">
```

**Reads as:**
- Mobile (< 768px): `flex-col` (vertical stack)
- Tablet/Desktop (≥ 768px): `flex-row` (horizontal)

### Home Page Breakpoint Patterns

#### 1. Gap Scaling
```jsx
<div className="gap-8 md:gap-10">
```
- Mobile: 32px gap
- Tablet+: 40px gap

#### 2. Grid Columns
```jsx
<div className="grid gap-12 md:grid-cols-3">
```
- Mobile: 1 column (implicit)
- Tablet+: 3 columns

#### 3. Layout Direction
```jsx
<div className="flex flex-col lg:flex-row gap-16">
```
- Mobile/Tablet: Vertical stack
- Desktop (≥ 1024px): Horizontal layout

#### 4. Fixed Width Columns
```jsx
<div className="w-full lg:w-[400px] flex-shrink-0">
```
- Mobile: Full width
- Desktop: 400px fixed width

#### 5. Content Visibility
```jsx
{/* Mobile/MD: ArticleCardMini */}
<div className="flex flex-col gap-8 lg:hidden">
  {articles.map(article => <ArticleCardMini />)}
</div>

{/* LG+: ArticleCardHero */}
<div className="hidden lg:grid gap-12 lg:grid-cols-3">
  {articles.map(article => <ArticleCardHero />)}
</div>
```

**Pattern:** Different component variants per breakpoint

#### 6. Height Scaling
```jsx
<div className="h-[640px]">
```
- Fixed height cards maintain aspect ratio
- No responsive height changes in current implementation

## Grid & Flex Patterns

### Flex Patterns

#### Standard Vertical Stack
```jsx
<div className="flex flex-col gap-8">
```
**Usage:** Default section content flow

#### Responsive Direction Change
```jsx
<div className="flex flex-col py-16 lg:flex-row gap-16">
```
**Usage:** Two-column layouts (HomeFoundry)

#### Center Alignment
```jsx
<div className="flex flex-col items-center justify-center text-center">
```
**Usage:** CTA sections (HomeSignup)

#### Inline-Flex with Direction
```jsx
<div className="inline-flex flex-col md:flex-row md:h-72 gap-6">
```
**Usage:** Feature card grids (HomeCardFeatures)

### Grid Patterns

#### Responsive Column Grid
```jsx
<div className="grid gap-12 md:grid-cols-3">
```
**Usage:** Blog articles (CmsGlobal)
- Mobile: Auto 1 column
- Tablet+: 3 columns

#### Fixed Height Rows (Bento)
```jsx
<div className="self-stretch h-[640px] rounded inline-flex">
```
**Usage:** HomeHighlights bento cards
- `self-stretch` = fills parent width
- `h-[640px]` = fixed card height
- `inline-flex` = flex container for card content

#### Split Layout Grid
```jsx
<div className="self-stretch h-[640px] inline-flex gap-8">
  <BentoCard className="flex-1" />
  <div className="flex-1 inline-flex flex-col gap-6">
    <BentoCard className="self-stretch flex-1" />
    <BentoCard className="self-stretch flex-1" />
  </div>
</div>
```
**Usage:** Asymmetric layouts (HomeHighlights row 3)
- Left: Single large card (`flex-1`)
- Right: Two stacked cards in nested container

## Common Section Types

### 1. Hero Section (Full Viewport)

**Example:** HomeHero

```jsx
<div className="relative h-dvh w-screen overflow-x-hidden">
  <div id="video-frame" className="relative z-10 h-dvh w-screen bg-surface-inverse">
    <video />
    {/* Overlays */}
  </div>
</div>
```

**Characteristics:**
- `h-dvh` = dynamic viewport height (mobile-safe)
- `w-screen` = full viewport width
- `overflow-x-hidden` = prevents horizontal scroll
- `relative` + `z-index` = layering control

---

### 2. Animated Section (Scroll-Triggered)

**Example:** HomeAbout

```jsx
<div id="studio" className="min-h-screen w-screen">
  <div className="relative mb-8 mt-36 flex flex-col items-center gap-5">
    {/* Content */}
  </div>
  <div className="h-dvh w-screen" id="clip">
    <div className="mask-clip-path aboutImage">
      <img />
    </div>
  </div>
</div>
```

**Characteristics:**
- `min-h-screen` = at least full viewport
- `mt-36` = 144px top margin (9rem)
- GSAP scroll triggers on `#clip` ID

### 3. Feature Grid Section

**Example:** HomeCardFeatures

```jsx
<section className="w-full">
  <div className="w-full flex flex-col gap-8 md:gap-10 max-w-[1200px] mx-auto">
    {/* Header */}
    <div className="w-full pt-[224px]">

    <div className="inline-flex flex-col md:flex-row md:h-72 gap-6">

    {/* Actions */}
```

**Pattern:**
1. Section wrapper (`w-full`)
2. Content container (max-width + centering)
3. Header area (label + description)
4. Grid area (responsive columns)
5. Actions area (buttons)

## Anti-Patterns to Avoid

### 1. Inconsistent Wrapper Usage
**Bad:**
```jsx
<section className="p-8 max-w-[1200px] mx-auto">
  {/* Replicating main-wrapper styles manually */}
</section>
```

**Good:**
```jsx
<div className="main-wrapper">
  <div className="card-wrapper">
    <section className="w-full">
      {/* Section manages internal structure only */}
    </section>
  </div>
</div>
```

---

### 2. Hardcoded px Values Instead of Tailwind
**Bad:**
```jsx
<div style={{ padding: '32px', gap: '32px' }}>
```

**Good:**
```jsx
<div className="p-8 gap-8">
```

**Exception:** Intentional custom values like `pt-[224px]` when no Tailwind value fits

---

### 3. Breaking Mobile-First Pattern
**Bad:**
```jsx
<div className="flex-row sm:flex-col">
  {/* Desktop-first approach */}
</div>
```

**Good:**
```jsx
<div className="flex-col md:flex-row">
  {/* Mobile-first approach */}
</div>
```

---

### 4. Mixing w-screen with Container Constraints
**Bad:**
```jsx
<section className="w-screen max-w-[1200px] mx-auto">
  {/* w-screen overrides max-width */}
</section>
```

**Good:**
```jsx
{/* Hero sections */}
<div className="w-screen">

{/* Content sections */}
<section className="w-full">
  <div className="max-w-[1200px] mx-auto">
```

---

### 5. Inconsistent Gap Scaling
**Bad:**
```jsx
<div className="gap-6 md:gap-12 lg:gap-20">
  {/* Too many breakpoint changes */}
</div>
```

**Good:**
```jsx
<div className="gap-8 md:gap-10">
  {/* Single responsive step */}
</div>
```

---

### 6. Overusing Arbitrary Values
**Bad:**
```jsx
<div className="pt-[47px] pb-[93px] gap-[22px]">
  {/* Random values with no system */}
</div>
```

**Good:**
```jsx
<div className="py-16 gap-6">
  {/* System values: 64px, 24px */}
</div>
```

**Exception:** Intentional custom spacing like `pt-[224px]` for specific design needs

---

### 7. Nested Surface Context Conflicts
**Bad:**
```jsx
<div className="bg-surface-primary">
  <div className="bg-surface-inverse">
    <p className="text-auto">
      {/* Ambiguous context nesting */}
    </p>
  </div>
</div>
```

**Good:**
```jsx
<div className="bg-surface-inverse">
  {/* Clear single context */}
  <p className="text-auto">{/* Auto adapts to inverse */}</p>
</div>
```

---

### 8. Ignoring Semantic HTML
**Bad:**
```jsx
<div className="w-full">
  <div className="max-w-[1200px] mx-auto">
    {/* No semantic meaning */}
  </div>
</div>
```

**Good:**
```jsx
<section className="w-full">
  <div className="max-w-[1200px] mx-auto">
    {/* Clear section boundary */}
  </div>
</section>
```

---

### 9. Over-Specifying Flex Properties
**Bad:**
```jsx
<div className="flex flex-row flex-wrap justify-start items-start">
  {/* Too many default values */}
</div>
```

**Good:**
```jsx
<div className="flex flex-wrap">
  {/* flex-row, justify-start, items-start are defaults */}
</div>
```

---

### 10. Missing Responsive Image Constraints
**Bad:**
```jsx
<img src="/img/..." />
{/* No width/height control */}
```

**Good:**
```jsx
<TiltCard className="w-full aspect-[4/5]" />
{/* or */}
<img src="/img/..." className="w-full h-auto object-cover" />
```

## Usage Guidelines

### When to Use main-wrapper
- Primary content area after hero sections
- Contains multiple card-wrapper sections
- Provides consistent padding and gap

### When to Use card-wrapper
- Individual feature sections
- Content that needs subtle background differentiation
- Maintains consistent padding across sections

### When to Use Neither
- Hero sections (full-bleed)
- Footer CTAs
- Sections that manage their own complete styling
- Bento grids that need direct control

### Migration Checklist

When refactoring pages (Foundry, Work, Stack):

1. Use `<main className="min-h-screen w-full overflow-x-hidden">`
2. Separate hero sections from main content
3. Wrap main content in `.main-wrapper`
4. Wrap individual sections in `.card-wrapper` (unless full-bleed)
5. Sections use `<section className="w-full">`
6. Content containers use `max-w-[1200px] mx-auto`
7. Use `gap-8` as default, `md:gap-10` for responsive
8. Use `py-16` or `py-24` for vertical section padding
9. Apply mobile-first breakpoints (md, lg)
10. Use semantic HTML (`<section>`, `<main>`, `<article>`)
