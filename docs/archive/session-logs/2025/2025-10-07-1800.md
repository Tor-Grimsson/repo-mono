## Notes
**Key Design Decisions:**
- Used flexbox `gap` instead of `space-y-*` because grid children don't work with space utilities
- Responsive grid rows require custom CSS classes (can't use inline styles with media queries)
- Text clipping must use React state, not direct DOM manipulation, to avoid fighting React reconciliation
- Compact mode isolates layout changes with utility classes to avoid complex conditional Tailwind classes
- Safety margin approach prevents partial line visibility but may clip too aggressively - needs real-world testing
