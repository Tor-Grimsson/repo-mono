## Notes
**Key Pattern - Style Button with Hover:**
```css
@utility styleButtonWithHover {
  background-color: rgba(0, 0, 0, 0.1);
  color: var(--color-text-primary);
  transition: background-color 0.3s, color 0.3s;

  &:hover {
    background-color: var(--color-brand-dark);
    color: var(--color-brand-light);
  }

  :is([data-theme="dark"], .dark) & {
    background-color: rgba(255, 255, 255, 0.1);

    &:hover {
      background-color: var(--color-brand-light);
      color: var(--color-brand-dark);
    }
  }
}
```

**Button Patterns:**
- **Primary**: Solid base → subtle on hover (opposite of secondary)
- **Secondary**: Subtle base → solid on hover (matches style buttons)
- Both flip correctly in dark mode

**Design Insight:**
- Inline styles override CSS hover states - remove inline backgrounds to allow hover effects
- Color contrast creates optical illusion - same font-weight appears heavier on inverted backgrounds
- `var(--color-accent-red)` automatically flips red→yellow in dark mode per theme.css
