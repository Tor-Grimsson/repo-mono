**Critical Discovery:** The content package has TWO schema locations:
- ❌ `packages/content/schemas/` - This was an incorrect duplicate I was editing
- ✅ `packages/content/src/schemas/types/` - This is the actual schema location used by Studio

The blog schema is at `packages/content/src/schemas/types/blog.ts` and exports happen through `src/schemas/index.ts`.

**Code Block Data Structure:** The @sanity/code-input plugin provides data as:
```javascript
{
  _type: 'code',
  language: 'javascript',
  code: 'const foo = "bar";',
  filename: 'optional.js' // if withFilename: true
}
```

This maps perfectly to our CodeBlock component which expects `{ language, code, filename }`.

**Import Chain:**
1. `packages/content/index.ts` → exports from `./src/schemas`
2. `packages/content/src/schemas/index.ts` → exports `schemaTypes` array including `blog`
3. `apps/studio/sanity.config.ts` → imports `schemaTypes` from `@kol/content`
