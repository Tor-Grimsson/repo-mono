**Critical CSS Classes Created:**

- `.hover-flip-theme`: Inverts theme colors on hover - light mode flips to dark (brand-dark bg, brand-light text), dark mode flips to light (brand-light bg, brand-dark text)

**Important:** ALL inline color styles must be removed from elements using hover-flip-theme, otherwise the hover won't work properly. The class sets base color to `var(--color-text-primary)` and flips it on hover.

**For Next Agent:** The hover-flip-theme implementation required removing ALL inline color styles from child elements. If hover isn't working, check for `style={{ color: 'var(--color-text-*)' }}` attributes and remove them.
