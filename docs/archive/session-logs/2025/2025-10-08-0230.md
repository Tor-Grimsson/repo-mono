## Notes
**IMPORTANT FOR FUTURE SESSIONS:**

The MODE-ADAPTIVE STYLES section in `packages/ui/theme.css` (lines 431-486) is the canonical location for all light/dark mode color switching classes.

**DO NOT create new mode-adaptive styles elsewhere.** Always:
1. Check if a suitable class exists in this section first
2. If creating new mode-adaptive styles, add them to this section with clear documentation
3. Use `.pill-inverse` for full black/white inversion
4. Use `.pill-subtle` for neutral gray backgrounds that adapt
5. Keep `.control-unified*` classes for Foundry-specific controls only

This prevents the pattern of repeatedly creating duplicate "inverted" or "site-specific" styles scattered throughout the codebase.

Contact section uses absolute colors (#000000/#ffffff) because it needs to stay inverted from the page theme (dark card in light mode, light card in dark mode). The inner styles handle this with !important overrides.

Blog/Article components use the new pill classes which are reusable and theme-aware.
