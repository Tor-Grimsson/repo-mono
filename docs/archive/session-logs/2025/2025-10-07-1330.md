## Notes
**Key Learning:**
- Inline styles have higher specificity than CSS classes - remove them to allow CSS control
- The `.dark` class is meant for parent-level theme switching, not individual component inversion
- Use variant utilities like `foundryCardInverted` for component-level contrast toggling
- User prefers step-by-step collaborative work vs. batch changes

**CSS Pattern Used:**
```css
&Inverted {
  background-color: #000000;
  color: #ffffff;

  :is([data-theme="dark"], .dark) & {
    background-color: #ffffff;
    color: #000000;
  }
}
```
