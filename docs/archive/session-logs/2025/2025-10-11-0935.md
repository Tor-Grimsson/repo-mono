## Notes
**Code Block Styling Strategy:**
- Main `.code-block` container: Only element with border, background, padding
- All nested elements (`*`, `pre`, `code`, `div`, `span`): No borders, transparent backgrounds
- This prevents overlapping borders and stroke artifacts
- Universal selector `.code-block *` ensures ALL children are clean

**Wrapping Configuration:**
- CSS: `white-space: pre-wrap`, `word-break: break-word`
- Component: `wrapLines={true}`, `wrapLongLines={true}`
- This preserves formatting while wrapping long lines

**Key CSS Rules Added:**
```css
.code-block * {
  border: none !important;
  outline: none !important;
  box-shadow: none !important;
}
```

This nuclear approach eliminates all potential border/stroke sources from nested elements.
