## Notes
**Font Family Setup:**
TGMalromur now has proper roman + italic linking:
```css
@font-face {
  font-family: 'TGMalromur';
  src: url('/fonts/TGMalromurRomanVF.ttf') format('truetype');
  font-weight: 100 900;
  font-style: normal;
}

@font-face {
  font-family: 'TGMalromur';
  src: url('/fonts/TGMalromurItalicVF.ttf') format('truetype');
  font-weight: 100 900;
  font-style: italic;
}
```

This allows the 16 styles in StylesSection (8 weights × 2 variants) to properly toggle between upright and italic using the same family name.
