## Notes
**Critical Refactoring Pattern:**
When migrating CSS to Tailwind utilities, we learned:
1. Create standalone base utilities first
2. Add nested overrides in parent utilities using `&` selector
3. Update both CSS definitions AND component usage atomically to avoid disconnection
4. For Tailwind v4: use camelCase for custom utilities, not kebab-case

**Utility Class Structure:**
```css
/* Base utility - standalone */
@utility fpsMainWrapper {
  /* base styles */
}

/* Parent utility with nested overrides */
@utility fpsCompactControls {
  & .fpsMainWrapper {
    /* override styles */
  }
}
```

**foundryCard Pattern:**
```css
@utility foundryCard {
  /* base: background, border-radius, transition */

  &Padded {
    /* adds responsive padding */
  }

  &Inverted {
    /* inverts colors for contrast */
  }
}
```

Usage: `className="foundryCard foundryCardPadded"` or `className="foundryCard foundryCardInverted"`
