# Documentation Archive

This folder preserves historical context without overloading the default documentation set.

## Structure
- `plans/` – superseded migration plans and proposals that have already been executed.
- `research/` – legacy audits, competitive research, and exploratory notes.
- `session-logs/<year>/` – past session transcripts older than the current active cycle.

Keep the most recent checkpoints inside `docs/SESSION-LOGS/` so new agents only scan the latest work. When archiving, move whole files into the appropriate subfolder and update any links if a doc is still referenced elsewhere.
