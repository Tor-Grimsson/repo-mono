## Current State

### Working
- `/icons` renders. Loads ~860 icons (367 live + 493 stroke), filters / search / view-mode toggle / click-zoom all functional. Sidebar updated.

### Known issue (unresolved)
- The `remake` set was generated by mechanically flipping `fill="X"` → `fill="none" stroke="X"`. This produces **boundary strokes** (silhouette of the filled glyph) rather than **trace strokes** (polylines through space). Wrong for trace-meaning glyphs (checks, arrows, `+ − ×`, chevrons, math, clock hands). Right for region-meaning glyphs (rect, circle, folder, file, eye-outline, lock body, bell).
- No replacement path: every stroke-native external library (Lucide / Phosphor / Heroicons / Feather / Tabler / Iconoir) is MIT or ISC and requires attribution. User does not want license attribution in the project. So replacement requires hand-redraw.
- Auto-flipped trace icons remain in place pending triage.
