### Phase 6c — Canvas organism (pan extraction)
- `Canvas.jsx` — added `panEnabled` prop. When set, wraps the existing letterbox in `<PanViewport>`. PanViewport owns Space-key + drag pan + cursor switch. Pointer events on the transform layer suppressed while Space held so layer-level mousedowns don't fire mid-pan. Decorative chrome (grid bg / dark bg) stays at consumer level — Canvas only provides letterbox + pan.
- `GeneratorLayout.jsx` — 121 → 55 lines. Dropped all pan state, key listeners, drag listeners. Stage column keeps `kol-grid-bg + #0E0E11 + select-none + overflow-hidden`. Renders `<Canvas panEnabled>` for `stage` mode. `rawStage` mode is consumer-controlled (SocialLab "All" multi-aspect view no longer pans — acceptable; multi-canvas pan is unusual UX).
- `compose/CanvasArea.jsx` — added `panEnabled`. CanvasArea's existing keyboard listener (Escape/Backspace/Arrows/cmd+Z) coexists with PanViewport's Space-only listener; no conflict. Layer-mousedown continues to work because PanViewport returns early when `!spaceHeld`. While Space held, transform layer's `pointer-events: none` cascades to the inner stage div, suppressing layer mousedowns AND letting PanViewport's `cursor: grab` show through.
- File location stays at `src/components/generators/Canvas.jsx` for now (move to `organisms/` deferred — same module, same import shape, not blocking).
