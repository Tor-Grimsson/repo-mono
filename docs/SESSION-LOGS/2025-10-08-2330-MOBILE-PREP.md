## Industry Standards Research

### What to DISABLE on Touch (Reference: Apple.com, Stripe.com, Awwwards winners):
- ❌ Hover states (`:hover` pseudo-class)
- ❌ Mouse-only interactions (`onMouseMove` without `onTouch` equivalent)
- ❌ 3D tilt effects (poor performance + no natural gesture)
- ❌ Cursor-following effects (no cursor exists)
- ❌ Complex parallax on scroll (mobile GPU strain)
- ❌ Scroll pinning on mobile (janky, especially iOS Safari)

### What to KEEP on Touch:
- ✅ Tap/Click (`onClick` → `onTouchEnd`)
- ✅ Scroll animations (ScrollTrigger without pin)
- ✅ Swipe gestures (if implemented)
- ✅ Direct manipulation (drag, pinch)
- ✅ Auto-playing videos (with `playsInline`)

### **Phase 4: Story Section**
**Task**: Disable 3D tilt on touch, keep mask movement
- **File**: `apps/web/src/components/sections/home/Story.jsx`
- **Change**: Skip `rotateX/rotateY` animation on touch events
- **Code**:
  ```jsx
  const handleMove = (e) => {
    const isTouchEvent = e.type.startsWith('touch')

    // Always update mask position
    gsap.set(overlayEl, { '--x': `${x}px`, '--y': `${y}px` })

    // Only apply 3D tilt on mouse (not touch)
    if (!isTouchEvent) {
      gsap.to(imageEl, { rotateX, rotateY, ... })
    }
  }
  ```
- **Result**: Desktop gets full interaction, mobile gets mask reveal only (no awkward tilt on drag)

## Performance Considerations

### Mobile GPU Limitations:
- 3D transforms (`rotateX/rotateY`) trigger compositing layers
- Multiple simultaneous transforms = frame drops
- ScrollTrigger pin = layout recalculation overhead
- Touch events fire rapidly = GSAP animation queue buildup

### Optimizations Applied:
- Remove 3D transforms on touch devices
- Disable scroll pinning on small screens
- Keep only essential animations (mask reveals, scroll-driven)
- Maintain video autoplay (GPU-accelerated)
