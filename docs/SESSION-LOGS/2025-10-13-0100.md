## Notes

### Key Implementation Details

**ProjectDial Architecture:**
- Uses `itemsRef` array to track individual pill elements
- `updatePositions()` function calculates x/y from angle and applies via gsap.set
- Rotation stored in `rotationRef.current`, not in React state (performance)
- Items positioned at `top-1/2 left-1/2` then transformed with x/y offsets
- No parent container rotation - prevents text from flipping

**Momentum Physics:**
- Tracks velocity during drag (degrees/millisecond)
- On release: calculates throw velocity vs base velocity
- GSAP timeline: 3-second ease from throw speed to base speed (power2.out)
- Then continues infinitely at base speed in same direction
- Direction preserved based on velocity sign

**Responsive Strategy:**
- Radius scales with viewport width
- Typography scales at lg breakpoint (1024px)
- Pill padding remains constant
- Container has maxWidth to prevent overflow

**Color Token Usage:**
- Pills: `var(--surface-inverse)` bg + `var(--foreground-inverse)` text
- Circle: `var(--foreground)` at opacity 1
- All theme-aware, no hardcoded colors
