## Notes
**Key Learnings:**
- Inline styles override CSS classes - use rgba() in inline styles to control opacity while preserving class-based color flipping
- Check dark mode with `document.documentElement.classList.contains('dark')` to dynamically adjust styles
- Viewport-relative values (like `window.innerHeight * 0.08`) adapt better than fixed pixels for responsive margins
- User prefers asking questions first to understand goals before implementing

**CSS Pattern - Standalone Utilities:**
```css
@utility foundryCardInverted {
  background-color: #000000;
  color: #ffffff;
}

.dark .foundryCardInverted {
  background-color: #ffffff;
  color: #000000;
}
```

**Responsive Safety Margin:**
```javascript
const safetyMargin = Math.min(Math.max(40, window.innerHeight * 0.08), 120)
```
Scales with viewport height, clamped between 40px-120px.
