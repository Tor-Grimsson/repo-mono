## Overview

The workshop search overlay (`Cmd+K`) indexes page content — not just titles — so users can find icon names, color tokens, typography classes, component names, and more.

## How It Works

### Keyword Map

`apps/web/src/data/workshop/navigation.js` defines a `routeKeywords` object that maps route child IDs to arrays of searchable strings, pulled from existing data sources at build time:

| Route ID | Source | Example keywords |
|----------|--------|-----------------|
| `colors` | `colorGroups`, `layerPairs`, `utilitySwatches` from `tokens.js` | `--kol-surface-primary`, `bg-fg`, `border-surface` |
| `typography` | `typographyScale` from `tokens.js` | `kol-display-lg`, `kol-heading-xl`, `Right Grotesk` |
| `icons` | `icons` array from `Icons.jsx` | `chevron-down`, `chess-pawn`, `stat-stat` |
| `spacing` | `spacingScale` from `tokens.js` | `--spacing-1`, `--spacing-4` |
| `atoms` | `componentAtoms` from `tokens.js` | `Button Primary`, `Pill`, `Slider` |
| `molecules` | `componentMolecules` from `tokens.js` | `Theme Toggle`, `Section Toggle` |
| `organisms` | `componentOrganisms` from `tokens.js` | `Foundry Font Preview` |

### Search Filter

`packages/ui/src/layout/ShellSearchOverlay.jsx` checks four fields per item:

1. **label** — page title (always checked)
2. **tags** — frontmatter/inline tags (docs only)
3. **headings** — H2 headings from markdown (docs only)
4. **keywords** — content keywords from `routeKeywords` (workshop routes)

When a match comes from a keyword (and not the label or a heading), the matched keyword is shown beneath the result as `⤷ keyword-name`.

## Files

| File | Role |
|------|------|
| `apps/web/src/data/workshop/navigation.js` | `routeKeywords` map + `buildWorkshopSearchItems()` |
| `apps/web/src/data/workshop/tokens.js` | Color, typography, spacing, component data |
| `apps/web/src/routes/workshop/Icons.jsx` | Exports `icons` array |
| `packages/ui/src/layout/ShellSearchOverlay.jsx` | Search filter + keyword match display |

## Adding Keywords to a New Page

1. Export a data array from the page file (or add it to `tokens.js`)
2. Import it in `navigation.js`
3. Add an entry to `routeKeywords` keyed by the route child's `id`

No changes needed in the search overlay — it reads `keywords` automatically.
