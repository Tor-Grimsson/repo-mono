## Overview

Shared React hooks used across workshop pages.

## useSectionExpansion

**File:** `apps/web/src/components/workshop/useSectionExpansion.js`

Wraps `useStyleguideExpansion` (the shared expansion context) with convenience helpers for section toggle state. Eliminates boilerplate that was previously repeated in every workshop page.

### API

```js
const { sections, toggleSection, allExpanded, toggleAll } = useSectionExpansion(pageKey, defaults)
```

| Param | Type | Description |
|-------|------|-------------|
| `pageKey` | `string` | Unique key for the page (e.g. `'dashboard-components'`) |
| `defaults` | `object` | Initial section states, e.g. `{ 'section-a': false, 'section-b': false }` |

### Returns

| Property | Type | Description |
|----------|------|-------------|
| `sections` | `object` | Current section states keyed by section ID |
| `toggleSection` | `(sectionId: string) => void` | Toggle a single section |
| `allExpanded` | `boolean` | `true` when every section is expanded |
| `toggleAll` | `() => void` | Expand all if any collapsed, collapse all if all expanded |

### Usage

```jsx
import useSectionExpansion from '../../components/workshop/useSectionExpansion'

export default function MyPage() {
  const { sections, toggleSection, allExpanded, toggleAll } = useSectionExpansion('my-page', {
    'intro': false,
    'details': false,
  })

  return (
    <div>
      <DesPage title="My Page" allExpanded={allExpanded} onToggleAll={toggleAll} />
      <SectionToggle
        label="Intro"
        isExpanded={sections['intro']}
        onToggle={() => toggleSection('intro')}
      />
    </div>
  )
}
```

### Context

State is persisted in `StyleguideExpansionProvider` (wraps the workshop shell in `App.jsx`), so section states survive navigation between pages.
