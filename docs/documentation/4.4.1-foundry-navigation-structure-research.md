# 4.4.1 Foundry Navigation Structure Research

**Date**: November 8, 2024
**Status**: Research & Planning
**Decision**: Option A - Foundry as Hub with Sub-Navigation ⭐

---

## Overview

This document explores navigation structures for the Kolkrabbi Foundry section, focusing on how to organize typeface specimens, prose style demonstrations, and future font releases in an intuitive, scalable hierarchy.

---

## Current Structure (Flat)

```
Navbar
├── Home
├── Work
├── Foundry (single page with cards)
│   └── Shows 5 specimen cards, click goes directly to specimen
├── Stack
└── Collections
```

**Issues**:
- No hierarchy or organization
- Prose Styles specimen buried in card 3
- No room for future collections (Sans Serif, Display)
- No way to browse "all specimens"

---

## Proposed Options

### Option A: Foundry as Hub with Sub-Navigation ⭐ (SELECTED)

```
Navbar
├── Home
├── Work
├── Foundry ▾ (dropdown/submenu)
│   ├── Overview (main foundry landing /foundry)
│   │   ├── Featured Typeface Section
│   │   ├── About the Foundry
│   │   └── Quick Links to Specimens
│   │
│   ├── Specimens (organized index)
│   │   ├── /foundry/specimens (overview of all)
│   │   │   ├── Serif Collection
│   │   │   ├── Sans Serif Collection (future)
│   │   │   └── Display Collection (future)
│   │   │
│   │   └── Individual Specimens
│   │       ├── /specimen/one (TG RÓT)
│   │       ├── /specimen/two (TG MÁLRÓMUR)
│   │       ├── /specimen/prose (Prose Styles Overview)
│   │       │   └── /specimen/three (Full Prose Specimen)
│   │       ├── /specimen/four (TG TRÖLLATUNGA)
│   │       └── /specimen/five (TG LÓGARTEXTI)
│   │
│   ├── Prose Styles ⭐ (special highlight)
│   │   └── /specimen/prose (direct link)
│   │
│   └── Purchase/Licensing (future)
│       └── /foundry/purchase
│
├── Stack
└── Collections
```

**Benefits**:
- Clear hierarchy and organization
- Room for future expansion (Sans, Display)
- Highlights special content (Prose Styles)
- Maintains clean top-level navigation
- All foundry content under one umbrella

**Why This Was Selected**:
- Scalable architecture for future font releases
- Logical grouping of related content
- Special emphasis on Prose Styles (our unique offering)
- Professional foundry site pattern

### Option C: Keep It Simple

```
Navbar
├── Home
├── Work
├── Foundry
│   └── /foundry (current page - shows 5 cards)
│
├── Specimens ▾ (NEW top-level item)
│   ├── Overview → /foundry/specimens
│   ├── Prose Styles → /specimen/prose ⭐
│   ├── Serif Collection
│   └── All Specimens
│
├── Stack
└── Collections
```

**Benefits**:
- Separates foundry info from specimens
- Top-level access to specimens
- Simple to understand

**Drawbacks**:
- Breaks up related content
- Top-level navigation gets crowded
- Foundry feels empty without specimens

## New Page Concepts

### 1. Style Specifications Table

**Route**: `/specimen/prose/specs` or embedded in `/specimen/prose`

**Purpose**: Technical reference showing exact typography settings for each prose style

**Content Structure**:
```
Prose Style Specifications

[Table Format]
Style         | Size    | Weight  | Leading | Tracking | Use Case
──────────────┼─────────┼─────────┼─────────┼──────────┼─────────────
Editorial     |         |         |         |          |
  - Headline  | 64px    | 500     | 1.0     | 0        | Display
  - Body      | 16px    | 400     | 1.5     | 0        | Reading
  - Sidebar   | 14px    | 400     | 1.4     | 0        | Captions

Data Table    |         |         |         |          |
  - Headers   | 12px    | 600     | 1.2     | 0.05em   | Labels
  - Data      | 14px    | 400     | 1.4     | 0        | Content
  - Footnote  | 12px    | 400     | 1.4     | 0        | Attribution

Menu Design   |         |         |         |          |
  - Category  | 16px    | 600     | 1.3     | 0.1em    | Headers
  - Items     | 14px    | 400     | 1.4     | 0        | Content
  - Prices    | 14px    | 400     | 1.4     | 0        | Numeric

[etc for all 8 styles]
```

**Features**:
- Downloadable as PDF/CSV
- Copy-to-clipboard for individual rows
- Toggle between px/rem/em units
- Show/hide advanced properties (kerning, OpenType features)
- Interactive - click to see live example

**Visual Design**:
- Clean, scannable table
- Monospace for numeric values
- Color-coded by category
- Responsive: cards on mobile, table on desktop

1. TG RÓT - Display serif, Icelandic text

- Bauhaus layouts
- Technical documentation

- Signage systems

- Brand applications

- Easier maintenance

## Design System Integration

### Typography Scale

All specimens should use consistent scale:

```css
/* Display */
text-7xl   - 72px  - Main titles
text-6xl   - 60px  - Section titles
text-5xl   - 48px  - Subsection titles

/* Body */
text-4xl   - 36px  - Large body
text-3xl   - 30px  - Regular body
text-2xl   - 24px  - Small body
text-xl    - 20px  - Caption
text-base  - 16px  - Fine print
text-sm    - 14px  - Micro copy
text-xs    - 12px  - Legal text
```

### Color Palette

```css
/* Backgrounds */
bg-[#F5F1E8]  - Cream (specimen pages)
bg-white      - White (clean pages)
bg-black      - Black (accents)

/* Accents */
bg-[#E8DCC0]  - Darker cream (sidebars)
bg-orange-100 - Orange (special specimens)
```
