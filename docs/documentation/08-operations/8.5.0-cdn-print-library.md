## Overview

The print store uses a centralized data file (`apps/web/src/data/prints.js`) with images served from the Backblaze B2 CDN.

---

## CDN Structure

**Base URL**: `https://f005.backblazeb2.com/file/kolkrabbi/website/art-prints`

### Per-Print Folder Structure

```
art-prints/
└── print-{folder}/
    ├── master/
    │   └── {name}_print-master.tif
    ├── print/
    │   ├── {name}_print-A1.tif
    │   ├── {name}_print-A2.tif
    │   ├── {name}_print-A3.tif
    │   └── {name}_print-A4.tif
    └── web/
        ├── {name}-400.jpg
        ├── {name}-800.jpg
        ├── {name}-1200.jpg
        └── {name}-2000.jpg
```

### Web Image Sizes

| Size | Dimensions | Usage |
|------|-----------|-------|
| 400 | ~400px wide | Thumbnails |
| 800 | ~800px wide | Grid cards, default `image` field |
| 1200 | ~1200px wide | Detail page, gallery |
| 2000 | ~2000px wide | Full resolution viewing |

## Print Data Schema

All fields in `prints.js`:

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `id` | string | Yes | Unique identifier (e.g., `print-eth`) |
| `name` | string | Yes | Display name |
| `slug` | string | Yes | URL slug for detail page route |
| `description` | string | Yes | Detailed description text |
| `price` | number | Yes | Base price in EUR |
| `priceISK` | number | No | Price in Icelandic Króna |
| `currency` | string | Yes | Primary currency (`EUR`) |
| `image` | string | Yes | Primary image URL (800px recommended) |
| `images` | array | No | Gallery images array (all sizes) |
| `category` | string | Yes | Product category for filtering |
| `year` | string | Yes | Creation year |
| `edition` | string | Yes | Edition type (`open`, `limited-50`, etc.) |
| `sizes` | array | Yes | Available print sizes (`A4`, `A3`, `A2`, `A1`) |
| `tags` | array | No | Searchable tags for display |
| `featured` | boolean | No | Featured status for homepage |
| `stripePaymentLink` | string | No | Stripe payment link (self-fulfilled) |
| `printOnDemandUrl` | string | No | POD service link (e.g., Gelato) |

## Fields Displayed in PrintDetail View

### SEO Meta Tags
- `name` — Page title
- `description` — Meta description
- `image` — Open Graph image
- `slug` — Canonical URL path

### Header Section
- `category` — Displayed as accent label above title
- `name` — Main heading (h1)
- `tags` — Rendered as Pill components

### Specs Table
| Label | Data Field | Formatting |
|-------|------------|------------|
| Edition | `edition` | `formatEdition()` — "Open Edition" or "Limited Edition of X" |
| Year | `year` | Raw value |
| Category | `category` | Raw value |
| Sizes | `sizes` | Joined with comma |

### Content Tabs

**Description Tab**
- `description` — Full description text

**Details Tab**
- `edition` — Simple format ("Open" or "Limited")
- `year` — Raw value
- `sizes` — Joined list

**Shipping Tab**
- Static content (no data fields)

### Price Section
- `price` — Formatted with `formatPrice()` in EUR
- `priceISK` — Optional, formatted with `formatPrice()` in ISK

### Purchase Controls
- `sizes` — Populates size dropdown
- `stripePaymentLink` — Used by PrintBuyButton
- `printOnDemandUrl` — Used by PrintBuyButton

### Gallery
- `image` — Primary image (added to gallery if not in `images`)
- `images` — All gallery images with thumbnail selector

## Helper Functions

Exported from `prints.js`:

```javascript
// Get print by URL slug
getPrintBySlug(slug) → print object | undefined

// Format price with currency
formatPrice(price, currency = 'EUR') → formatted string
// Examples: "€95", "14.000 kr"

// Format edition display
formatEdition(edition) → formatted string
// "open" → "Open Edition"
// "limited-50" → "Limited Edition of 50"
```

## Adding New Prints

1. Upload assets to CDN:
   ```
   art-prints/print-{folder}/
   ├── master/{name}_print-master.tif
   ├── print/{name}_print-A1.tif ... A4.tif
   └── web/{name}-400.jpg ... 2000.jpg
   ```

2. Add entry to `prints.js`:
   ```javascript
   {
     id: 'print-{id}',
     name: 'Print Name',
     slug: 'print-slug',
     description: 'Description text.',
     price: 85,
     priceISK: 12500,
     currency: 'EUR',
     image: `${cdnBase}/print-{folder}/web/{name}-800.jpg`,
     images: [
       `${cdnBase}/print-{folder}/web/{name}-400.jpg`,
       `${cdnBase}/print-{folder}/web/{name}-800.jpg`,
       `${cdnBase}/print-{folder}/web/{name}-1200.jpg`,
       `${cdnBase}/print-{folder}/web/{name}-2000.jpg`
     ],
     category: 'Category',
     year: '2024',
     edition: 'open', // or 'limited-50'
     sizes: ['A4', 'A3', 'A2', 'A1'],
     tags: ['tag1', 'tag2'],
     featured: false,
     stripePaymentLink: null,
     printOnDemandUrl: null
   }
   ```
3. Access at `/prints/{slug}`
