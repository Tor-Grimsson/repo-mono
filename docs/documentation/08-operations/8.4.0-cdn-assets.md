## HLS Video Library

Videos are organized by page under `hls-library/`. Each video folder contains:
- `hls/` - Adaptive bitrate streams (360p, 480p, 720p, 1080p)
- `master.m3u8` - Main playlist for hls.js
- Still image(s) for poster/fallback

### Homepage Hero Videos

Theme-aware hero videos with automatic theme switching:

| Theme | Video Path | Still Image |
|-------|------------|-------------|
| Dark | `hls-library/video-home/hero-dark/hls/master.m3u8` | `still-hero-4k-dark.jpg` |
| Light | `hls-library/video-home/hero-light/hls/master.m3u8` | `still-hero-4k-light.jpg` |

### Homepage Highlights Videos

Used in `HomeHighlights.jsx` via `BentoCard` component:

| Card | Video Path | Still Image |
|------|------------|-------------|
| Málrómur | `hl-malmromur/hls/master.m3u8` | `hl-malromur-still.jpg` |
| Radial Dial | `hl-radial/hls/master.m3u8` | `radial-dial-still.png` |
| Motion Graphics | `hl-sanid/hls/master.m3u8` | `sanid-still.png` |
| Visuals | `hl-trollatunga/hls/master.m3u8` | `trollatunga-still-wide.jpg` |

### HlsVideo Component Behavior

The `HlsVideo` component (`apps/web/src/components/media/HlsVideo.jsx`):
- Loops indefinitely
- ALL user interactions disabled (no controls, no PiP, no context menu)
- Completely non-interactive across all devices
- DO NOT remove these attributes without explicit approval

## Usage in Code

### Full URL Pattern
```
https://f005.backblazeb2.com/file/kolkrabbi/website/{path}
```

### Homepage Hero Example
```javascript
// HomeHero.jsx
const cdnBase = 'https://f005.backblazeb2.com/file/kolkrabbi/website/hls-library/video-home'

const videoSrc = useMemo(() => {
  const variant = theme === 'dark' ? 'hero-dark' : 'hero-light'
  return `${cdnBase}/${variant}/hls/master.m3u8`
}, [theme])

const posterSrc = useMemo(() => {
  const variant = theme === 'dark' ? 'hero-dark' : 'hero-light'
  const filename = theme === 'dark' ? 'still-hero-4k-dark.jpg' : 'still-hero-4k-light.jpg'
  return `${cdnBase}/${variant}/${filename}`
}, [theme])
```

### Print Store Example
```javascript
image: 'https://f005.backblazeb2.com/file/kolkrabbi/website/art-prints/print-gblokk/web/gul-blokk-1200.jpg'
```
