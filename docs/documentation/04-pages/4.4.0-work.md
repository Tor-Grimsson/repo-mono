## Interactive Elements

### DialRotation Apparatus
The hero features a fully interactive canvas-based visualization tool:

**Parameters:**
- **Intensity:** Controls the strength of the wave effect
- **Frequency:** Adjusts wave oscillation frequency
- **Breath Time:** Animation cycle duration
- **Breath Amp:** Amplitude of breathing animation
- **Separation:** Spacing between circular elements
- **Global Scale:** Overall size scaling
- **Global Time:** Master time multiplier for animation speed
- **Circles:** Number of circular elements in the pattern

**Interactive Features:**
- Real-time parameter adjustment via sliders
- Quantize toggle for discrete value snapping
- Snap function for alignment
- Collapsible control panel
- Mouse/cursor interaction with the visualization
- Smooth transitions and animations

## Content Strategy

### Featured Projects (Dynamic)
Project content is managed through Sanity CMS via `getAllProjects` query:
- Project names
- Project descriptions
- Thumbnail images
- Links to project detail pages

**Note:** Update CMS entries to change copy shown in the grid/list. Empty states are handled at the data level.

### Collection Archive (Static)
The archive rows provide quick navigation to specialized collection pages:
- **Logomarks** - Brand identity and logo design work
- **Grids** - Editorial layout and grid system explorations
- **Illustrations** - Visual design and conceptual work
- **Motion Graphics** - Experimental animation and generative visuals

## Technical Notes

### Data Integration
- Featured projects fetch from Sanity CMS dynamically
- Collection archive uses static routing configuration
- Project cards render with data-driven content
- Empty states handled at component level

### Canvas Rendering
- DialRotation uses HTML5 Canvas API
- Animation runs at 60fps target
- Control panel state managed via React hooks
- Parameters persist during session via local state
- Responsive canvas sizing adjusts to viewport

### Performance Considerations
- Canvas animation optimized for smooth 60fps
- Project images lazy-loaded for performance
- Control panel toggles reduce complexity when hidden
- Data queries optimized to fetch only required fields

## Work Detail Page (`WorkDetail`)

Individual project pages accessed via `/work/:slug`.

**Route:** `/work/:slug`
**Component:** `apps/web/src/routes/WorkDetail.jsx`

### Page Structure

1. **Detail Hero (`DetailHero`)** - Full-viewport hero with project video/image
2. **Project Text (`ProjectText`)** - Overview section with metadata
3. **Image Carousel (`ImageCarousel`)** - Project image gallery (desktop only)
4. **Image Layout (`ImageLayout`)** - Additional image grid
5. **Projects List (`ProjectsList`)** - All projects navigation
6. **Connect CTA (`CtaGlobal`)** - Footer CTA

### Project Text Section

**Layout:** Two-column on desktop, stacked on mobile

**Fields displayed:**
- Section label: "Overview"
- Slug title: `/ {project.slug}`
- Description (right-aligned on xl+)
- Client name
- Services list
- Timeframe
- Year
- About text (from Sanity blocks)
- Back/Next navigation (cycles through projects)

**Responsive behavior:**
- `flex-col lg:flex-row` for info fields
- Description hidden below `xl` breakpoint
- Metadata fields stack vertically on mobile

### Image Carousel

**Features:**
- Drag/swipe navigation (mouse + touch)
- Arrow buttons (left/right)
- Indicator dots for slide position
- Smooth 500ms transitions
- 20% drag threshold to advance slides

**Layout:**
- Container: `h-[80vh]`
- Images: `max-w-[70%]` with `aspect-[3/2]`
- Hidden on mobile (`hidden md:block`)

**Indicator styles:**
- Active: `bg-fg-64` with `w-6` (pill shape)
- Inactive: `bg-fg-24` with `w-2` (dot)

### Mobile Behavior
- Carousel hidden below `md` breakpoint
- ProjectText fields stack vertically
- Full-width layout with page padding
