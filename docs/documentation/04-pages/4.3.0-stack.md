# 4.3.0 Page: Stack

## Overview
Stack is the editorial arm of kolkrabbi.io, branded as "Study Stack" — a blog featuring design insights, typography tutorials, and creative technology articles. The page provides a curated view of articles with hero feature, highlights grid, browsable archive, and smart article routing that supports both standard single-column and research two-column layouts.

**Primary Route:** `/stack`
**Component:** `apps/web/src/routes/Stack.jsx`
**Article Route:** `/article/:slug`
**Component:** `apps/web/src/routes/Article.jsx`

## SEO Metadata
- **Title:** Stack — Articles & Design Insights
- **Description:** Read our latest articles on design, typography, creative technology, and design systems.
- **OG Title:** Stack — Design Articles & Insights
- **OG Description:** Explore our blog featuring design insights, typography tutorials, and creative tech articles.
- **OG Image:** `https://kolkrabbi.io/img/open-graph/open-graph-03.png`

## Page Structure

Full-viewport hero with tall padding and gradient overlay.

**Content:**
- Title: "Study Stack"

- Excludes the featured article from index 0

### Browse Articles Section (`StackBrowseArticles`)
Searchable and filterable archive of all other articles.

**Heading:** "Browse Articles"
**Controls:**

## Article Layouts

Stack supports **two editorial layouts** via the Sanity `type` field:

### Standard Layout (`type: 'standard'`)
Single-column layout for straightforward blog posts.

**Features:**
- Max-width: 800px
- Portable Text rendering with `kol-prose-wide` typography
- `ArticleHeader` component (tags, title, author, excerpt, hero image)
- Optional `SourcesSection` for references
- `SimpleCodeBlockWide` for code samples

**When to Use:** News updates, quick reads, standard blog posts

### Research Layout (`type: 'research'`)
Two-column layout for in-depth articles with navigation.

**Features:**
- Sticky navigation sidebar (529px)
- Content column (flexible width)
- Summary bullets in sidebar via `StickyNavCard`
- Denser typography with `kol-prose` variant
- `ProseContent` component for article body
- `SourcesSection` for bibliography
- Interactive TOC with active section tracking

**Sidebar Behavior:**
- Cards for older sections (indices < activeSection) overlap by 40px
- Dimmed text for past sections
- Collapsed to single-line heading for visual hierarchy
- Normal spacing for active and future sections
- Z-index ordering ensures newer cards sit on top

**When to Use:** Deep dives, tutorials, documentation, research articles

## Data Flow

### Content Source
All articles fetched from Sanity CMS via `getLatestBlogPosts(20)`:
- Index 0 → Featured hero article
- Indices 1-4 → Highlights grid
- Remaining → Browse section

### Smart Article Routing
The `/article/:slug` route dynamically selects layout based on Sanity `type` field:

```
URL /article/my-post
  ↓ useParams() -> slug
  ↓ BLOG_DETAIL query (includes type field)
  ↓ const articleType = article.type || 'standard'
  ↓
  ┌──────────────────────────────┬─────────────────────────────┐
  │ articleType === 'research'   │ else                       │
  │ Two-column research layout   │ Single-column standard     │
  └──────────────────────────────┴─────────────────────────────┘
```

## Sanity Integration

### Environment Configuration
Required environment variables in `apps/web/.env`:

```bash
VITE_SANITY_PROJECT_ID=<project_id>
VITE_SANITY_DATASET=projects
VITE_SANITY_API_VERSION=2025-01-01
VITE_SANITY_USE_CDN=true
```

### Blog Schema Fields
File: `packages/content/src/schemas/types/blog.ts`

| Field | Type | Purpose |
|-------|------|---------|
| `title` | string | Article title (required) |
| `slug` | slug | URL slug, mirrors title by default |
| `excerpt` | text | 300 char summary for cards and SEO |
| `author` | reference | Points to `author` document |
| `publishedAt` | datetime | Required; drives ordering |
| `featured` | boolean | Flags hero/highlight candidates |
| `coverImage` | image | Hero image for article header |
| `thumbnail` | image | Card thumbnail for listings |
| `body` | Portable Text | Rich article content |
| `tags` | array<string> | Powers tag filter pills |
| `relatedProjects` | array<ref> | Cross-links to projects |
| `sources` | array<object> | Rendered by `SourcesSection` |
| `type` | string | Layout toggle: 'standard' or 'research' (default: 'standard') |

### Article Type Field Definition
```ts
defineField({
  name: 'type',
  title: 'Article Type',
  type: 'string',
  group: 'meta',
  initialValue: 'standard',
  options: {
    list: [
      { title: 'Standard Blog Post', value: 'standard' },
      { title: 'Research Article', value: 'research' }
    ],
    layout: 'radio'
  },
  description: 'Choose the layout and features for this article'
})
```

### Queries
File: `packages/content/src/queries.ts`

- `BLOG_DETAIL` - Single article lookup by slug (includes `type`, `sources`, `body`, related projects, tags, hero media)
- `BLOG_LIST` - Summary listing for Stack page
- `BLOG_FEATURED` - Hero and highlight picks

## Image Sizing Guidelines

| Location | Target Size | Notes |

## Technical Notes

### Runtime Flow
1. `Article.jsx` route grabs slug via `useParams()`
2. Fetches `BLOG_DETAIL` from Sanity
3. Calculates reading time (~200 WPM) and formats dates
4. Determines `article.type || 'standard'`
5. Renders appropriate layout based on type

### Sources Layout
- Sources list inherits `.kol-prose` width for both layouts
- Uses `dense` variant (1rem padding-top, 1px divider)
- Wrapper margin controlled at route level (`mt-8`)
- H3 headings override default `.kol-prose h3` top margin
- List items use 20px×24px padding with 0.5rem gaps

### Studio Workflow
1. Run `yarn workspace @kol/content studio`
2. Create/Edit "Blog Post" document
3. Fill required fields and select **Article Type** radio
4. Publish and preview via `/article/<slug>`

### Troubleshooting
- **Unknown field `type`:** Schema not deployed; run `yarn workspace @kol/content sanity-deploy`
- **Missing body content:** Ensure Portable Text blocks are under `body[]`
- **Hero not showing:** Provide `coverImage` with asset reference
- **Tags not filtering:** Confirm `tags` array is populated in Sanity
- **Layout not switching:** Verify `type` field is included in GROQ queries
