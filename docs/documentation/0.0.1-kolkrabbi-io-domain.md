## 🔄 Migration Overview

**Current Setup**: Framer hosting
**Target Setup**: Vercel hosting
**Domain**: kolkrabbi.io (+ www.kolkrabbi.io)

---

## Phase 1: Prepare Vercel (Do This First)

### 1. Deploy to Vercel

```bash
# If not already deployed
vercel --prod
```

### 2. Add Domain in Vercel Dashboard

- Go to your project in Vercel
- Settings → Domains
- Click "Add Domain"
- Enter: `kolkrabbi.io` (and `www.kolkrabbi.io` if you want both)
- Vercel will show you the DNS records you need

### 3. Note Down Vercel's DNS Records

Vercel will provide records like:

```
Type: A
Name: @
Value: 76.76.21.21 (example IP - yours will be different)

Type: CNAME
Name: www
Value: cname.vercel-dns.com
```

**⚠️ IMPORTANT**: Copy these exact values - you'll need them in Phase 3

---

## Phase 2: Remove Domain from Framer

### 1. In Framer Dashboard

- Go to your Framer project settings
- Find "Custom Domain" or "Domains" section
- Remove `kolkrabbi.io` from Framer
- This is important - Framer might hold the domain otherwise

**Why this matters**: Framer may have domain locks that prevent other services from claiming it

---

## Phase 3: Update DNS Records

### DNS Provider: Cloudflare

**Domain**: kolkrabbi.io is managed through Cloudflare

### In Cloudflare Dashboard:

#### Step 1: Configure Cloudflare Settings (Before DNS Changes)

**1. Set SSL/TLS Mode:**
- Go to SSL/TLS → Overview
- Set to **Full (strict)**
- This ensures proper SSL between Cloudflare and Vercel

**2. Enable Always Use HTTPS:**
- Go to SSL/TLS → Edge Certificates
- Turn on "Always Use HTTPS"

#### Step 2: Delete Framer's DNS Records

**In Cloudflare:**
1. Go to your domain: kolkrabbi.io
2. Click "DNS" in the left sidebar
3. Click "Records" tab
4. Find and delete:
   - A record pointing to Framer's IP (usually @ or root)
   - CNAME record for `www` pointing to Framer
   - Any other Framer-related records

**To delete:** Click "Edit" → "Delete" on each record

#### Step 3: Add Vercel's DNS Records

**Add these records in Cloudflare DNS:**

```
Type: A
Name: @
IPv4 address: [Vercel's IP - from Vercel dashboard]
Proxy status: DNS only (gray cloud ☁️)
TTL: Auto

Type: CNAME
Name: www
Target: cname.vercel-dns.com
Proxy status: DNS only (gray cloud ☁️)
TTL: Auto
```

**⚠️ CRITICAL - Proxy Status:**
- Click the cloud icon to toggle between "Proxied" 🟠 and "DNS only" ☁️
- **Must be gray cloud (DNS only)** during initial setup
- Orange cloud (Proxied) can cause SSL issues with Vercel
- You can enable proxy AFTER migration completes and SSL works

**To add records:**
1. Click "Add record" button
2. Select Type (A or CNAME)
3. Enter Name (@ for root, www for subdomain)
4. Enter Target/IPv4 (from Vercel)
5. **Click cloud icon to set "DNS only"** (gray)
6. Click "Save"

## Phase 4: Wait & Verify

### 1. DNS Propagation

**Timeline:**
- Minimum: 5-10 minutes
- Typical: 30-60 minutes
- Maximum: 24-48 hours (rare)

**Check Propagation Status:**
- https://dnschecker.org
- Enter your domain: `kolkrabbi.io`
- Should see Vercel's IP appear globally

### 2. Verify in Vercel

- Go back to Vercel → Settings → Domains
- Should show green checkmarks when DNS propagates
- Vercel will auto-generate SSL certificate (takes 5-10 min)

### 3. Test Your Site

- Visit `https://kolkrabbi.io`
- Should load your new Vercel-hosted site!
- Check SSL padlock in browser (https working)
- Test a few key pages:
  - Homepage
  - /foundry
  - /collections
  - /work

## 🐛 Troubleshooting

### "Domain already in use" in Vercel

**Cause**: Domain still claimed by Framer
**Fix**: Remove domain from Framer first, wait 5 minutes, try again

### "DNS not propagating"

**Cause**: DNS changes take time
**Fix**:
1. Verify records are correct in Cloudflare
2. Check if old records were fully deleted
3. **Verify Proxy Status is "DNS only" (gray cloud)**
4. Wait longer (up to 24 hours in rare cases)
5. Use incognito/private browsing to avoid cache

### "SSL certificate error" or "Too many redirects"

**Cause**: Cloudflare proxy enabled too soon or wrong SSL mode
**Fix**:
1. In Cloudflare: Set DNS records to "DNS only" (gray cloud)
2. In Cloudflare: SSL/TLS mode set to "Full (strict)"
3. Wait 5-10 minutes
4. Clear browser cache
5. After SSL works, you can enable Cloudflare proxy if desired

### "SSL certificate pending"

**Cause**: Vercel generates SSL after DNS verifies
**Fix**:
1. Wait 5-10 minutes after DNS propagates
2. Vercel auto-generates certificate
3. If stuck after 30 min, remove and re-add domain in Vercel

### Site loads but assets missing

**Cause**: Incorrect base URL or asset paths
**Fix**:
1. Check Vercel environment variables
2. Verify build completed successfully
3. Check browser console for 404 errors

### Site loads on www but not root (or vice versa)

**Cause**: Missing A or CNAME record
**Fix**:
1. Verify both A record (`@`) and CNAME (`www`) are in DNS
2. Wait for DNS propagation
3. Check Vercel has both domains added
