# Data Configuration

All foundry content is data-driven. Two main configuration files:

1. **typefaceConfig.js** - Typeface data (7 typefaces)
2. **specimens.js** - Specimen data (hubs + specimens)

## Quick Reference

**Add new typeface:**
1. Edit `typefaceConfig.js`
2. Create route file
3. Add route in `App.jsx`

**Add new specimen:**
1. Edit `specimens.js` (optional - for library display)
2. Create component file
3. Add route in `App.jsx`
