# 4.5.2.2 Málrómur Specimen Sections

## Overview
The Málrómur complete specimen page (`/specimen/malromur/selection`) showcases 11 different prose pattern sections, each demonstrating the typeface in various use cases. Each section follows a consistent structure with a title page followed by the actual specimen content.

2. **Editorial** (`MalromurEditorial`)

## Grid System

### Specifications
- **Columns**: 12
- **Gutter**: 24px
- **Margin X**: 180px (left/right)
- **Column Width**: 86px (fixed)
- **Baseline Grid**: 8px increments (with 24px major lines)

### Grid-Aligned Sections
Currently implemented sections that align to the grid overlay:
- Data Tables (✅)
- Newsletter (✅)

### Structure Pattern
The component structure wraps all sections in a GridOverlay component:

```jsx
<GridOverlay columns={12} gutter={24} marginX={180} columnWidth={86}>
  <div id="title-page">
    <MalromurTitlePage />
  </div>
  <div id="editorial">
    <MalromurEditorial />
  </div>
  {/* ... other sections */}
</GridOverlay>
```

Each grid-aligned section uses this pattern internally:

```jsx
<section className="w-full min-h-screen snap-start">
  <div style={{
    paddingLeft: '180px',
    paddingRight: '180px',
    paddingTop: '96px',
    paddingBottom: '96px'
  }}>
    <div className="grid" style={{
      gridTemplateColumns: 'repeat(12, 86px)',
      gap: '24px'
    }}>
      {/* Content using col-span-* and col-start-* */}
    </div>
  </div>
</section>
```

### Typography Baseline Alignment
Line heights use 8px increments to align with the baseline grid:
- Small text: 20px or 24px
- Body text: 24px
- Subheadings: 32px
- Headings: 56px or 72px

## Page Structure

### Component Hierarchy
```
MalromurSelection (route)
├── MalromurSpecimens (composition component)
│   ├── Floating Navigation (fixed positioning with auto-hide)
│   └── GridOverlay (wraps all specimen sections)
│       ├── Title Page
│       ├── Editorial
│       ├── Data Tables
│       ├── Menu
│       ├── Newsletter
│       ├── Index
│       ├── Chapter
│       ├── TOC
│       ├── Scientific
│       ├── Legislative
│       └── Variable Axis
└── FeaturesCardSection (CTA with links to other specimens)
```

### Floating Navigation
- **Positioning**: Fixed at `top-24` with nested sticky children
- **Auto-hide**: Fades to 0 opacity after 10 seconds of inactivity
- **Active tracking**: Highlights current section based on scroll position (center of viewport)
- **Behavior**: Navigation scrolls away naturally when specimens end (no bleed into CTA)

## Scroll Behavior

### Snap Points
- Container: `snap-y snap-mandatory` with `scroll-behavior: smooth`
- Each section: `snap-start` on both title pages and content sections
- This creates predictable snap points as users scroll through specimens

### Navigation
- Page loads with scroll position at top via `useEffect(() => window.scrollTo(0, 0))`
- Each section has an ID for deep linking from quick navigation
- GridOverlay provides visual grid toggle for design verification
- Grid toggle states: 1 (both grid + columns), 2 (columns only - default), 3 (hidden)
