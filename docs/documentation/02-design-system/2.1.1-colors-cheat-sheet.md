## Context Utilities

**Tokens:**
| Token | Dark Theme | Light Theme | Usage |
|-------|------------|-------------|-------|
| `--kol-surface-on-primary` | `#fafafa` | `#121215` | Foreground color |
| `--kol-surface-primary` | `#121215` | `#fafafa` | Background color |
| `--kol-border-default` | 8% foreground | 8% foreground | Border color |

**Utility Classes:**
```css
.text-auto              /* color: var(--kol-surface-on-primary) */
.text-auto-inverse      /* color: var(--kol-surface-on-inverse) */

.bg-auto                /* background: var(--kol-surface-primary) */
.bg-auto-inverse        /* background: var(--kol-surface-inverse) */

.border-auto            /* border-color: 8% foreground */
.border-auto-inverse    /* border-color: 8% inverse foreground */

.divider-auto           /* border: 1px, 8% foreground */
.divider-auto-inverse   /* border: 1px, 8% inverse foreground */
```

**Example:**
```jsx
{/* Context utilities set ONE property at a time */}
<div className="bg-auto text-auto border border-auto">
  Each utility sets a single CSS property
</div>
```

## Opaque Scale — `oq` (Solid Neutrals)

The **solid mirror of the `fg` scale** — same 14 stops, same source ink, but mixed onto the surface instead of `transparent`. So `oq` is **opaque** (hides what's behind it) where `fg` is alpha. `oq` replaces the retired `opacity-hex` family.

**14 Levels:** `01, 02, 04, 08, 12, 16, 24, 32, 40, 48, 64, 80, 88, 96`

**Definition (mirror of `fg` — only the base differs):**
```css
--kol-fg-16: color-mix(in srgb, var(--kol-surface-on-primary) 16%, transparent);              /* alpha  */
--kol-oq-16: color-mix(in srgb, var(--kol-surface-on-primary) 16%, var(--kol-surface-primary)); /* opaque */
```

**Background Utilities (standard + inverse + hover):**
```css
.bg-oq-01 … .bg-oq-96
.bg-oq-inverse-01 … .bg-oq-inverse-96
.hover\:bg-oq-* / .hover\:bg-oq-inverse-*
```

**Text Utilities:**
```css
.text-oq-01 … .text-oq-96
.text-oq-inverse-01 … .text-oq-inverse-96
```

**Border Utilities:**
```css
.border-oq-01 … .border-oq-96
.border-oq-inverse-01 … .border-oq-inverse-96
```

**How It Works:**
- `color-mix()` of the foreground ink onto the surface → an opaque grey.
- **Auto-themes:** both `--kol-surface-on-primary` and `--kol-surface-primary` flip in dark mode, so `oq` recomputes — no hardcoded light/dark blocks.
- Use `oq` for opaque fills (cover layers, a chip over a photo, anything that must hide its background). Use `fg` when you want the background to bleed through.

**`fg` vs `oq`:** `fg` = transparent (alpha) · `oq` = opaque (solid). Same stops, same ink, different base. Defined in `packages/theme/kol-opaque.css`.

## Quick Reference

**Total Utility Classes:**
- Foreground opacity (`fg`, alpha): 14 stops × {bg, text, border} × {standard, inverse} (+ hover)
- Opaque (`oq`, solid): 14 stops × {bg, text, border} × {standard, inverse} (+ bg hover) — 112 classes
- Surface: 8 classes
- Support surfaces: 4 classes
- Context: 8 classes
- State: surface hover/active (container removed)
- Elevation: 3 classes

**Key Patterns:**
- All utilities adapt to light/dark mode automatically
- Inverse variants use `--kol-surface-on-inverse` as base
- `fg` = transparent (alpha) · `oq` = opaque (solid) — same stops, different base
- Context-aware utilities work in inverse surface contexts
- State utilities use pseudo-classes (`:hover`, `:active`, `:focus-visible`)
