## Tier Table

| Name | Prefix | Min-width | Frequency |
|------|--------|-----------|-----------|
| Mobile | — | 0px | Base (all styles) |
| Small | `sm:` | 640px | Rare — hero sizing only |
| Tablet | `md:` | 768px | **Dominant** |
| Desktop | `lg:` | 1024px | Common |
| Desktop Large | `xl:` | 1280px | Rare — StackDetail hero only |
| Desktop XL | `2xl:` | 1536px | Not currently used |

## Standard Patterns

### Page Padding

```html
<!-- Standard pages — SiteLayout owns this. Do not set on routes/components. -->
<div class="px-4 md:px-6 lg:px-8">  <!-- 16px → 24px → 32px -->

<!-- Workshop content area -->
<div class="px-4 sm:px-8 lg:px-12"> <!-- 16px → 32px → 48px -->
```

> `SiteLayout` applies `px-4 md:px-6 lg:px-8` to the `<Outlet>` wrapper. Only apply this directly on `Footer` or other elements rendered outside the Outlet. Use `full-bleed` on any component that must extend edge-to-edge.

### Section Padding

```html
<section class="py-6 md:py-8">       <!-- 24px → 32px -->
```

### Section Gap

```html
<div class="gap-8">                   <!-- 32px always -->
```

### Desktop-Only Push

```html
<div class="lg:mt-16">               <!-- 64px at lg+ only -->
```

### Grid

```html
<div class="grid grid-cols-1 md:grid-cols-2">
<div class="grid grid-cols-1 md:grid-cols-3">
```

### Flex Direction

```html
<div class="flex flex-col md:flex-row">
```

### Visibility

```html
<div class="hidden md:block">  <!-- hide on mobile, show tablet+ -->
<div class="md:hidden">        <!-- show on mobile, hide tablet+ -->
```

## "What Breakpoint For X?" Decision Reference

| What you're doing | Use |
|-------------------|-----|
| Flip layout direction | `md:` |
| Change grid column count | `md:` |
| Toggle visibility | `md:` |
| Expand spacing on desktop | `lg:` |
| Hero heading tweak | `sm:` |
| Wide layout override | `xl:` (rare) |
| Typography scaling | `clamp()` — no breakpoints |
| Complex sidebar logic | JS — not Tailwind |

---

## Strategy Summary

| Strategy | When to Use |
|----------|-------------|
| `clamp()` | Typography, continuous spatial values |
| Tailwind classes | Layout flips, column count, visibility |
| JavaScript | Complex sidebar, scroll-distance logic |
