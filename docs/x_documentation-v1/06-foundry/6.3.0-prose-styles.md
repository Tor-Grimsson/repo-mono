## Overview

Documentation for the `/foundry/prose-styles` page showcasing typographic prose style applications.

## Route

- **Path:** `/foundry/prose-styles`
- **Component:** `FoundryProseStyles`

## Content

The Prose Styles page demonstrates:
- Editorial typography patterns
- Long-form text styling
- Heading hierarchies
- Paragraph treatments
- Pull quotes and callouts
- List and table typography

## Prose Style Specifications

Three main prose specs available:
- **Málrómur Prose** - Editorial serif styling
- **Documentation Prose** - Technical writing patterns
- **Stack Prose** - UI-focused typography

## Components Used

- `FoundrySection` - Section layout wrapper
- `ProseSpecCard` - Individual spec preview
- `FoundryCTA` - Bottom call-to-action
