# 4.5.2.1 Typeface Slug Pages - Simplified Structure

**Date**: November 24, 2025
**Status**: Implemented (Málrómur)
**Related**: 4.5.2-foundry-navigation-structure-research.md, 4.5.2.2-malromur-specimen-sections.md

---

## Overview

This document proposes a simplified structure for individual typeface pages that consolidates the bloated hierarchy into a single, focused landing page per typeface. Instead of multiple nested pages (typeface → specimen collection → individual specimens), each typeface gets one comprehensive page with jump links to sections.

---

## Current Bloated Structure (Málrómur Example)

```
/foundry/malromur (Typeface Page)
  └── /specimen/malromur (Specimen Collection Hub)
      ├── /specimen/malromur/selection (Complete Selection)
      ├── /specimen/malromur/prose (Prose Styles Hub)
      │   └── Individual Prose Specimens (8 separate pages)
      │       ├── /specimen/malromur/prose/editorial
      │       ├── /specimen/malromur/prose/data-tables
      │       ├── /specimen/malromur/prose/menu
      │       └── [etc...]
      └── /specimen/malromur/specs (Style Specs)
```

**Issues:**
- Too many layers of navigation
- User has to click through 3-4 pages to see actual content
- Redundant hub pages that just link to other pages
- Unclear hierarchy - what's the difference between "typeface page" and "specimen hub"?
- No clear path for users browsing

---

## Proposed Simplified Structure

```
/specimen/malromur (LANDING PAGE)
├── Hero Section
│   └── Component: OverviewHero (existing, from @kol/ui)
│   └── Typeface name rendered in the actual typeface via title prop
│
├── Quick Links (3 cards)
│   └── Component: FeaturesCardSection (existing, from web/shared)
│   └── Cards link to specimen pages or external pages
│       ├── Complete Selection → /specimen/malromur/selection
│       ├── Specs → /specimen/malromur/specs
│       └── Licensing → /foundry/licensing
│
├── About Section
│   └── Component: FoundryFeatureSection (existing, imagePosition="right")
│   └── Text left, image right
│       ├── Typeface description
│       ├── Design philosophy
│       └── Best use cases
│
├── Chapter Jump Links (TOC-style navigation)
│   └── Component: NEW - ChapterNavigation (to be created)
│   └── Simple list/grid of jump links to prose patterns on selection page
│       ├── Editorial → /specimen/malromur/selection#editorial
│       ├── Data Tables → /specimen/malromur/selection#data-tables
│       ├── Menu Design → /specimen/malromur/selection#menu-design
│       ├── Newsletter → /specimen/malromur/selection#newsletter
│       ├── Index/Directory → /specimen/malromur/selection#index
│       ├── Chapter Opening → /specimen/malromur/selection#chapter
│       ├── Table of Contents → /specimen/malromur/selection#toc
│       └── Title Page → /specimen/malromur/selection#title-page
│
├── Specs Preview Card
│   └── Component: FoundryFeatureSection (existing, imagePosition="left")
│   └── Preview of specs with link to full specs page
│       └── CTA: View Full Specifications → /specimen/malromur/specs
│
└── CTA Section
    └── Component: FoundryCTA (existing, from @kol/ui)
    └── "Download Font" or "View Licensing"

/specimen/malromur/selection (FULL SPECIMEN PAGE - SEPARATE)
└── Long scrolling page with all prose patterns
    ├── <section id="editorial"> [Editorial content] </section>
    ├── <section id="data-tables"> [Data tables content] </section>
    ├── <section id="menu-design"> [Menu design content] </section>
    └── [... all remaining prose patterns ...]

/specimen/malromur/specs (SPECS PAGE - SEPARATE)
└── Technical specifications page
    ├── Font metrics (weights, axes, OpenType features)
    ├── Character set coverage
    ├── File information
    └── Usage guidelines
```

---

## Benefits

1. **Single source of truth** - Everything about Málrómur on one page
2. **Better discoverability** - User sees all content at once via TOC
3. **Faster navigation** - Jump links instead of page loads
4. **Eliminates redundant hub pages** - No more specimen collection pages that just link elsewhere
5. **Clearer hierarchy** - Specimen page consolidates all typeface content
6. **Mobile-friendly** - Smooth scrolling instead of multiple page transitions
7. **Reuses existing components** - OverviewHero, FeaturesCardSection, FoundryFeatureSection, FoundryCTA
8. **Only 1 new component needed** - ChapterNavigation for TOC-style jump links

## Technical Implementation

### Smooth Scroll
```jsx
// Enable smooth scrolling to anchor links
html {
  scroll-behavior: smooth;
}

// Or in React Router
<Link to="/foundry/malromur#editorial" smooth>
  Editorial
</Link>
```

### Active Section Highlighting
```jsx
// Track which section is in viewport
const [activeSection, setActiveSection] = useState(null)

useEffect(() => {
  const observer = new IntersectionObserver(
    (entries) => {
      entries.forEach(entry => {
        if (entry.isIntersecting) {
          setActiveSection(entry.target.id)
        }
      })
    },
    { threshold: 0.5 }
  )

  // Observe all sections
  document.querySelectorAll('[id]').forEach(section => {
    observer.observe(section)
  })
})
```

### Sticky Chapter Navigation
```jsx
<nav className="sticky top-20 z-10 bg-surface-primary">
  <ChapterLinks active={activeSection} />
</nav>
```

## Example Page Flow (Málrómur)

1. User lands on `/specimen/malromur`
2. Sees hero with "Málrómur" in italic
3. Reads quick description
4. Sees 3 quick link cards
5. Scrolls to chapter navigation
6. Clicks "Editorial" → smoothly jumps to #editorial
7. Scrolls through complete selection
8. Clicks "Specs" in sticky nav → jumps to #specs
9. Reviews technical details
10. Clicks CTA to download or view licensing

**Total pages loaded**: 1
**Total clicks to content**: 1-2 (jump links)
