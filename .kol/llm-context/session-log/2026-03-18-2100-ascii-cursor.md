# Session Log: ASCII Cursor — Interactive Site-Wide Cursor

**Date:** 2026-03-18
**Status:** Completed

## Overview

Built a custom ASCII cursor system as a site-wide overlay. Replaces native cursor with ASCII crosshairs, adds shimmering stars around cursor, click-to-firework (3 weighted types), and right-click-to-space-invader. Integrated into SiteLayout.

## Key Accomplishments

### 1. AsciiCursor Component
**File:** `apps/web/src/components/ui/AsciiCursor.jsx`

Full-featured ASCII cursor overlay with four systems:
- **ASCII Crosshair**: Two styles — heavy ticks (`╻╺╸╹`) as default, diamond (`◇`) on hover over links/buttons/inputs. Detects interactive elements via `elementFromPoint` with temporary pointer-events toggle. Contrast outline via 4 offset copies in `surface-primary` color (no text-shadow).
- **Cursor Stars**: Random shimmer particles spawning every 400–1200ms at random angle/distance (30–50px) from cursor. Chars cycle through `· + * + · - ·`. Fade in/out over 1.2s. Self-removing.
- **Fireworks**: 3 types — cross burst (60%), ring burst (20%), diamond scatter (20%). Explode immediately at click point. 5-frame animation, self-removing.
- **Space Invader**: Right-click spawns invader at cursor. Drops in, shoots 3 bullets, exits right. 2.5s cooldown between spawns.

### 2. SiteLayout Integration
**File:** `apps/web/src/components/layout/SiteLayout.jsx`

Added `AsciiCursor` as a site-wide overlay. Uses `pointer-events-none` with `window` event listeners so all clicks pass through to underlying elements (links, cards, buttons all work normally). Native cursor hidden via injected `cursor: none !important` style. Z-index `z-[100]` — above work detail (`z-[80]`) and lightbox (`z-[90]`).

## Issues Encountered

### 1. Overlay blocking clicks
- **Problem:** Fixed overlay with click handlers captured all clicks, preventing links/cards from working.
- **Resolution:** Switched to `pointer-events-none` on overlay + `window` event listeners for fireworks/invaders. All clicks pass through natively.

### 2. Crosshair not detecting hover on interactive elements
- **Problem:** `elementFromPoint` was hitting the overlay div itself.
- **Resolution:** Temporarily set `pointerEvents = 'none'` on overlay during `elementFromPoint` call, then restore.

### 3. Cursor disappearing behind overlays
- **Problem:** Work detail panel (`z-[80]`) and lightbox (`z-[90]`) covered the `z-30` cursor.
- **Resolution:** Bumped cursor to `z-[100]`.

### 4. Crosshair invisible on light backgrounds
- **Problem:** `surface-on-primary` text invisible over white sections.
- **Resolution:** 4 offset copies of crosshair text in `surface-primary` color at ±1px diagonal — acts as solid outline without text-shadow.
