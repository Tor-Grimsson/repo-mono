# Session Log: Work V2 HMR Fix

**Date:** 2026-03-10
**Status:** Completed

## Overview

Fixed hot module replacement (HMR) for Work V2 routes by converting eager imports to lazy-loaded imports with Suspense boundaries. Noted future idea for ProjectShelf-per-type on the listing page.

## Key Accomplishments

### 1. Lazy-load Work V2 routes
**File:** `apps/web/src/App.jsx`

`WorkV2` and `WorkDetailV2` were eagerly imported in App.jsx, meaning every edit to those files or their children forced a full module reload through App.jsx, breaking HMR. Converted both to `lazy(() => import(...))` with `<Suspense>` fallbacks using `bg-surface-secondary` to match the V2 background.
