## Operational
- **Build:** always `pnpm exec turbo run build --force` — plain `pnpm build` cache-lies on raw-source packages.
- **Build green ≠ works (standing law, 2026-07-29):** `@kolkrabbi/*` publish raw source using `import.meta.glob` — rollup (build) transforms it, esbuild pre-bundling (dev) can't. A missing `optimizeDeps.exclude` entry fails **dev only**. After wiring any DS package into an app: copy the exclude rule from `apps/web/vite.config.js` (+ `include` for CJS chains) and **playwright-verify the live surfaces** before reporting.
- **Dev ports in practice (2026-08-25):** kol-studio's app usually holds 5173, so web hops to **5174** and brand to **5175** — and **5174 is not in Sanity's CORS list**: `/work`, `/stack` and their details render EMPTY locally. Audit Sanity-backed pages on production or add the port in Sanity Manage. Check `lsof -iTCP:517x` before pointing anything at a port.
- **Dev:** `pnpm dev` runs web+studio+brand, fully network-open (`host: true` / `--host 0.0.0.0`). Preferred ports (NOT pinned — `strictPort: false`, vite hops if taken): web **5173**, brand **5174**, studio **3333**, metrics **5176** via `pnpm dev:metrics` (not in root `pnpm dev`; its `/api` is proxied to production). Media **5177** via `pnpm dev:media` (`/api` → `admin.kolkrabbi.io`; `pnpm media:cf` for the functions locally). ⚠️ Sanity CORS is allowlisted per-origin — a hopped port breaks data fetches until added in Sanity Manage → API → CORS. ⚠️ **Agents: run app-scoped dev only** (`cd apps/brand && pnpm dev`) — root `pnpm dev` claims studio's 3333, collides with the user's own instance, and turbo aborts the whole run.
- **Root `public/` = single source of truth for shared statics (2026-07-15):** `public/fonts/` (244 files) + `public/favicons/` (2 files). Apps mount them as relative symlinks keeping their local names (web `fonts`+`favicons`, brand `fonts`+`favicon`, video `fonts`). Add shared assets at root only; Vite follows symlinks in dev and copies real files into every dist. **MEASURED 2026-07-30 — the "161M photos" blocker was a false premise.** md5 sweep: only **14 files / 9.5M are actually shared** (8 photoshoot `thg-01..08` web `img/contact/` ↔ brand `images/kol-photoshoot/`; 6 open-graph web `img/open-graph-foundry/` ↔ brand `images/kol-textures/`). 135M of brand's 145M is brand-only and never moves. Remaining: a yes/no on hoisting the 9.5M.
- **PUBLISHING LAW (learned the hard way 2026-07-30): use `pnpm publish`, never `npm publish`.** `npm publish` ships `workspace:*` raw into `dependencies` and every consumer install dies with `ERR_PNPM_WORKSPACE_PKG_NOT_FOUND`. That burned framework **0.8.0** (now deprecated by the DS agent) exactly as it burned 0.5.11/0.5.12.
